프로그래밍과 컴퓨터 과학 개념을 수업에서 직관적으로 설명할 수 있도록 만든 웹 강의노트입니다. 모든 자료는 웹페이지 형태로 제공되며, 별도의 설치 없이 브라우저에서 바로 수업에 사용할 수 있습니다.

## 🔗 바로가기
* **단축 링크:** [https://bit.ly/정보교과](https://bit.ly/정보교과)
* **웹 페이지:** [https://luminousky.com/Visual-Assets-for-CS-Teacher/](https://luminousky.com/Visual-Assets-for-CS-Teacher/)

## 🌟 주요 특징

* **웹버전 강의노트:** 고등학교 「정보」 · 「인공지능 기초」 · 「데이터 과학」 · 「프로그래밍」의 강의노트를 제공합니다.
* **AI 시뮬레이터:** 인공지능에서 다루는 기계학습 모델들의 작동 원리를 텍스트가 아닌 시뮬레이터로 **눈으로 직접 확인**하며 실습할 수 있습니다.
* **프로그래밍 개념 시각화:** 제어 구조, 알고리즘 등 추상적인 개념을 시각적으로 구현해 설명의 힘을 더합니다.
* **설치가 필요 없습니다:** 주소만 열면 바로 수업에 씁니다. 프로그램을 깔거나 계정을 만들 필요가 없습니다.
* **오프라인 zip:** 인터넷이 없는 교실을 위해 **통째로 다운로드받아 사용할 수 있는 zip**도 함께 배포합니다.
