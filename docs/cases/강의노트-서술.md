### 2026-08-12 · 「이전 차시 · 다음 차시」 링크를 만들지 않는다

파일 이름이나 차시 순서가 바뀔 때마다 **앞뒤 파일을 함께 고쳐야 한다.**
차시 하나를 둘로 나누면 고칠 파일이 셋이 된다. 이동은 푸터의 목록 링크로 충분하다.

처음에는 **글로 예고하는 것은 괜찮다**고 보았다 — 링크가 아니라서 깨지지 않는다고. 그러나
강의노트는 낱개로 읽히고 순서도 바뀌므로, 예고는 **없는 다음 시간을 가리키게 되거나 다른 차시를
가리키게 된다.** 2026-08-12 사용자가 글 예고도 막았다. 규칙만 있고 검사가 없던 동안
다섯 과목 모두에 쌓여 있다가 `check -- html`에 넣고서야 멈췄다.

2026-09-24에는 **앞 차시를 가리키는 것**(「앞 시간에 배운 대로」)과 **다른 강의노트로 거는 링크**
(용어에 건 링크 · 「○○ 다시 보기」)도 막았다. 순서가 바뀌면 없는 시간을 가리키는 것은 같다.

같은 파일 안에서 절을 **차례로** 가리키는 것(「세 번째 절」·「마지막 절」)도 같은 병이다.
절을 하나 끼우는 순간 어긋나는데 **어긋난 것을 아무도 알려 주지 않고**, 학생은 세어 보다가 틀린다.

### 2026-09-25 · 교과가 겹치는 개념은 기준 과목의 서술로 맞춘다

**2026-09-25 갱신 — 과목 간 점검의 기준선은 「인공지능기초」다**(사용자 확정). 정보 → 인공지능기초가 가장
무난한 선택과목 수강 순서이고, 인공지능기초에서 심화된 학생이 주로 데이터과학을 고르며, 인공지능기초가
과목 내부 점검을 가장 먼저 마쳤다. 과목 사이의 복합 용어 표기는 `check -- prose` 가 지킨다(`tools/checks/prose.mjs`).
아래는 그 전(2026-08-22 사용자 확정)에 「정보」를 기준으로 다섯 건을 맞춘 기록이다.

정보는 모든 학생이 듣는 공통 과목이고 인공지능기초·데이터과학이 그 위에 얹힌다.
**먼저 배운 말이 뒤에서 바뀌면 앞을 제대로 배운 학생이 걸려 넘어진다** → [오개념 판례](오개념.md)의 규칙 4 · 7.

교과서끼리 다를 때도 정보를 따르되, **교과서 근거를 먼저 확인한다.** 실제로 확인해 보니
어긋난 쪽이 근거가 없는 경우가 있었다 — 인공지능기초 강의노트가 쓰던 지능 에이전트의
특성 셋(자율성·협력성·목표 지향성)은 **그 교과서에 한 번도 나오지 않는 말**이었고,
정보 교과서에는 다섯(자율성·능동성·사회성·시간 연속성·반응성)이 실려 있었다.

| 어긋났던 것 | 어떻게 맞췄나 |
|---|---|
| 지도학습의 수치 유형 이름 | **회귀**. 두 교과서 모두 회귀다. 「예측」은 회귀가 **하는 일**을 말하는 동사 자리에만 쓴다 |
| 훈련/시험 데이터 | **훈련 데이터 · 테스트 데이터**. 「시험 데이터」는 두 교과서 어디에도 없던 말이었다 |
| 지능 에이전트의 정의 | 가르는 자리는 **학습과 추론이 있는가**. 학습을 요건에서 빼면 같은 기기를 두 교과가 다르게 판정한다 |
| 지능 에이전트의 특성 | **다섯**으로 통일 |
| 인공지능이 흉내 내는 능력 | **지각**(능력)과 **인식**(동작 단계)을 나눠 쓴다 |

**하나는 일부러 통일하지 않았다.** 동작 단계가 정보는 넷(인식→학습→추론→행동),
인공지능기초는 셋(인식→판단→행동)인데 **어긋난 것이 아니라 묶는 단위가 다르다.**
파일 전체가 3단계로 짜여 있어 다시 짜는 대신 **「판단은 학습과 추론을 함께 부르는 말」**
한 줄을 넣어 두 그림을 겹쳐 볼 수 있게 했다. **어긋남이 아닌 것을 억지로 맞추면
멀쩡한 구조가 무너진다.**

→ 규칙: docs/강의노트-작성-규칙.md 「서술 양식」

### 2026-08-06 · 자체 서술 원칙

참고 자료 내부의 번호(`[표 Ⅱ-9]`, `[그림 Ⅱ-21]`)는 **그 자료 안에서만 뜻이 통한다.**
캡션은 **무엇을 담은 표인지**로 쓴다. HTML 주석에도 남기지 않는다.

```html
<p>[표 Ⅱ-9] 세계 행복 보고서 2023 중 일부</p>              <!-- X -->
<p>세계 행복 보고서 2023 데이터 일부 — 137개국 중 12개국</p>   <!-- O -->
```

`fa-quote-left` 인용 블록은 **실존 인물의 발언에만** 쓰고 발언자를 밝힌다.
일반 개념 정의에 인용 블록을 쓰면 출처를 밝혀야 하는데 개념에는 밝힐 출처가 없다.

```html
<!-- O : 인물 발언 + 발언자 -->
<p>… 발견하는 태도, 유연성, 자발성이 바로 탐색적 데이터 분석이다.
   <span>— 존 튜키(John Tukey)</span></p>
```

→ 규칙: docs/강의노트-작성-규칙.md 「참고 자료와 자체 서술」

### 2026-09-24 · 문체 기준서

규칙은 CLAUDE.md 「문체 기준서」에 있다. 여기에는 X / O만 짧게 둔다.

**퀴즈 해설 첫머리(2)** — 감탄사가 첫 문장을 먹으면 이유가 둘째 문장으로 밀린다.
「틀린 것은?」 문항의 오답 해설이 「맞습니다」로 열리면 학생은 제 답이 맞은 줄 안다.

```text
X  정답(참): 맞습니다! 표본이 작으면 우연이 크게 섞입니다.
O  정답(참): 표본이 작으면 우연이 크게 섞입니다.
X  오답(부정형 문항): 맞습니다. 이 설명은 옳으므로 답이 아닙니다.
O  오답(부정형 문항): 맞는 설명입니다. 그래서 「틀린 것」이 아닙니다.
```

**부호(3)** — 과목마다 ‘ ’ · “ ” · « »가 섞여 같은 강조가 세 모양이었다(2026-09-24에 한 번에 바꿨다).

```text
X  컴퓨터가 무언가를 ‘안다’는 것      받을 때는 «자리»를 알려 줍니다
O  컴퓨터가 무언가를 「안다」는 것      받을 때는 「자리」를 알려 줍니다
```

**라벨(12)** — 이모지와 영문 머리표는 문장이 할 일을 그림이 대신하게 한다.

```text
X  💡 예: 집값을 예측할 때…      CHECK-UP      ※ 위 그래프는…      예) 긴 가래떡 썰기
O  예를 들어 집값을 예측할 때…   스스로 확인    위 그래프는…        떡에 비유하면 긴 가래떡을 써는 일입니다.
```

**판정문(7)** — 문단 끝의 「그것이 요점입니다」는 앞 문장을 한 번 더 말할 뿐이다.

```text
X  …그래서 두 값을 함께 봅니다. 이것이 핵심입니다.
O  두 값을 함께 봐야 합니다. 한쪽만 보면 …
```

**되읽기(9)** — 「위 설명을 다시 읽어 보세요」는 확인이 아니라 복습 지시다. 본문에 없는 상황을 하나 준다.

### 2026-08-05 · 서술 방법의 근거

- **참고 자료의 예시 · 비유 · 예시 값 · 예시 코드를 새로 짜는 까닭** — 출처 언급을 지워도 서술이
  원문에 가까우면 소용이 없다. 비유를 갈아타면 그 아래 문장이 통째로 달라져 겹침을 막는 가장 확실한
  길이 된다. 주제 순서는 교육과정이 정하므로 따라가도 된다.
- **예시가 하나뿐이면 2~4개로 늘리는 까닭** — 참고 자료는 지면 때문에 예시를 하나만 싣는데,
  그대로 옮기면 학생이 형식을 잡지 못한다. 예시들의 공통 형식을 짚고, 좋은 점만 적지 않는다.
- **활동을 뺄 때 보고하는 까닭** — 넣을지는 먼저 판단하되, 최종 생략 판단은 사용자가 한다(2026-08-05).
- **주어진 자료의 범위를 스스로 좁히지 않는 까닭** — C 문법에서 「고등학교 범위 밖」이라며 다섯 주제를
  뺐다가 되돌려받았다(2026-08-22). 사용자가 자료를 주었다면 다루라는 뜻이다.
- **앞 과목 내용을 기억한다고 전제하지 않는 까닭** — 「정보」는 중학교 내용을 기억하지 못한다고 보고,
  필요한 개념을 처음 나오는 곳에서 푼다. 별도 복습 절을 두지 않는다.
- **겹치는 과목을 「더 자세히 다룬다」로 넘기지 않는 까닭** — 강의노트는 독립 저작물이고, 다른
  과목을 가리키는 말은 순서가 바뀌면 거짓이 된다. 「여기서는 ~까지만 본다」로 닫는다.
- **숫자를 실제로 계산하고 코드를 실제로 돌리는 까닭** — 표에 적은 값과 본문 서술이 어긋나지 않는지는
  다른 길로 확인할 수 없다. 실습 자료(CSV · 시드를 고정한 모의 실험)를 고치면 본문 숫자도 함께 고친다.
- **SVG는 그림이라야 서는 개념에만 쓰는 까닭** — 차시당 개수는 상한이지 목표가 아니다. 「정보」
  그림이 없는 차시도 있다.
