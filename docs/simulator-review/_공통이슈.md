# AI 시뮬레이터 공통 이슈 누적

검증 기준: 고등학교 「인공지능 기초」 / 루브릭 4축(A 개념 정확성 · B 시각화 정합성 · C 안정성 · D 접근성·반응형)

> 제외 합의 사항: 형성평가(퀴즈) 부재는 감점하지 않음. CDN 전면 의존은 학교 온라인 환경 기준 **의도된 설계**이므로 감점하지 않음.

---

## 반복 확인된 패턴

### 1. 터치/포인터 이벤트 미지원 (접근성)
- **해당**: search-bfs-dfs (✅ 수정 완료)
- 격자·캔버스 조작을 `mousedown` / `mouseenter` 로만 바인딩. 태블릿에서 드래그 조작 불가(단일 탭만 동작).
- **표준 수정 레시피** (이후 파일에도 그대로 적용):
  ```javascript
  cell.addEventListener('pointerdown', onDown);
  cell.addEventListener('pointerenter', onEnter);
  document.onpointerup = document.onpointercancel = () => isDrawing = false;

  function onDown(e) {
      // 터치는 첫 요소에 포인터가 암묵 캡처되어 이웃의 pointerenter가 안 뜬다 → 반드시 해제
      if (e.pointerId !== undefined && e.currentTarget.hasPointerCapture?.(e.pointerId)) {
          e.currentTarget.releasePointerCapture(e.pointerId);
      }
      ...
  }
  ```
  컨테이너에 `touch-action: none;` 을 함께 지정해 드래그 중 페이지 스크롤을 막을 것.

### 2. 모바일 터치 타깃 44px 미달
- **해당**: search-bfs-dfs (375px에서 격자 셀 28×28px)

### 3. 키보드 접근 / ARIA 부재
- **해당**: search-bfs-dfs (격자 셀이 `div`, tabindex·aria-label 없음)

### 4. 색상 단독 상태 구분
- **해당**: search-bfs-dfs (발견/방문/경로를 색으로만 구분, 경로만 아이콘 병기)

### 5. status 요소 자체가 flex 컨테이너 → innerHTML 문장이 토막남
- **해당**: search-heuristic (✅ 수정 완료)
- `innerHTML`로 `<b>` 등이 섞인 문장을 넣는 요소에 `flex`를 주면 텍스트 노드와 태그가
  **각각 별도 flex 아이템**이 되어 따로따로 줄바꿈된다.
- **레시피**: 바깥 div는 정렬용(`flex items-center justify-center`)으로만 두고, 메시지는
  안쪽 `<span>`에 넣어 그 span을 `getElementById` 대상으로 삼는다. 고정 높이(`h-14`)는
  `min-h-14`로 바꿔 여러 줄일 때 잘리지 않게 한다.
- **이후 파일 확인 포인트**: `setStatus`/`innerHTML` 대상 요소의 클래스에 `flex`가 있는지.

### 6. 교육 메시지가 알고리즘과 무관하게 고정
- **해당**: search-heuristic (✅ 수정 완료 — 그리디에도 "최적 경로"라고 표시하고 있었음)
- **확인 포인트**: 최적성·수렴·정확도를 단정하는 문구가 알고리즘/설정에 따라 달라져야 하는데
  하드코딩되어 있지 않은지. 시뮬레이터가 가르치려는 대비를 스스로 무너뜨리는 유형의 버그다.

### 7. 개념적 의미가 있는 값에 난수 사용
- **해당**: search-heuristic (✅ 수정 완료 — 트리 h가 1~20 난수였음)
- **확인 포인트**: 거리 추정·가중치·확률처럼 의미가 있는 값에 난수를 쓰면 핵심 직관이
  화면에서 사라지고 이론적 보장(예: A*의 admissible 조건)이 깨진다.
