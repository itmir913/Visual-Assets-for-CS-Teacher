## ⚠️ 검증 범위의 한계

이 파일은 **웹캠과 원격 ML 모델(MobileNet / COCO-SSD / FaceMesh / BodySegmentation)** 이
있어야 실제 추론이 돌아갑니다. 검증 환경에 카메라가 없어 **추론 결과의 정확성은 확인하지
못했습니다.** 대신 다음을 확인했습니다.

- p5.js / ml5.js 라이브러리 로드 여부
- **카메라를 못 쓰는 상황의 처리** (교실에서 가장 흔한 실패)
- 레이아웃·가독성·반응형

추론 품질은 ml5가 제공하는 사전학습 모델에 달려 있어, 이 파일이 책임지는 부분이 아닙니다.

## C. 안정성 — 하 → 상 (핵심 수정)

### 🔴 C-1. 카메라를 못 쓰면 아무 안내 없이 멈춰 있었음

`startVideo()`가 p5의 `createCapture(constraints, 성공콜백)` 만 사용하고 **오류 처리가
전혀 없었습니다.** `createCapture`는 실패해도 콜백이 호출되지 않습니다.

그 결과 카메라를 쓸 수 없으면:
1. `startSystem()`이 이미 **[웹캠 켜기] 버튼을 숨기고** [중지] 버튼을 띄운 뒤
2. "버튼을 눌러 시작하세요" 안내 오버레이까지 **감춰 놓고**
3. 성공 콜백이 오지 않아 로딩 화면도 상태 메시지도 뜨지 않음

→ **검은 화면만 남고, 다시 시도할 버튼조차 사라진 상태**가 됩니다.

교실에서 가장 흔한 실패 경로입니다. 권한 팝업에서 실수로 '차단', 데스크톱 PC에 카메라 없음,
다른 프로그램이 카메라 점유 — 전부 여기에 해당합니다.

**수정**: `createCapture` 전에 `navigator.mediaDevices.getUserMedia()`로 먼저 확인하고,
실패하면 `handleCameraError(err)`가 UI를 되돌리고 원인별 안내를 띄우도록 했습니다.

오류 4종을 주입해 실제 동작을 검증했습니다.

| 오류 | 표시된 안내 | 시작 버튼 복구 | 중지 버튼 숨김 |
|---|---|---|---|
| `NotAllowedError` (권한 거부) | 카메라 사용이 거부되었습니다. 주소창의 카메라 아이콘에서 권한을 허용한 뒤 다시 시도하세요. | ✅ | ✅ |
| `NotFoundError` (장치 없음) | 사용할 수 있는 카메라를 찾지 못했습니다. 연결 상태를 확인하세요. | ✅ | ✅ |
| `NotReadableError` (사용 중) | 다른 프로그램이 카메라를 사용 중입니다. 해당 프로그램을 끄고 다시 시도하세요. | ✅ | ✅ |
| 기타 | 카메라를 켜지 못했습니다. 브라우저를 새로고침한 뒤 다시 시도하세요. | ✅ | ✅ |

확인하는 사이에 [중지]를 누른 경우도 `if (!isRunning) return;` 로 처리했습니다.

### ✅ 원래 잘 되어 있던 점
- `updateCameraList()`가 `mediaDevices` 미지원과 카메라 0개를 이미 구분해 처리합니다.
- `stopAllModels()`가 각 모델의 `*Stop()` 존재 여부를 확인하고 `try/catch`로 감쌌습니다.
- 모델을 한 번 받으면 재사용(캐싱)하고, 카메라 해상도를 640×480으로 제한해 연산량을 줄입니다.
- ml5 백엔드를 WebGL로 고정해 WebGPU 관련 오류를 피합니다.

## D. 접근성·반응형 — 중 → 상

### 🔴 D-1. 상태 메시지 상자가 56px 고정이었음 (수정)
`h-[56px]` 고정이라, 위에서 추가한 카메라 오류 안내 같은 긴 문구가 들어가면 잘립니다.
`min-h-[56px]` + `py-2` 로 바꿨습니다.

검증: 가장 긴 안내("카메라 사용이 거부되었습니다…")에서 상자 **104px, 잘림 없음**.

### 🔴 D-2. 본문 다수가 14px 이하였음 (수정)
| 대상 | 수정 전 | 수정 후 |
|---|---|---|
| 분류/탐지/분할 개념 설명문 (3곳) | 14px | 16px |
| 실습 안내문 | 14px | 16px |
| 웹캠 오버레이 안내 (2곳) | 14px | 16px |
| 상태 메시지 | 14px | 16px |
| `Interactive Demo` / `How it works` 라벨 | 12px | 16px |

검증: 375px에서 **본문성 작은 글자 0개**, 가로 넘침 0.

## B. 시각화 정합성 — 상 (수정 없음)

- 이미지 분류 / 객체 탐지 / 이미지 분할 세 가지를 **개념 카드 → 실습 모드**로 1:1 대응시켜,
  "무엇이 다른가"를 화면에서 바로 비교할 수 있습니다.
- 픽셀 격자 인터랙션(`.pixel-grid`)으로 "컴퓨터는 이미지를 숫자로 본다"를 먼저 다룹니다.
- 카메라 선택 드롭다운이 있어 외장 웹캠이 있는 교실에서도 전환할 수 있습니다.
