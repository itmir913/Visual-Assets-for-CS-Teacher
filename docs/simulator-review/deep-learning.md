## A. 개념 정확성 — 상 (수정 없음)

### ✅ 역전파가 정확
`TinyMLP` (입력 2 → 은닉 n (tanh) → 출력 1 (sigmoid), 이진 교차엔트로피):

| 요소 | 구현 | 판정 |
|---|---|---|
| 출력층 오차 | `dz2 = a2 - y` | ✅ 시그모이드+BCE 결합 미분 |
| 출력 가중치 | `dw2[j] = dz2 * a1[j]` | ✅ |
| 은닉층 오차 | `dz1[j] = dz2 * w2[j] * dtanh(a1[j])` | ✅ 연쇄법칙 |
| tanh 미분 | `dtanh(y) = 1 - y*y` (활성값 입력) | ✅ |
| 갱신 순서 | `dz1` 계산 후에 `w2` 갱신 | ✅ 순서 정확 |
| 손실 | BCE + `1e-7` 안정화 | ✅ |
| 시그모이드 | `±50` 클램프 | ✅ 오버플로 방어 |

### ✅ XOR 실험이 교과서 그대로 재현됨
**"은닉층 없이는 XOR를 못 푼다"** 는 딥러닝 단원의 출발점입니다. 4,000에포크 학습 결과:

| 은닉 뉴런 수 | 최종 손실 | 정확도 | 예측 |
|---|---|---|---|
| **1** | 0.574 ~ 0.760 | **0.5 ~ 0.75** | 갈라내지 못함 |
| **2** | 0.0004 | **1.00** | 0.001, 1.000, 1.000, 0.001 |
| 4 | 0.0002 | 1.00 | 0, 1, 1, 0 |
| 8 | 0.0001 | 1.00 | 0, 1, 1, 0 |

은닉 뉴런을 1개로 줄이면 실패하고 2개부터 완벽히 푸는 경계가 그대로 나타납니다.
선형 분리 가능한 AND는 은닉 2개로 정확도 1.00.

## B. 시각화 정합성 — 하 → 상

### 🔴 B-1. 과적합 탭(4번)의 그래프가 아예 보이지 않았음 (수정)

`switchTab()`이 탭 0·1·2에서는 각각 `resize()`를 호출하는데 **탭 3만 빠져 있었습니다.**

```javascript
if (i === 0) gdSim.resize();
if (i === 1) nnSim.resize();
if (i === 2) dbSim.resize();
// ← 탭 3(과적합 차트)에 대한 처리 없음
```

Chart.js 인스턴스는 탭이 **숨겨진 상태에서 생성**되어 크기가 0으로 잡히고, 탭을 열어도
다시 크기를 재지 않아 캔버스가 **0 × 0** 인 채로 남았습니다.

| 상태 | 캔버스 크기 |
|---|---|
| 수정 전 (탭 4 진입) | **0 × 0** (그래프 안 보임) |
| 수동 `chart.resize()` 호출 시 | 260 × 366 |
| **수정 후 (탭 4 진입)** | **259 × 366** ✅ |

훈련 오차와 검증 오차가 갈라지는 그래프가 그 탭의 전부이므로,
**과적합 단원이 통째로 작동하지 않던 상태**였습니다.

**수정**: `if (i === 3 && ofSim.chart) ofSim.chart.resize();` 추가.

검증 결과 탭 0~3 **모든 캔버스가 정상 크기**로 렌더링됩니다.

| 탭 | 캔버스 | 크기(375px) |
|---|---|---|
| 0 경사하강 | gdCanvasSide / gdCanvasTop | 298×298 / 291×248 |
| 1 신경망 구조 | nnCanvas | 293×183 |
| 2 결정경계 | dbCanvas | 291×298 |
| 3 과적합 | overfitChart | **259×366** |
