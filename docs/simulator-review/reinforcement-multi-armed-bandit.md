## A. 개념 정확성 — 상

### ✅ 구현이 전부 정석
| 요소 | 구현 | 판정 |
|---|---|---|
| 보상 | `Math.random() < trueProb ? 1 : 0` (베르누이) | ✅ |
| 가치 갱신 | `Q += (R − Q) / N` (증분식 표본평균) | ✅ |
| 탐험 | 확률 ε로 균등 무작위 | ✅ |
| 활용 | argmax Q, **동점 시 무작위 선택** | ✅ |

동점 무작위 처리가 특히 중요합니다. 초기에 모든 Q가 0이라 동점인데, 이걸 빼먹으면
항상 0번 기계만 골라 실험이 망가집니다. 제대로 되어 있습니다.

### ✅ ε에 따른 결과가 교과서 그대로
3,000스텝 실험:

| ε | 최적 기계 선택률 | 평균 보상 | (최적 기계 확률) |
|---|---|---|---|
| 0 | 1.000 *(운 좋은 경우)* | 0.717 | 0.72 |
| **0.05** | 0.952 | **0.670** | 0.68 |
| 0.3 | 0.733 | 0.554 | 0.61 |
| 1 | 0.202 (= 1/5, 균등) | 0.427 | 0.69 |

- **ε = 0.05에서 평균 보상이 최적에 가장 근접**합니다. Sutton & Barto 교재의 결과와 같은 모양입니다.
- ε = 1은 정확히 1/5(균등 무작위)로 떨어집니다.
- 많이 뽑힌 기계의 Q가 실제 확률과 거의 일치합니다(오차 0.003 ~ 0.055).

### ✅ ε = 0의 고착이 실제로 재현됨 — 이 단원의 핵심
"탐험을 안 하면 최적을 못 찾는다"를 실측으로 확인했습니다 (ε = 0, 1,000스텝, **100회 반복**):

| 항목 | 결과 |
|---|---|
| 최적 기계를 절반도 선택하지 못한 경우 | **73 / 100** |
| 평균 최적 기계 선택률 | 0.27 |
| 평균 **미탐색** 기계 수 (5개 중) | **3.03개** |

ε를 0으로 놓고 여러 번 돌려 보게 하면 "처음 운 좋게 걸린 기계에 눌러앉는" 모습이
73%의 확률로 나옵니다. 수업에서 그대로 쓸 수 있는 대비입니다.

## B. 시각화 정합성 — 상

- ε 슬라이더가 0 ~ 1, 0.05 단위로 **탐험 확률을 %로 표시**합니다. 값의 의미가 바로 보입니다.
- 보상을 `+1` / `+0` 플로팅 텍스트로 즉시 띄워, 확률적 보상이라는 점이 드러납니다.
- 기계별 Q값 추이를 그래프로 누적(최근 500스텝)해, 추정값이 실제 확률로 수렴하는 과정을
  관찰할 수 있습니다.
