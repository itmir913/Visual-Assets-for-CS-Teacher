## A. 개념 정확성 — 상 (수정 없음)

### ✅ 안전성 판정이 정확
```javascript
if (state[i] === col || Math.abs(state[i] - col) === Math.abs(i - row)) return false;
```
같은 열 + 두 대각선을 한 줄로 정확히 검사합니다. 행은 구조상 한 행에 하나만 놓으므로
검사할 필요가 없고, 실제로 검사하지 않습니다. 정석 구현입니다.

### ✅ 해가 실제로 유효
| N | 찾은 해 | 유효성 |
|---|---|---|
| 4 | `1,3,0,2` | ✅ |
| 5 | `0,2,4,1,3` | ✅ |
| 6 | `1,3,5,0,2,4` | ✅ |
| 8 | `0,4,7,5,2,6,1,3` | ✅ (고전적 첫 해와 일치) |

### ✅ 탐색 단계 수가 이론값과 일치
| N | 단계 수 | 트리 노드 | 시도 | 가지치기 | 백트래킹 |
|---|---|---|---|---|---|
| 4 | 57 | 26 | 26 | 18 | 4 |
| 5 | 31 | 15 | 15 | 10 | 0 |
| 6 | 368 | 171 | 171 | 140 | 25 |
| 8 | 1,858 | 876 | 876 | 763 | 105 |

N=5가 N=4보다 단계가 적은 것도 정상입니다(첫 해를 운 좋게 빨리 만남).
**가지치기(prune)가 시도의 대부분을 차지**한다는 사실이 수치로 드러나, 백트래킹의 핵심인
"안 되는 가지를 일찍 자른다"를 학생이 직접 확인할 수 있습니다.

### ✅ 힌트로 제시하는 정답 예시가 전부 유효
`iqShowHint()`가 제시하는 4·5·6·8 모든 크기의 정답 예시를 파싱해 검증했습니다. **4개 모두 유효**.

### ✅ 해가 없는 경우 처리
N=2·3은 선택지에 없지만, 탐색 실패 시 "모든 탐색을 마쳤거나 정답이 없습니다" 메시지가 있습니다.

## B. 시각화 정합성 — 상 (수정 없음)

- **`try` / `place` / `prune` / `backtrack` 4단계를 구분해 yield** 합니다. 백트래킹을 가르칠 때
  꼭 필요한 구분이 그대로 화면에 반영됩니다.
- D3 탐색 트리와 체스판이 매 단계 동기화되고, 카메라 3모드(노드 추적 / 전체 맞춤 / 자유 이동)를
  제공합니다.
- 8×8 선택지 라벨이 "8 x 8 (트리가 거대해짐)"으로 되어 있어 학생에게 미리 경고합니다. 좋은 배려입니다.

---

## C. 안정성 — 상 (수정 없음)

### ✅ 제너레이터로 양보해 화면이 멈추지 않음
```javascript
// 제너레이터를 사용하여 브라우저가 멈추지 않게 매 단계마다 양보(yield)합니다.
function* dfsGenerator(row, currentPath, tempState) { ... }
```
주석과 구현이 일치합니다. (3번 8-퍼즐은 같은 취지의 주석이 있었지만 실제로는 동기 루프였습니다.)

실측 — N=8, 최고 속도:

| 항목 | 결과 |
|---|---|
| 스텝당 평균 렌더 | 2.88ms |
| 스텝당 최악 | 32ms |
| 콘솔 에러 | 0건 |

N=8 전체 재생은 1,858단계라 최고 속도에서도 수 초가 걸리지만, **매 단계 양보하므로 화면이
얼지 않고 일시정지·단계 진행도 계속 받습니다.** 문제없습니다.

## D. 접근성·반응형 — 중 → 상

### 🔴 D-1. 모바일에서 상태 메시지가 잘림 (수정)

`#statusText`가 `h-10`(40px) **고정 높이**인데, 375px에서 주요 메시지가 두 줄(44px)이 되어
잘리고 있었습니다.

| 메시지 | 상자 | 내용 | 잘림 |
|---|---|---|---|
| 🏁 탐색 종료! 모든 탐색을 마쳤거나… | 40px | 40px | **잘림** |
| 🎉 탐색 성공! N-Queen 완벽한 배치를… | 40px | 40px | **잘림** |

탐색 성공 메시지가 잘리는 것은 학습 흐름상 나쁩니다.

### 🔴 D-2. 상태창 글자 14px (수정)
`text-sm md:text-base` 라 모바일에서 14px였습니다. CLAUDE.md 최소 규격(`text-base`) 위반.

**수정**: `h-10` → `min-h-10 py-1.5`, `text-sm md:text-base` → `text-base leading-snug break-keep`.
초기 마크업과 `updateStatusText()` 양쪽 모두 적용.

검증: 상자 58px / 내용 44px / **잘림 없음**, 폰트 16px.

### ✅ 이미 잘 되어 있던 점
- **`touchstart`가 이미 구현**되어 있고 `preventDefault()`로 클릭 중복까지 막습니다.
- **`aria-label` 64개** — 체스판 각 칸에 "N행 M열"이 붙어 있습니다. 검증한 파일 중 접근성 배려가
  가장 좋습니다.
- 375px 가로 넘침 없음, `<pre>`에 `overflow-x: auto` 적용.
- `#statusText`는 flex 컨테이너지만 메시지를 `<span>` 하나로 감싸 넣으므로
  2번 파일에서 발견한 문장 토막남 문제가 없습니다.

## 남긴 항목 (미수정)

- **8×8 판의 셀이 375px에서 34×34px** — 권장 44px 미달이지만, 8칸을 375px에 넣으면
  구조적으로 44px 확보가 불가능합니다(8×44=352 + 간격 > 375). 모바일에서 4×4·5×5를
