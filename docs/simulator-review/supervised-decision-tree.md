## A. 개념 정확성 — 상 (수정 없음)

### ✅ 지니 불순도가 정확
| 데이터 | 계산값 | 이론값 |
|---|---|---|
| 순수(1클래스) | 0 | 0 |
| 반반(2클래스) | 0.5 | 0.5 |
| 3등분(3클래스) | 0.6667 | 2/3 |

### ✅ 분할 선택이 실제로 최적
독립 작성한 브루트포스(모든 후보 임계값 전수 탐색)와 루트 분할의 **가중 지니를 대조**:

| 시행 | 불일치 | 최대 차이 |
|---|---|---|
| 70회 (60점, 3클래스, 무작위) | **0** | **0** |

`if (sorted[i].cls === sorted[i+1].cls) continue;` 로 후보를 줄이는 최적화가 들어 있는데,
**최적해를 놓치지 않음**을 실측으로 확인했습니다.

### ✅ 범주형 트리도 정확
- 가중 지니 `probL·giniL + probR·giniR` ✅
- 학습 데이터 6건 재예측 **오분류 0**
- `'아니오' 분기에서는 해당 특징을 소진시키지 않음` — 다중 카테고리 특징을 다시 물을 수 있게 한
  처리로, 원-vs-나머지 방식 범주형 분할에서 올바릅니다. (코드에 의도가 주석으로 남아 있음)
- 종료 조건: 순수 노드 / 특징 소진 / 깊이 5 / 개선 없음 — 모두 타당

## B. 시각화 정합성 — 상 (수정 없음)

- **범주형 트리**(질문-예/아니오 구조)와 **2D 결정경계**(축 평행 분할) 두 가지를 모두 제공합니다.
  "의사결정 트리는 공간을 사각형으로 쪼갠다"는 직관과 "질문을 이어 간다"는 직관을
  각각 다른 화면으로 다루는 좋은 구성입니다.
- 노드 라벨에 `(불순도: 0.375)` 처럼 지니값을 함께 표시해, 분할이 왜 그 순서로 일어났는지
  학생이 확인할 수 있습니다.
- 깊이·최소 리프 크기 슬라이더가 있어 **과적합을 직접 만들어 볼 수 있습니다**(깊이 1~15).

## C. 안정성 — 중상 → 상

### 🟡 C-1. 자식이 `null`이 되어 그리기가 터지는 경로 (수정)

같은 좌표에 클래스가 다른 점이 겹쳐 있고 `minLeaf = 0` 이면, 분할 한쪽이 비어
자식이 `null`이 됩니다. 그 트리로 결정경계를 그리면:

```
Cannot read properties of null (reading 'isLeaf')
```

> 실제로 UI 슬라이더의 `min`이 1이라 **현재 화면 조작만으로는 도달할 수 없습니다.**
> 다만 코드 상 방어가 없어 잠재적이므로, 분할 후보에서 한쪽이 비면 건너뛰도록 했습니다.

수정 후 동일 조건에서 `null` 자식 **0건**, 그리기 예외 없음.

### ✅ 그 밖의 경계 케이스 — 전부 정상
| 케이스 | 결과 |
|---|---|
| 데이터 0개 | `null` 반환, 예외 없음 |
| 점 1개 | 리프 반환 |
| 전부 같은 클래스 | 즉시 리프(지니 0) |
| 무작위 200점 / 깊이 10 | 정상, 무한 재귀 없음 |
| 범주형 모순 데이터(같은 특징·다른 클래스) | 예외 없이 리프 반환 |

- 콘솔 에러 0건.

### 참고 (미수정)
범주형 쪽 `bestGini === calcGiniCat(data)` 는 부동소수점을 `===` 로 비교합니다.
허용오차를 쓰는 편이 안전하지만, 깊이 5 상한과 데이터 축소가 있어 무한 재귀로는 이어지지 않습니다.
