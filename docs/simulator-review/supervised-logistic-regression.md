## A. 개념 정확성 — 상 (수정 없음)

### ✅ 기울기가 정확
```javascript
dw += (pred - p.y) * p.x;   db += (pred - p.y);
dw = dw / N;   db = db / N;
```
이진 교차엔트로피의 편미분 `(σ(z) − y)·x` 와 정확히 일치합니다.
(선형회귀의 MSE와 달리 계수 2가 없는 것이 맞습니다.)

### ✅ 시그모이드가 정확하고 오버플로 방어까지 되어 있음
| z | 구현값 | 참값 |
|---|---|---|
| −25 | 0.000001 | ~0 (클램프) |
| −2 | 0.119203 | 0.119203 |
| 0 | 0.5 | 0.5 |
| 2 | 0.880797 | 0.880797 |
| 25 | 0.999999 | ~1 (클램프) |

`|z| > 20`에서만 클램프하며, 그 구간의 실제 오차는 10⁻⁶ 수준이라 무해합니다.

### ✅ 결정 경계가 실제 정답과 일치
| 데이터 | 학습된 경계 | 참 경계 | 정확도 |
|---|---|---|---|
| 겹치는 두 그룹(시그모이드 생성) | x = 4.78 | 5.0 | 0.95 |
| 완전 분리 가능 | x = 4.86 | 5.0 | 1.00 |
| 역방향 분류(라벨 반대) | x = 5.07 | 5.0 | 0.98 |

**역방향도 정확히 학습**합니다(w가 음수로 수렴). "가중치 부호가 방향을 결정한다"를 보여 줄 수 있습니다.

## B. 시각화 정합성 — 상 (수정 없음)

- `z = 2.02x − 9.83` 처럼 **원래 데이터 단위**로 역정규화해 표시합니다.
  검산: 경계 = 9.83 / 2.02 = 4.87 — 화면의 경계선 위치와 일치합니다.
- `P(y=1) = σ(z)` 를 별도로 병기해, z(선형 부분)와 σ(확률 변환)를 분리해 보여 줍니다.
  로지스틱 회귀의 구조를 정확히 반영한 표시입니다.
- 학습 완료 후 예측 패널이 활성화되어 임의의 x에 대한 확률을 확인할 수 있습니다.

## C. 안정성 — 상 (수정 없음)

### ✅ 분리 가능 데이터의 발산을 안전하게 처리
로지스틱 회귀는 데이터가 **완전히 분리 가능하면 최대가능도 추정치가 무한대**로 발산합니다.
(학생이 두 그룹을 확실히 갈라 찍으면 바로 이 상황이 됩니다.)

실측: 30만 회를 돌려도 기울기 수렴 판정에 걸리지 않고 w가 계속 커졌습니다(w = 114).

그런데 학습 루프에 `this.model.epoch > 3000` 상한이 있어 **무한 루프가 되지 않습니다.**
상한에 도달한 시점의 상태를 확인했습니다:

| 항목 | 값 |
|---|---|
| 에포크 | 3,001 |
| w, b | 23.67, −11.81 |
| 경계 | x = 4.86 (참값 5.0) |
| **정확도** | **1.000** |

이미 완벽히 분류된 상태에서 멈추므로 "경계선 탐색 완료" 표시가 정직합니다. 문제없습니다.

### ✅ 그 밖
- 클래스가 하나뿐인 데이터 → 예외·발산 없이 종료(w, b 유한).
- 콘솔 에러 0건.

## 추가 기능 (2026-08-03, 사용자 승인 후)

### 학습률(α) 슬라이더 추가

경사하강 단원의 핵심 개념인 **"학습률이 크면 발산하고 작으면 느리다"** 를 학생이 직접
실험할 수 없던 문제를 해결했습니다. 기존에는 학습률이 코드에 고정되어 있었습니다.

- 로그 스케일 슬라이더 + 현재 값 표시 + 구간별 안내 문구(색상 구분)
- 값이 무한대로 튀면 **발산으로 감지해 안전하게 멈추고** 이유를 알려 줍니다.
  발산은 실패가 아니라 관찰 대상이므로 버튼을 다시 누를 수 있게 열어 둡니다.

| 슬라이더 | 학습률 | 결과 | 경계 | 정확도 | 안내 문구 |
|---|---|---|---|---|---|
| 0 | 0.01 | 상한 | 4.11 | 0.867 | 너무 작습니다 |
| 25 | 0.1 | 상한 | 5.30 | 0.883 | 적당합니다 |
| 50 (기본) | 1.0 | 상한 | 5.53 | 0.883 | 적당합니다 |
| 75 | 10 | 수렴 (383) | 5.54 | 0.883 | 다소 큽니다 |
| 100 | 100 | 상한 | 4.23 | 0.867 | 너무 큽니다 |

(참 경계 5.0)

**로지스틱은 발산하지 않습니다.** 시그모이드가 포화하면서 기울기를 눌러 주기 때문에
선형회귀처럼 값이 무한대로 튀지 않습니다. 대신 경계선이 크게 흔들려 정확도가 떨어집니다
(0.883 → 0.867). 안내 문구를 이 실제 동작에 맞춰 썼습니다.

그래서 선형회귀보다 큰 학습률을 견디며, 슬라이더 범위도 0.01 ~ 100 으로 넓게 잡았습니다.

**핵심**: 수렴한 모든 경우에서 결과가 동일합니다. 학습률은 **정확도가 아니라 속도와 안정성**을
바꾼다는 점이 수치로 드러납니다.
