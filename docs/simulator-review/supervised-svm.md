## A. 개념 정확성 — 중상 → 상

### ✅ Pegasos 구현이 정석
알고리즘은 **Pegasos**(SVM 원문제 확률적 부분경사법)로, 교과서 그대로입니다.

| 요소 | 구현 | 판정 |
|---|---|---|
| 학습률 | `eta = 1/(λt)` | ✅ |
| 마진 위반 시 | `w = (1−ηλ)w + η·y·x` | ✅ |
| 마진 충족 시 | `w = (1−ηλ)w` | ✅ |
| 사영 | `‖w‖ ≤ 1/√λ` | ✅ |
| C ↔ λ | `λ = 1/(C·N)` | ✅ |
| 에포크마다 셔플 | **Fisher-Yates** | ✅ (5번 파일의 편향 셔플과 달리 제대로 됨) |

### ✅ C가 마진 폭을 올바른 방향으로 바꿈
SVM 단원의 핵심입니다. 실측:

| C | ‖w‖ | 마진 폭 (2/‖w‖) | 정확도 |
|---|---|---|---|
| 0.1 | 1.748 | **1.144** (넓음 = 소프트) | 1.000 |
| 1 | 4.087 | 0.489 | 1.000 |
| 10 | 6.209 | 0.322 | 1.000 |
| 100 | 10.821 | **0.185** (좁음 = 하드) | 1.000 |

**C ↑ → 마진 ↓** 가 정확히 나타납니다. 겹치는 데이터(비분리)에서도 발산 없이 정확도 0.767로 안정.

### 🔴 A-1. 오분류된 점이 서포트 벡터에서 빠져 있었음 (수정)

```javascript
if (margin <= 1.05 && margin >= -0.05) this.supportVectors.push(p.original);
```

서포트 벡터는 `y·f(x) ≤ 1` 인 점, 즉 **마진 경계 위 또는 그 안쪽**의 점입니다.
그런데 하한 `margin >= -0.05` 때문에 **경계 반대편으로 깊이 넘어간 오분류 점이 제외**되고
있었습니다. 소프트 마진 SVM에서 그런 점들은 벌점을 무는 대표적인 서포트 벡터(α = C)입니다.

재현: `f(x) = −4x₁ − 4x₂ + 4` 에 대해 margin = −2.8 인 오분류 점이 서포트 벡터 목록에서 빠짐.

**수정**: 하한을 제거해 `margin <= 1.05` 만 판정.
검증 결과 margin −2.8 점이 **서포트 벡터로 포함**되고, 마진 밖 정상 점(margin 3.2)은 제외됩니다.

> 참고: C가 작으면 마진이 넓어 대부분의 점이 서포트 벡터가 됩니다(C=0.1에서 40/40).
> 이는 소프트 마진 SVM의 실제 성질이라 정상입니다. "소수의 점만 경계를 결정한다"는
> 직관은 C가 클 때 드러나며, 실측에서 C=10일 때 4/40으로 잘 나타납니다.

## B. 시각화 정합성 — 중상 → 상

### 🔴 B-1. C 슬라이더의 표시값과 실제값이 어긋남 (수정)

C는 `Math.pow(10, (sliderVal − 50) / 20)` 로그 스케일인데, 학습부에서 `C < 0.01`을 `0.01`로
잘라냅니다. 슬라이더 min이 0이었으므로:

- **슬라이더 0~10 구간이 전부 같은 C(0.01)로 동작하는 먹통 구간**
- 그 구간의 표시값은 `toFixed(2)` 때문에 **"0.00"** — SVM에서 의미가 없는 값이고 실제 사용값과도 다름

**수정**:
- 슬라이더 `min="0"` → `min="10"` (C = 0.01에 정확히 대응, 먹통 구간 제거)
- 라벨을 `actualC < 1 ? toFixed(3) : toFixed(1)` 로 — 로그 스케일에서 작은 쪽 자릿수가 살아남

검증:

| 슬라이더 | 표시 | 실제 C |
|---|---|---|
| 10 | 0.010 | 0.01 |
| 25 | 0.056 | 0.0562 |
| 50 | 1.0 | 1 |
| 75 | 17.8 | 17.78 |
| 100 | 316.2 | 316.23 |

### ✅ 좋은 점
- 결정 경계 + 양쪽 마진선(점선)을 함께 그리고, 마진 폭을 `1/‖w‖`로 정확히 계산합니다.
- "소프트 마진 (벌점 낮음 😌) / 표준 / 하드 마진 (벌점 높음 😡)" 라벨이 C에 따라 바뀌어
  추상적인 C 값에 의미를 붙여 줍니다.

## C. 안정성 — 상 (수정 없음)

- Pegasos 사영(`‖w‖ ≤ 1/√λ`)이 있어 **큰 C에서도 w가 발산하지 않습니다.**
  (C=100일 때 초기 eta가 매우 커지지만 사영이 잡아 줍니다. 실측 ‖w‖ = 10.8로 유한)
- 겹치는 데이터, C 극단값(0.01 / 316) 전부 유한한 해 반환.
- `abortFlag`로 학습 중단이 가능하고, 애니메이션이 `async`라 화면이 멈추지 않습니다.
