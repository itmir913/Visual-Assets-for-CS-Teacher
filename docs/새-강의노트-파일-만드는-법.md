# 새 강의노트 파일 만드는 법 (Write 도구 쓰지 말 것)

Write로 2,000행짜리를 한 번에 쓰면 **느리고, 중간에 끊기면 전부 날아간다.**
head의 CSS 블록만 200행이고 파일마다 거의 같으므로 매번 새로 쓰는 것은 낭비다.

## 절차

1. **복사해서 껍데기 만들기** — 출력 0행
   ```bash
   cd 데이터과학
   cp 2-2-2.데이터-시각화.html 새파일.html
   python - <<'PY'
   import io
   p = "새파일.html"
   s = io.open(p, encoding="utf-8").read()
   i, j = s.index("<main "), s.index("</main>")
   s = s[:i] + s[i:s.index(">", i)+1] + "\n\n    <!-- 섹션은 여기에 하나씩 추가한다 -->\n\n" + s[j:]
   io.open(p, "w", encoding="utf-8", newline="\n").write(s)
   PY
   ```
   2,000행 → 360행. CSS·hero·nav·footer·퀴즈 스크립트가 전부 남는다.

2. **정체성 부분만 교체** — title / hero 아이콘·제목·부제 / 학습 목표 / nav 아이콘·제목·링크 / footer

3. **여기서 커밋한다.** 이 시점부터 중단돼도 껍데기는 안전하다.

4. **섹션을 하나씩 Edit로 붙인다.** `<!-- 섹션은 여기에 하나씩 추가한다 -->`를
   `새 섹션 + 같은 주석`으로 바꾸면 계속 이어 붙일 수 있다.
   섹션 2~3개마다 커밋하면 중단 시 그 지점부터 재개하면 된다.

5. 다 붙이면 주석을 지우고 검증 → 커밋.

## 덤
- `table-prose`, `ext-link`, `chart-svg` 같은 CSS 규칙을 빠뜨릴 일이 없다.
- 퀴즈 `checkAnswer`/`showToast` 스크립트도 그대로 온다.
