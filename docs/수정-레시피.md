# 알려진 수정 레시피

한 번 풀어 본 문제의 해법을 적어 둔다. 같은 증상을 다시 만났을 때 처음부터
다시 파헤치지 않으려는 것이다. **규칙이 아니라 해법이므로** 상황이 다르면 그대로 쓰지 않는다.

## 터치 드래그가 안 되는 격자·캔버스

`mousedown`/`mouseenter`만 바인딩하면 태블릿에서 드래그 조작이 되지 않는다.
포인터 이벤트로 바꾸되, **암묵 캡처를 반드시 해제해야 한다.**

```javascript
cell.addEventListener('pointerdown', onDown);
cell.addEventListener('pointerenter', onEnter);
document.onpointerup = document.onpointercancel = () => isDrawing = false;

function onDown(e) {
    // 터치는 첫 요소에 포인터가 암묵 캡처되어 이웃의 pointerenter가 발생하지 않는다 → 반드시 해제
    if (e.pointerId !== undefined && e.currentTarget.hasPointerCapture?.(e.pointerId)) {
        e.currentTarget.releasePointerCapture(e.pointerId);
    }
    ...
}
```

컨테이너에 `touch-action: none;`을 함께 지정해 드래그 중 페이지 스크롤을 막는다.

## 375px에서 섹션이 몇 화면인지 재기

브라우저 콘솔에서. **`clientWidth`가 정말 375인지 함께 찍어 확인한다** —
뷰포트가 바뀐 채로 재면 값이 전부 틀린다.

```javascript
[...document.querySelectorAll('main > section')].map(s => ({
    id: s.id, 화면수: +(s.getBoundingClientRect().height / 812).toFixed(1)
}))
```

재는 대상은 **소스가 아니라 `dist/`다.** 소스는 CDN 판이라 배포본과 다를 수 있다.

```bash
npm run build:one -- "<파일>"
```
