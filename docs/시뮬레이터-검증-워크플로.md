# 시뮬레이터 검증 워크플로

`인공지능기초/simulator/` 18개를 **한 번에 하나씩** 검증하는 절차다.
진행 현황과 공통 이슈는 [`simulator-review/_공통이슈.md`](simulator-review/_공통이슈.md),
파일별 리포트는 `simulator-review/<파일명>.md`.

- 학생 수준: **고등학교 「인공지능 기초」** (수식은 개념 수준, 코드 이해는 선택적)
- 방법: 핵심 알고리즘 함수 + 디자인 부분만 정독 → 브라우저 실행 → 리포트 → 수정 → 커밋
- 파일당 730~1,630줄이므로 **전체 정독 금지.** grep으로 구조를 스캔한 뒤
  핵심 알고리즘 함수와 레이아웃·반응형 부분만 읽는다.

## 루브릭 4축

| 축 | 확인 내용 |
|---|---|
| A. 개념 정확성 | 구현이 표준 정의와 일치하는가 (자료구조, 갱신식, 최적성 보장 조건) |
| B. 시각화 정합성 | 화면에 보이는 것이 내부 상태와 같은가, 오개념을 심지 않는가 |
| **C. 안정성** | 콘솔 에러, 경계 케이스(빈 데이터·극단값·봉쇄), 무한 루프 |
| **D. 접근성·반응형** | 터치 조작, 375px 레이아웃, 터치 타깃 크기, 키보드·색상 접근성 |

**C와 D가 최우선이다.**

## 감점하지 않는 항목

사용자가 명시적으로 제외한 것들이다.

- **형성평가·퀴즈 부재** — 문제 아님. **퀴즈 추가를 제안하지 말 것.**
- **CDN 전면 의존** — 의도된 설계.
- **조작 UI의 `text-sm`** — 시뮬레이터는 최소 글자 크기 규칙의 범위 밖이다.

```
탐색      bfs-dfs → river-crossing → tower-of-hanoi → heuristic
          → 8-puzzle → n-queen → wumpus-world

비지도    k-means

딥러닝/CV deep-learning → computer-vision-ml5
```
