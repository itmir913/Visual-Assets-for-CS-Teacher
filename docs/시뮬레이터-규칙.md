# 시뮬레이터 규칙

`simulator/`의 페이지와 강의노트에 내장한 시뮬레이터를 만들고 고칠 때 지킬 규칙이다. 규칙의 정본은 [`CLAUDE.md`](../CLAUDE.md)이고 이 문서는 그 가운데 시뮬레이터 영역이다.
화면의 글자 크기 · 문체는 [강의노트 작성 규칙](강의노트-작성-규칙.md)을 함께 따른다.

## 만들기와 검사

판례 → [cases/시뮬레이터.md](cases/시뮬레이터.md)

- **조작이 간단하면 강의노트 안에 내장하고, 복잡하면 `simulator/<ai|cs>/`에 별도 페이지로 만든다.**
  별도 페이지는 대단원이 끝날 때 사용자에게 보고하고 나서 만든다.
- **여러 교과가 쓰면 파일을 복제하지 말고 링크를 여러 번 건다.** 교과를 넘어 걸 때는 글로 보여 줄 수 없는 것을
  상상하라고 시키는 곳에만 건다. 방금 갈라 놓은 개념을 도로 섞는 링크는 넣지 않는다.
- **캔버스는 `window.fitCanvas`로 잰다.** 배치 치수는 `rem`이 아니라 px로, 캔버스 배치는 화면 폭이 아니라 칸 폭으로 정한다.
- **시뮬레이터 폴더와 파일 이름은 영문이다.**
- **검사의 정답은 페이지 코드와 상관없는 방법으로 따로 구한다.** 스텁을 빈 함수로 두지 않는다 → [수정 레시피](수정-레시피.md) 「시뮬레이터 검사를 쓸 때」.
- **화면 문장에 값을 끼우면 조사는 `src/entries/_lib/josa.js`로 붙인다.** 조사를 손으로 박지 않는다.
- **가르치려는 장면을 만드는 버튼은 그 장면이 나오는 상태에서 시작한다.** 알림은 토스트가 아니라 상태 줄에 둔다.
- **JS가 `className`을 통째로 덮어쓰지 않는다.** 상태 클래스만 `classList`로 켜고 끈다.
- **시뮬레이터 페이지에 `<style>` · 마크업 `style=""` · 섬 밖 임의 색 클래스를 두지 않는다**(`check -- inline-css`). 실행 중에 계산한 값만 스크립트가 `style`로 준다. 공통 틀은 `_sim-cs.css` · `_sim-ai.css`, 그 편만의 틀은 `src/styles/sim-ai/<편>.css`의 `:where(.sim-<편>)` 아래에 둔다(새 편은 `simulator.css`에 import 한 줄).
- **UX를 바꿀 때는 한 쪽을 먼저 고쳐 스크린샷으로 확인받고 나서 넓힌다.**
- **`simulator/index.html`을 손으로 고치지 않는다.** 루트 `index.html`을 고치고 `npm run gen:sim-index`를 돌린다.
  새 시뮬레이터는 루트에 링크를 걸거나, 미룰 까닭과 함께 `sim-index.mjs`의 `UNLINKED_OK`에 적는다.

## 전체 화면

판례 → [cases/시뮬레이터.md](cases/시뮬레이터.md)

- **전체 화면에서 모든 조작을 누를 수 있어야 한다.** `fs-stage`는 그림 · 재생 줄 · 조작을 감싸고,
  읽는 카드는 무대 밖에 둔다. **탭 줄만은 전체 화면 밖에 남긴다.**
- **조작에 `fs-hide`를 주지 않는다.** 세로가 빠듯하면 설명을 줄인다.
- **넓은 화면에서 폭을 쓴다.** 등록부의 `shape`에 적는다. 규약은 `src/styles/simulator.css`의 전체 화면 주석.
- **누를 때마다 화면이 흔들리지 않아야 한다.** 길이가 바뀌는 설명은 높이를 못박고, 연산을 눌러도 재생하지 않는다.
  높이를 JS로 재서 맞추지 않는다.
- **CSS는 `:fullscreen`이 아니라 `fs-on` 클래스를 보게 한다.**
- **ai 시뮬레이터에 `fs-cols`를 옮길 때는 스크린샷으로 먼저 확인받는다.**

## 용어와 이름

판례 → [cases/시뮬레이터.md](cases/시뮬레이터.md)

- **정식 교과 용어를 풀어 쓰지 않는다** — 탐색 트리 · 노드 · 트리 · 순차 탐색 · 순회. 비용은 「값」이라 적지 않는다.
  화면의 «순서»는 순서, 조작하는 것은 버튼, 한 번의 실행은 회차. 정한 용어는 `terms.mjs`의 `SIM_TERMS`에 넣는다.
- **낱말이 이름 자리(절 제목 · nav · 학습 목표)에도 있으면 파일을 통째로 바꾸거나 그대로 둔다.**
  절 제목을 바꾸면 `data-src`가 가리키는 코드 파일 이름까지 바꾼다.
- **누르는 것의 이름은 한자어로 쓴다**(삭제 · 제거 · 해제 · 선택 · 추가 · 추출 · 분할 · 교체 · 이동 · 조정).
  순우리말은 `verbs.mjs`의 닫힌 허용 목록에 있는 것만 쓰고, 굳은 말인지 판단하지 않는다.
  - 자료가 없어지면 삭제, 목록에서만 빠지면 제거, 설정을 풀면 해제.
  - 이름은 변경, 밀어내고 넣으면 교체, 값을 옮기면 조정.
  - 문장의 일반 동사는 그대로 둔다. 「펴다 · 펼치다」는 문장에서도 쓰지 않는다. <!-- verbs: 예시 -->
  - 목록에는 활용형을 손으로 적고, `-ㄹ`/`-ㅂ` 꼴부터 적는다.
- **시뮬레이터 화면도 강의노트와 같은 문체 검사를 받는다.** 이모지는 예외다.
