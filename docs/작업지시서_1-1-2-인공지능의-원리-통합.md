# 새 세션 프롬프트 — 지능 에이전트·센서 3개 파일을 「인공지능의 원리」 한 개로 통합

새 세션(Sonnet 가능)에 **아래 「프롬프트」 블록 전체를 그대로 붙여넣으세요.**

---

## 배경 (사람이 읽는 부분)

`1-1-2`·`1-1-3`·`1-1-4` 세 파일은 2015 개정 교육과정 내용이라 2022 개정 「인공지능 기초」
교과서에 대응 소단원이 없다. 그래서 지금은 index.html 에서 `details` 로 접힌 "참고자료"
신세이고, 학생은 접힌 것을 열지 않는다.

그런데 **다른 출판사 교과서는 대단원 Ⅰ의 중단원 1을 이렇게 구성한다.**

```
1. 인공지능의 개념과 원리
   1-1 인공지능의 개념과 특성
   1-2 인공지능의 원리
```

즉 이 내용에는 **「인공지능의 원리」라는 정식 자리가 있다.** 셋을 합쳐 `1-1-2. 인공지능의 원리`
로 승격하면 참고자료 딱지를 뗄 수 있고, 내용 중복(에이전트 3요소 = 센서·지능·액추에이터가
1-1-2 와 1-1-4 에 두 번 나옴)도 해소된다.

**가장 중요한 목적**은 마지막 절이다. 현재 강의노트는 "인식 → 판단 → 행동"을 배운 뒤
1-2-1 에서 갑자기 탐색으로 넘어가는데, 그 사이에 다리가 없다. 학생들이 실제로
"8-퍼즐을 왜 배우죠?"라고 묻는 것과 같은 종류의 간극이다. **'판단'을 실제로 하는 두 가지
방법이 탐색과 지식 표현·추론이라는 것을 명시하는 절**을 반드시 넣어야 한다.

## 최종 구성 (섹션 번호와 제목을 이대로)

```
1-1-2. 인공지능의 원리
 ❶ 인공지능이 일하는 순서 — 인식 → 판단 → 행동
 ❷ 인식(Perception): 센서와 A/D 변환
 ❸ 판단(Reasoning): 지능 에이전트
 ❹ 행동(Action): 액추에이터
 ❺ 지능 에이전트는 어디에 쓰이나
 ❻ 그래서 '판단'은 실제로 어떻게 하는가?   ← 신규 작성, 이 절이 핵심
 ❼ 확인 퀴즈
```

### 중복 제거 (반드시)

1-1-2 의 「❷ 에이전트는 어떻게 세상을 이해하고 움직일까 — ① 센서 ② 지능 ③ 액추에이터」와
1-1-4 전체는 **같은 이야기를 두 번 한다.** ❷·❹ 로 흡수하고 중복 서술은 지운다.
1-1-4 의 「코드로 보는 인식의 흐름」, 「AI와 함께 똑똑 정리하기」 절은 그대로 살린다.

### ❻ 절 상세 — 이 절이 이번 통합의 진짜 목적이다

현재 강의노트는 "인식 → 판단 → 행동"을 배운 뒤 1-2-1 에서 갑자기 탐색으로 넘어간다.
그 다리를 여기서 놓는다. 다음 내용을 반드시 포함할 것.

- '판단'이란 **여러 선택지 중 하나를 고르는 일**이라는 정의
- 고르는 방법이 크게 두 갈래라는 것:
  - **방법 1. 탐색** — 가능한 경우를 상태 공간 트리로 펼쳐 놓고 목표로 가는 길을 찾는다.
    → `1-2-1.탐색과-문제-해결.html`, `1-2-2.지능적-탐색.html`, `1-2-3.탐색을-활용한-문제-해결.html`
  - **방법 2. 지식 표현과 추론** — 아는 사실을 규칙·의미망·프레임으로 적어 두고 새 사실을 이끌어낸다.
    → `1-2-4.지식의-표현과-논리-추론.html`
  - (그리고 2단원의 **기계학습**은 규칙을 사람이 적어 주는 대신 데이터에서 스스로 찾는 세 번째
    갈래라는 것을 한 문단으로 예고 → `2-1-1.기계학습과-문제-해결-과정.html`)
- 로봇 청소기 하나를 예로 들어 세 갈래를 대조하면 좋다.
  (어느 방으로 갈지 = 탐색 / "카펫 위에서는 물걸레를 올린다" = 규칙 기반 추론 /
   먼지 사진을 보고 종류를 알아내기 = 기계학습)
- 각 파일로 가는 **링크 카드**를 넣는다. 마크업은 다른 강의노트의 실습 링크 카드를 복사해 쓴다.

## 절대 규칙 (어기면 반려)

- **최소 글자 크기는 `text-base`.** `text-sm`·`text-xs`·`text-[13px]` 등 금지. SVG `font-size` 16 미만 금지.
- **모든 `<table>` 은 `overflow-x-auto` 컨테이너 + `min-w-[Npx]`** (열당 120px 기준).
- **375px 에서 `documentElement.scrollWidth - clientWidth == 0`.**
- **`<title>` 은 파일명과 일치**시킨다 → `<title>인공지능의 원리</title>`.
  상단 sticky nav 제목과 푸터 문구도 "인공지능의 원리"로 맞춘다.
- hero 배지 텍스트는 `인공지능 기초` 로 고정한다. 단원·차시 번호를 넣지 않는다.
- `<style>` 에 아래 규칙이 이미 있는지 확인하고 없으면 넣는다 (전 파일 공통).
  ```css
  code, kbd, samp, pre,
  body .font-mono {
      font-family: ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono",
      "Courier New", "Pretendard Variable", Pretendard, "Apple SD Gothic Neo",
      "Malgun Gothic", monospace;
  }
  ```
- **트리·분기 도형을 그린다면 div 조합 대신 SVG 를 쓴다.** div 로 그리면 가로 연결선이
  빠지거나 어긋나기 쉽다 (1-2-1 에서 실제로 발생한 결함).
- **커밋 메시지에 AI 협업 표시 문구 금지** (`Co-Authored-By`, `Generated with`, 🤖 등 일체).
  한국어 한 줄 제목 + 필요시 항목 본문. `master` 에 직접 커밋.
- `git add .` / `git add -A` 금지. `git commit -- <정확한 경로>` 또는 `git add -- <경로>` 만 쓴다.
