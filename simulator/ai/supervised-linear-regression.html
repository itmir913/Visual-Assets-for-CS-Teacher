선형 회귀 (Linear Regression) 시뮬레이터

데이터를 가장 잘 설명하는 단 하나의 '직선'은 무엇일까요? 오차를 줄여나가며 최적의 선을 찾는 선형 회귀의 원리를 시각적으로 체험해 봅니다.

선형 회귀
도입 개념설명 시뮬레이터
Core Mechanism

선형 회귀는 어떻게 최적의 선을 찾을까요?

선형 회귀는 데이터와 직선 사이의 '오차'를 최소화하는 방향으로 선을 조금씩 수정합니다.

Step 1

데이터 표시

수집한 데이터들을 2차원 그래프 위에 점으로 찍어 분포와 패턴을 확인합니다.

Step 2

초기 직선 생성

데이터의 경향을 추측하여 임의의 위치와 기울기를 가진 선을 무작위로 하나 긋습니다.

Step 3

오차 계산

현재 직선과 실제 데이터 점들 사이의 수직 거리(오차)를 구한 뒤, 제곱해서 평균 낸 값을 오차의 크기로 삼습니다. 이 값을 평균제곱오차(MSE)라고 합니다.

Step 4

직선 수정 (학습)

계산된 오차를 줄이는 방향으로 직선의 기울기와 높이를 조금씩 이동시킵니다.

핵심 정리

  • 선형 회귀는 데이터를 가장 잘 설명하는 직선을 찾는 방법입니다.
  • 기계가 '학습'한다는 것은 오차를 줄이도록 직선을 계속 수정하는 과정을 의미합니다.

주의할 점 (오개념 방지)

  • 선형 회귀가 항상 완벽하게 모든 점을 지나는 선을 찾는 것은 아닙니다.
  • 현실의 데이터는 직선 관계가 아닐 수도 있습니다 (곡선 형태 등).
  • 절편(b)은 직선의 높이를 맞춰 주는 숫자입니다. 예제에는 x가 0인 자료가 없으므로, 절편을 'x가 0일 때의 기본값'으로 읽지 않습니다.
