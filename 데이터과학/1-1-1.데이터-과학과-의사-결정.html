데이터를 모으기만 하면 저절로 답이 나올까?

현대 사회는 모든 것이 데이터와 연결되어 있어 데이터를 중심으로 움직입니다. 개인 수준의 문제부터 전 지구적 수준의 문제까지 데이터를 이용해 본질을 파악하고 해결합니다.

데이터 과학 (data science)

대량의 데이터를 다양하게 분석하여 정보와 지식을 찾아내는 학문입니다. 데이터에 숨겨진 패턴을 발견하고 예측하여, 이를 통한 합리적인 결정을 할 수 있습니다.

‘정보와 지식을 찾아낸다’는 게 무슨 뜻일까?

데이터를 아무리 많이 모아도 그것만으로는 아무 일도 일어나지 않습니다. 데이터 과학은 흩어진 기록(데이터)에서 의미(정보)를 읽어 내고, 다시 다음에 무엇을 할지(지식)로 이어 가는 일입니다. 학교 매점의 아이스크림 판매 기록으로 따라가 봅시다.

데이터 과학에 필요한 것들

데이터 과학은 한 분야의 지식만으로는 할 수 없습니다. 실제 세계의 문제는 단편적이지 않고 서로 다른 분야의 지식이 복잡하게 얽혀 있기 때문에, 여러 분야의 전문 지식이 융합되어 활용됩니다.

도메인 지식

상상력

도메인 지식(domain knowledge)이란 각 분야의 전문 지식을 말합니다. domain은 ‘영역 · 분야’라는 뜻입니다. 예를 들어 농작물 데이터를 분석하려면 농업에 대한 지식이 함께 있어야 데이터가 무엇을 뜻하는지 해석할 수 있습니다.

도메인 지식이 없으면 어떻게 될까?

데이터만 볼 줄 알고 그 분야를 모르면 숫자는 맞는데 해석이 틀리는 일이 생깁니다. 어떤 농장의 데이터를 분석했더니 이런 결과가 나왔다고 해 봅시다.

“물을 많이 준 밭일수록 수확량이 낮다.”

농업을 모르는 사람의 해석

“물이 수확량을 떨어뜨리는구나. 물을 줄이자.”

농업을 아는 사람의 해석

“원래 메마른 밭이라 물을 더 준 것이다. 수확량이 낮은 진짜 원인은 물이 아니라 땅이다.”

함께 움직인다고 해서 원인인 것은 아닙니다. 데이터는 ‘물’과 ‘수확량’이 함께 움직인다는 것까지만 보여 줍니다. 둘 중 무엇이 원인인지, 아니면 숨은 다른 원인(땅)이 있는지는 그 분야를 아는 사람이라야 가릴 수 있습니다. 데이터 과학에 도메인 지식이 필요한 이유가 이것입니다.

데이터 과학은 왜 지금 중요해졌을까?

다양한 형태의 데이터가 급속도로 증가하고, 데이터를 수집하고 처리하는 능력과 분석 능력이 크게 발전하면서 데이터 과학의 역할이 넓어졌습니다. 이제 데이터 과학은 산업의 문제뿐만 아니라 사회·경제적인 문제, 그리고 지속가능발전목표(SDGs)와 같은 전 지구적 차원의 문제까지 포함합니다.

실시간 교통 데이터를 분석해 최단 시간 이동 경로와 예상 도착 시간을 계산하는 개인의 영역부터, 환경 변화 데이터로 위험을 인식하고 원인을 파악해 선제적으로 대응하는 지속가능한 발전 분야까지 데이터가 있는 곳이라면 어디에서나 광범위하게 활용됩니다.

데이터 과학은 어디에 쓰일까?

내가 관심 있는 분야에도 데이터 과학이 들어와 있을까?

데이터 과학이 적용된 현대 사회의 모습입니다. 각 분야가 어떤 데이터를 모아 무엇을 해결하는지에 주목해 봅시다.

교육

학업 성적, 학습 패턴, 학습 태도 등의 데이터를 분석하여 맞춤형 교육 과정과 교육 방법을 제공합니다.

농업

토양, 기상, 작물 성장 등의 데이터를 분석하여 병충해를 예방하고 농작물의 생산량을 높입니다.

환경

환경 오염 및 기후 변화 데이터를 분석하여 환경 보호 정책이나 환경 개선 방안을 도출합니다.

금융

고객의 소비 패턴 및 추세 분석 결과를 활용하여 개인화된 금융 상품을 개발하고 금융 범죄 패턴을 파악합니다.

재난 · 안전

기상, 지진 감지 등의 데이터를 분석하여 재난의 위험을 사전에 예측하고 미리 대응 방안을 세웁니다.

에너지 최적화

스마트 그리드 시스템에서 수집되는 데이터를 분석하여 에너지를 효율적으로 관리합니다.

의료

환자의 의료 기록 데이터를 분석하여 진단, 치료 방법, 재발 가능성 등을 예측합니다.

유통 및 마케팅

고객의 구매 패턴, 위치 데이터를 분석하여 상품 추천과 마케팅에 활용합니다.

교통

실시간 교통 데이터를 분석하여 교통 체증 완화에 활용할 수 있습니다.

위에 나온 낯선 말 두 가지

스마트 그리드 (smart grid)

기존 전력망에 정보·통신 기술을 접목하여, 공급자와 수요자 간 양방향으로 실시간 정보를 교환함으로써 지능형 수요 관리, 신재생에너지 연계, 전기차 충전 등을 가능하게 하는 전력 인프라 시스템입니다. 쉽게 말해 전기가 얼마나 쓰이는지를 실시간으로 알려 주는 전력망이라, 데이터가 계속 쌓입니다.

지속가능발전목표(SDGs)

국제 연합(UN)에서 2030년까지 세계가 함께 실천해야 할 ‘미래 세대가 자신의 필요를 채울 수 있는 능력을 해치지 않으면서 현재 세대의 필요를 충족시키는’ 발전을 위한 목표로, 17개 목표와 169개의 세부 목표를 제시했습니다. 데이터 과학은 기후 변화, 빈곤 감소, 삶의 질 증진 등의 지속가능발전목표를 달성하기 위해 다양한 분야의 도메인 지식과 결합하여 발전하고 있습니다.

데이터 과학은 어떤 순서로 문제를 해결할까?

데이터를 구했다면 곧바로 결론을 내려도 될까?

우리 주변에서 일어나는 작은 문제부터 전 지구적인 큰 문제까지 데이터 과학은 다음 여섯 단계를 거쳐 해결합니다.

1

문제 정의하기

무엇을 알아내고 싶은지 분명히 정한다.

2

데이터 수집 및 특성 파악하기

문제 해결에 필요한 데이터를 모으고 살펴본다.

3

데이터 전처리하기

분석할 수 있는 형태로 데이터를 다듬는다.

4

탐색적 데이터 분석하기

데이터의 패턴과 관계를 찾아본다.

5

데이터 모델링하기

모델을 만들어 더 상세하게 확인한다.

6

결과 해석 및 공유하기

알아낸 것을 해석하고 다른 사람과 나눈다.

3·4·5단계의 말이 어렵다면

앞의 여섯 단계에서 3·4·5단계는 처음 듣는 말이 많습니다. 말뜻부터 풀어 봅시다.

전처리(前處理, preprocessing) — 앞 전, 처리할 처 · pre-(먼저) + processing(처리)

분석하기 전에 데이터를 손보는 일입니다. 한자의 앞 전(前)과 영어의 pre-가 같은 자리에 있습니다 — preview(미리 보기)의 그 pre-입니다. 빈칸으로 비어 있는 값, 혼자만 터무니없이 튀는 값, 단위가 서로 다른 값을 정리합니다. 요리로 치면 재료를 씻고 다듬는 단계입니다.

탐색적 데이터 분석 — 탐색 = 뒤져서 찾아봄

결론을 내기 전에 이리저리 살펴보는 단계입니다. 그래프를 그려 보고 평균을 내 보면서 “데이터가 대충 이렇게 생겼구나”를 파악합니다. 앞의 매점 예시에서 기온과 판매량을 나란히 놓고 본 것이 바로 이 단계입니다.

데이터 모델링 — 모델 = 본뜬 것

찾아낸 규칙을 수식이나 프로그램의 형태로 본떠 만드는 일입니다. 한 번 만들어 두면 처음 보는 값을 넣어도 답을 예측할 수 있습니다. “기온을 넣으면 판매량이 나오는 장치”를 만드는 셈입니다.

사례로 따라가기 — 지구 온난화

단계 지구 온난화 문제에서는
1. 문제 정의하기 북극의 빙하가 정말 녹고 있는지 알아본다.
2. 데이터 수집 및 특성 파악하기 지구 온난화를 알기 위해 필요한 데이터(기온, 해수면 등)를 모은다.
3. 데이터 전처리하기 기온은 섭씨(℃)인데 데이터가 화씨(℉)로 되어 있다면 속성값의 단위를 통일한다.
4. 탐색적 데이터 분석하기 “시간이 지날수록 해수면은 상승할 것이다”와 같은 관계를 찾아낸다.
5. 데이터 모델링하기 데이터 모델을 만들어 더 상세하게 확인한다.
6. 결과 해석 및 공유하기 지구 온난화에 대한 변화를 포스터로 만들어 게시판에 붙이고 심각성을 알린다.

3단계에서 단위를 통일하지 않으면 “어느 해의 기온이 99℃”와 같은 이상한 결과가 나옵니다. 전처리가 왜 필요한지 보여 주는 대목입니다.

다음 두 사례가 데이터 과학 사례가 맞을지 생각해 봅시다.

사례 데이터 과학 여부 이유
프로 스포츠팀 전략 최적화 맞다 상대 선수들의 패턴이나 스타일을 분석하여 유리한 전략을 세울 수 있다.
새로운 요리 메뉴 개발 아니다 경험과 취향을 근거로 재료와 맛의 조합을 예상하여 개발한다. 데이터가 사용되지 않았다.

판단의 열쇠 — 결정을 내릴 때 실제로 데이터를 수집하고 분석했는지를 봅니다. 결과가 그럴듯해 보여도 경험과 감에만 의존했다면 데이터 과학이라고 할 수 없습니다.

데이터 과학으로 풀 수 있는 다른 문제들

  • 은행에서 고객의 거래 내역, 결제 이력, 시장 데이터 등을 활용하여 투자 포트폴리오를 최적화할 수 있다.
  • 소셜 미디어 플랫폼에서 텍스트, 감정 등을 파악하여 제품 개선 및 마케팅에 활용할 수 있다.
  • 도시 교통 흐름 데이터를 분석하여 교통 체증을 줄이고 교통 안전을 향상시킬 수 있다.

Q.

데이터 과학은 무엇이고, 왜 데이터에 기반해 의사 결정을 해야 할까?

A.

데이터 과학은 대량의 데이터를 분석해 정보와 지식을 찾아내는 학문으로, 데이터에 숨겨진 패턴을 발견하고 예측합니다. 데이터에 기반한 의사 결정은 객관적인 수치와 사실에 근거하므로 감정이나 직관보다 훨씬 객관적이고 신뢰할 수 있으며, 시행착오를 줄여 줍니다.

핵심 정리

데이터 과학

data science

  • 대량의 데이터를 분석해 정보와 지식을 찾아내는 학문
  • 숨겨진 패턴 발견 · 예측으로 합리적 결정
  • 여러 분야의 전문 지식이 융합되어 활용

문제 해결 절차

data science process

  • 문제 정의 → 데이터 수집 및 특성 파악 → 전처리
  • 탐색적 데이터 분석 → 모델링 → 결과 해석 및 공유
  • 전처리를 건너뛰면 단위 불일치 같은 오류가 남는다

데이터 기반 의사 결정

data-driven decision making

  • 수집 · 분석 · 검증을 거친 전략적 결정
  • 객관적 수치와 사실 → 주관적 오류 최소화
  • 시행착오 감소, 책임감 · 신뢰성 향상
