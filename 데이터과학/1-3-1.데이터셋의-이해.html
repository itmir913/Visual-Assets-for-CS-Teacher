학습 목표

  1. 데이터셋의 뜻을 설명하고, 데이터와 데이터셋이 어떻게 다른지 구분할 수 있다.
  2. 정형 데이터셋과 비정형 데이터셋의 예를 들고, 서로 다른 형태의 데이터셋을 함께 분석하면 무엇이 좋은지 말할 수 있다.
  3. 데이터 통합의 세 가지 방법을 구분하고, 목적에 맞는 방법을 고를 수 있다.

데이터셋이란 무엇일까?

데이터와 데이터셋은 그냥 같은 말 아닐까?

앞 절에서 데이터 하나하나와 속성을 배웠습니다. 이제 그것들이 모여서 이룬 덩어리를 봅니다.

데이터셋(dataset)은 데이터를 모아 놓은 덩어리입니다. 데이터 포인트가 하나 이상 모이면 데이터셋이 됩니다.

용어 들여다보기

데이터셋 dataset

data + set입니다. 영어 set은 ‘한 벌 · 한 묶음’을 뜻합니다. 커피잔 여섯 개를 한 상자에 담은 것을 ‘커피잔 세트’라고 부르는 것과 같습니다. 즉 데이터셋은 따로 놀던 데이터를 목적에 맞게 한 묶음으로 정리해 둔 것입니다.

데이터 (data)

사실이나 정보의 원시 형태로, 다양한 형태(숫자, 텍스트, 이미지 등)로 존재할 수 있습니다.

아직 정리되지 않은 낱개입니다.

데이터셋 (dataset)

특정 분석이나 처리라는 목적에 맞게 관련 데이터를 모아 정리한 것으로, 여러 데이터 포인트들이 모여서 형성됩니다. 흔히 표나 데이터베이스처럼 구조화된 형태로 구성되지만, 리뷰 글 모음처럼 구조 없이 모인 데이터셋도 있습니다.

낱개에 목적이 생긴 묶음입니다.

가르는 지점은 ‘목적’과 ‘구조’입니다. 서랍에 굴러다니는 영수증은 데이터이고, 그것을 ‘이번 달 지출을 알아보려고’ 날짜 · 항목 · 금액 표로 옮겨 적으면 데이터셋이 됩니다. 같은 내용인데도 왜 모았는지가 정해지고 칸이 생기는 순간 데이터셋이 되는 것입니다.

우리집 감독 A 324 8.8
민들레 감독 B 186 8.7
영혼들 감독 C 405 9.1

앞 절에서 배운 눈으로 읽어 봅시다. 이 영화 데이터셋은 4개의 속성(제목 · 감독 · 관객 수 · 평점)과 4개의 데이터 포인트(영화 네 편)로 이루어져 있습니다. 속성은 세로줄, 데이터 포인트는 가로줄이었습니다.

데이터셋은 표로만 되어 있을까?

데이터는 정형 데이터로 표현하거나, 구조화되지 않은 리뷰 텍스트와 이미지 같은 비정형 데이터로도 표현할 수 있습니다.

너무 재밌어서 두 번 봤습니다. 꼭 보세요!
기대를 하지 않고 봤는데, 기대 이상이었어요!

시간 보내기용으로 추천합니다. 영화보는 내내 웃었어요.

왼쪽 리뷰들도 하나의 데이터셋입니다. ‘이 영화에 대한 관객의 반응’이라는 목적으로 모였기 때문입니다. 다만 앞 절에서 배운 대로 칸이 정해져 있지 않아 비정형입니다. 글의 길이도 제각각이고, 옆에 붙은 프로필 이미지도 표에 넣을 수 없습니다.

데이터셋은 세 가지로 나뉩니다

  • 정형 데이터로 구성된 데이터셋 — 영화 데이터셋처럼 전부 표에 들어감
  • 비정형 데이터로 구성된 데이터셋 — 리뷰 데이터셋처럼 전부 표 밖에 있음
  • 정형과 비정형이 섞인 데이터셋 — 실제로 가장 흔한 경우

영화 예매 앱을 떠올려 보세요. 상영 시간 · 좌석 · 가격은 정형이고, 포스터 이미지 · 예고편 영상 · 관람평은 비정형입니다. 한 화면 안에 둘이 같이 있습니다.

서로 다른 형태의 데이터셋을 함께 분석하면 새로운 통찰을 얻을 수 있습니다. 위 영화 데이터셋과 리뷰 데이터셋을 함께 분석하면 해당 영화에 대한 관객들의 감정과 느낀점을 더 명확하게 파악할 수 있습니다.

평점 8.8이라는 숫자만으로는 왜 그 점수인지 알 수 없습니다. 리뷰를 함께 보면 ‘웃겨서’인지 ‘감동해서’인지가 드러납니다. 숫자는 ‘얼마나’를, 글은 ‘왜’를 알려 줍니다.

데이터셋을 합치면 무엇이 좋을까?

따로 있는 표 두 개를 왜 굳이 하나로 만들까?

앞에서 ‘함께 분석하면 좋다’고 했는데, 어떻게 함께 놓는지가 이번 내용입니다.

데이터 통합은 흩어져 있는 데이터셋 여럿을 하나로 합치는 일입니다.

속성이 많아집니다

여러 개의 데이터를 통합하면 한 번에 분석할 수 있는 속성의 수가 많아지게 되므로 포괄적인 분석이 가능합니다.

관계가 더 보입니다

더 많은 수의 속성 간 관계를 발견할 수 있습니다. 앞 절에서 배운 상관관계 · 인과 관계를 찾을 재료가 늘어나는 것입니다.

영화 데이터셋만 보면 ‘평점이 높은 영화’까지밖에 알 수 없습니다. 여기에 상영관 데이터셋을 붙이면 ‘평점이 높은 영화가 어느 관에서 하는가’를 한 번에 물을 수 있습니다. 따로 있을 때는 던질 수 없던 질문이 생기는 것, 이것이 통합의 이유입니다.

합치기 전에 두 가지를 확인하세요. 첫째, 공통된 속성이 있는가 — 여기서는 ‘제목’입니다. 이것이 두 표를 잇는 다리 역할을 합니다. 둘째, 한쪽에만 있는 데이터가 무엇인가 — 민들레는 영화 데이터셋에만, 아홉 번째 별은 상영관 데이터셋에만 있습니다. 이 둘을 어떻게 처리하느냐가 다음에 나올 세 가지 방법을 가릅니다.

스스로 확인

위 두 데이터셋에서 양쪽에 모두 있는 영화는 무엇이고, 한쪽에만 있는 영화는 무엇인가요? 각각 이름을 대 보세요.

통합하는 방법은 몇 가지일까?

한쪽에만 있는 데이터는 버려야 할까, 남겨야 할까?

데이터 통합 방법은 세 가지 종류가 있으며, 목적에 맞는 방법을 선택하여 통합합니다.

아래 그림에서 왼쪽 원은 영화 데이터셋, 오른쪽 원은 상영관 데이터셋입니다. 두 원이 겹치는 부분이 양쪽에 모두 있는 데이터이고, 색칠된 부분이 결과에 남는 데이터입니다.

방법 1 공통된 속성 기준으로 통합

두 데이터셋에서 공통된 속성인 ‘제목’을 기준으로 같은 데이터만 통합합니다. 양쪽에 모두 있는 것만 남고, 한쪽에만 있는 것은 버려집니다.

제목 감독 상영관
우리집 감독 A 1관
영혼들 감독 C 3관

이 방법은 불필요한 데이터 없이 공통된 값만 필요한 경우에 사용할 수 있습니다. 빈칸이 하나도 없어 바로 분석에 쓰기 좋습니다. 대신 민들레와 아홉 번째 별은 사라졌다는 점을 잊으면 안 됩니다.

방법 2 영화 데이터셋의 속성 기준으로 통합

영화 데이터셋의 데이터 포인트를 기준으로 상영관 데이터셋의 데이터 포인트를 통합하고, 일치하는 데이터가 없는 경우에는 해당 속성값을 빈 칸으로 추출합니다.

제목 감독 상영관
우리집 감독 A 1관
민들레 감독 B
영혼들 감독 C 3관

이 방법은 기준이 되는 데이터셋과 다른 데이터셋과의 관계를 파악할 때 사용할 수 있습니다. 영화 세 편이 모두 남아 있고, 민들레의 상영관 칸만 비어 있습니다. ‘우리 영화 중 아직 상영관이 안 잡힌 것은?’을 알고 싶을 때 이 방법을 씁니다.

방법 3 공통된 속성 기준으로 모든 데이터 통합

공통된 속성을 기준으로 모든 데이터셋의 데이터 포인트를 통합합니다. 어느 한쪽에만 있어도 버리지 않고 모두 남깁니다.

제목 감독 상영관
우리집 감독 A 1관
민들레 감독 B
아홉 번째 별 1관
영혼들 감독 C 3관

이 방법은 데이터셋 간의 완전한 관계를 파악할 때 사용할 수 있습니다. 아무것도 잃지 않는 대신 빈칸이 가장 많이 생깁니다.

세 방법을 한 줄로 비교하면

방법 남는 데이터 포인트 빈칸 언제 쓰나
1. 공통된 것만 2개 (양쪽에 다 있는 것) 없음 공통된 값만 필요할 때
2. 기준 데이터셋 전부 3개 (영화 데이터셋 전부) 조금 기준 데이터셋과의 관계를 볼 때
3. 모든 데이터 4개 (양쪽 전부) 가장 많음 완전한 관계를 볼 때

고르는 기준은 ‘무엇을 알고 싶은가’입니다. 빈칸이 없는 깔끔한 표가 늘 좋은 것이 아닙니다. 방법 1을 쓰면 ‘아직 상영관이 안 잡힌 영화’는 아예 보이지 않게 됩니다. 버려진 데이터가 사실은 답이었을 수도 있습니다.

직접 판단해 봅시다

감독 A의 영화가 현재 어디에서 상영하는지를 알고 싶다면 어떤 통합 방법을 사용해야 할까요?

세 방법 모두 감독 A의 영화가 어디에서 상영되고 있는지 알 수 있습니다. ‘우리집’은 양쪽 데이터셋에 다 있어서 어느 방법으로 합쳐도 남기 때문입니다. 다만 ‘공통된 속성을 기준으로 통합하는 방법’(방법 1)이 가장 효율적입니다. 필요 없는 빈칸이 딸려 오지 않기 때문입니다.

데이터 통합하기

  1. 오렌지 프로그램을 열고 File 위젯에서 상영관 데이터를 불러옵니다. 창이 열리면 저장한 xlsx 파일을 고르고, 속성명을 확인한 뒤 Apply를 클릭합니다.
  2. 같은 방법으로 File 위젯을 하나 더 놓아 영화 데이터를 불러옵니다.
  3. 두 개의 File에 Merge Data 위젯을 연결하고, Row matching 설정을 [제목] - [제목]으로 설정합니다.

3번이 이 실습의 핵심입니다. Row matching이 바로 앞에서 배운 ‘공통된 속성’을 지정하는 자리입니다. 두 표를 잇는 다리를 무엇으로 놓을지 정하는 것입니다. 여기서는 양쪽에 다 있는 제목을 골랐습니다.

이번 실습에서는 상영관 데이터가 기준입니다. Merge Data 위젯에 먼저 연결한 데이터를 Data, 그 이후에 연결한 데이터를 Extra data라고 부릅니다. 앞 절 설명에서는 영화 데이터셋이 기준이었지만, 여기서는 상영관을 먼저 불러오므로 기준이 뒤바뀝니다. 같은 설정이라도 무엇을 먼저 연결했느냐에 따라 결과가 달라집니다.

설정 예상 데이터 포인트 수 화면에서 확인한 수 · 특징
Append columns from Extra data 상영관 3개가 모두 남으므로 3개 직접 확인해 보세요
Find matching pairs of rows 공통은 우리집 · 영혼들뿐이므로 2개 직접 확인해 보세요
Concatenate tables 상영관 3개 + 영화에만 있는 민들레 = 4개 직접 확인해 보세요

통합에 쓸 수 있는 위젯이 하나 더 있습니다. Concatenate 위젯입니다. Merge Data는 특정 키를 기준으로 두 데이터셋의 행을 통합하고, Concatenate는 동일한 형식의 두 데이터셋을 단순히 연결한다는 점에서 차이가 있습니다. 다리를 놓고 잇느냐, 그냥 아래에 이어 붙이느냐의 차이입니다.

AI와 함께 정리하기

Q.

데이터셋은 무엇이고, 왜 합쳐서 볼까?

A.

데이터셋(dataset)은 데이터들의 모임으로 하나 이상의 데이터 포인트로 구성됩니다. 낱개인 데이터와 달리 목적에 맞게 모여 구조를 갖춘 것이 데이터셋입니다. 정형으로도, 비정형으로도 표현할 수 있고 둘이 섞이기도 합니다. 데이터 통합은 두 개 이상의 데이터셋을 하나로 합하는 과정으로, 분석할 수 있는 속성이 많아져 포괄적인 분석이 가능해지고 더 많은 속성 간 관계를 발견할 수 있습니다. 방법은 세 가지이고, 무엇을 알고 싶은지에 따라 골라 씁니다.

핵심 정리

데이터셋

dataset

  • 데이터들의 모임으로 하나 이상의 데이터 포인트로 구성
  • 데이터는 원시 형태의 낱개, 데이터셋은 목적 + 구조를 갖춘 묶음
  • 보통 표나 데이터베이스 형태로 구성된다

데이터셋의 형태

structured · unstructured

  • 정형(영화 표) · 비정형(리뷰 글 · 이미지) · 섞인 것
  • 서로 다른 형태를 함께 분석하면 새로운 통찰을 얻는다
  • 숫자는 얼마나를, 글은 왜를 알려 준다

데이터 통합

data integration

  • 두 개 이상의 데이터셋을 하나로 합하는 과정
  • 속성 수가 늘어 포괄적인 분석이 가능해진다
  • 두 표를 잇는 공통된 속성이 반드시 필요하다

통합의 세 가지 방법

Orange · Merging

  • 공통된 것만 — 빈칸 없음 / Find matching pairs of rows
  • 기준 데이터셋 전부 — 짝 없으면 빈칸 / Append columns
  • 모든 데이터 — 아무것도 안 버림 / Concatenate tables
