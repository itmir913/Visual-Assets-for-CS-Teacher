데이터에서 발생하는 문제

결측치 (Missing Value)

데이터에서 누락된 값을 말합니다.
예) 시험 결석으로 성적 데이터가 없는 경우

처리 방법

  • 해당 데이터 삭제
  • 평균값·중간값·최빈값으로 대체
  • 다른 특성과의 상관관계를 이용해 추정

이상치 (Outlier)

정상 범위를 크게 벗어난 값을 말합니다.
예) 키 데이터에서 300cm처럼 극단적인 값

처리 방법

  • 해당 데이터 삭제
  • 평균값·중간값으로 대체
  • 원인 파악 후 신중하게 판단

전처리(Preprocessing)란?

데이터를 기계학습에 적합한 형태로 만드는 작업을 말합니다.
노이즈 제거, 중복값 삭제, 결측치 보정 등의 정제 작업이 포함되며,
전처리를 한 데이터는 기계학습 성능 향상에 큰 영향을 미칩니다.

데이터 유형에 따른 전처리 방법 비교

구분 정형 데이터 비정형 데이터
예시 시험 성적, 고객 정보 이미지, 음성, 텍스트
결측치 처리 결석생 데이터 삭제 또는 인정 점수 부여 해당 파일 제거
수치화 필요성 이미 수치 또는 카테고리로 구성 숫자 배열(임베딩)로 변환 필요
대표 전처리 정규화, 표준화, 결측치 보정 임베딩(Embedding), 크기 조정

❷ 이미지 데이터를 어떻게 처리할까?

오렌지(Orange3) 프로그램으로 이미지 데이터를 전처리해 봅시다.

오렌지(Orange3) 프로그램 실습

총 5단계로 이미지 데이터를 수집, 입력, 확인, 전처리하는 과정을 실습합니다.

1

이미지 데이터 세트 다운로드

이미지 데이터 세트를 제공하는 캐글(Kaggle) 사이트에서 과일 이미지 데이터를 다운로드합니다.
검색창에 Fruits 360을 입력하여 데이터 세트를 찾습니다.

Fruits 360 Dataset

배경을 제거한 100×100 픽셀 크기의 과일·채소 이미지

폴더 구성

  • Training/ — 학습용 이미지
  • Test/ — 테스트용 이미지

추출 기준

  • Training 폴더에서 5개 과일 선택
  • 각 폴더에서 10개씩 이미지 추출
  • 총 50개 이미지로 새 폴더 생성

3

이미지 데이터 입력 및 확인

① Import Images 위젯으로 폴더 업로드

[Image Analytics] 목록에서 Import Images 위젯을 선택하고 5개 과일 추출 폴더를 업로드합니다.
위젯의 Info 창에 50 Images / 5 Categories라고 표시되면 성공입니다.

확인: 50 images / 5 categories

② Image Viewer 위젯으로 이미지 확인

Image Viewer 위젯을 선택한 후 드래그하여 Import Images 위젯과 연결합니다.
위젯을 열면 50개의 과일 이미지가 잘 입력되어 있는지 확인할 수 있습니다.

③ Data Table 위젯으로 속성 확인

[Data] 목록에서 Data Table 위젯을 선택하고 Import Images 위젯과 연결합니다.
50개 이미지 데이터가 테이블 형태로 표현됩니다.

속성(컬럼) 내용 예시
category 과일 종류 (5가지) Apple, Banana, Cherry …
image name 이미지 파일 이름 Apple_1_100.jpg …
size 이미지 파일 크기 4727
width 이미지 너비(픽셀) 100
height 이미지 높이(픽셀) 100

이 5개의 값은 이미지 데이터의 속성(특징)이 아니라 각 이미지에 대한 사전 정보(메타데이터)입니다.

메타데이터(Metadata)란?

데이터에 대한 데이터를 말합니다. '어떤 목적을 가지고 만들어진 데이터'라고도 합니다.
예를 들어, 스마트폰으로 사진을 찍으면 촬영 시간, 해상도, 크기 등의 정보가 사진과 함께 저장되는데,
이러한 정보가 바로 메타데이터입니다.

Data Table에서 확인한 category, image name, size, width, height는 모두 과일 이미지의 메타데이터입니다.

4

기계학습을 위한 전처리 — 이미지 임베딩

이미지 데이터는 비정형 데이터이므로 기계학습에 바로 사용할 수 없습니다.
Image Embedding 위젯을 통해 이미지를 숫자 배열로 변환하는 전처리를 수행합니다.

임베딩(Embedding)이란?

기계가 이해할 수 있는 숫자의 배열로 치환하는 것입니다.
이미지의 픽셀 정보, 색상, 패턴 등이 숫자로 표현됩니다.

임베딩 예시 — 카테고리 A, B, C를 숫자 배열로 변환

A → → [0.1, 0.3, 0.0]
B → → [0.0, 0.1, 2.0]
C → → [0.3, 0.0, 0.7]

Q. 기계학습에서 데이터 처리는 왜 필요할까?

A. 데이터를 기계학습에 적합한 형태로 만들기 위해 전처리 작업이 필요합니다. 정형 데이터와 비정형 데이터에 따라 다른 전처리 방법이 사용되며, 전처리를 한 데이터는 데이터 분석의 성과뿐만 아니라 기계학습 성능 향상에도 큰 영향을 미칩니다.

핵심 용어

  • 결측치 — 누락된 값
  • 이상치 — 범위를 벗어난 값
  • 전처리 — 기계학습에 적합하게 가공

이미지 처리 흐름

  • ① 캐글에서 데이터 다운로드
  • ② Import Images로 입력
  • ③ Image Embedding으로 변환

  • 2,048개 속성(n0~n2047)
  • Inception v3 (구글 CNN)
