인공지능의 원리

인공지능은 인식 → 판단 → 행동의 순서로 세상과 상호작용합니다.
각 단계가 어떻게 이루어지는지 차례로 살펴봅니다.

학습 목표

  1. 인공지능이 인식→판단→행동의 순서로 동작한다는 것을 설명할 수 있다.
  2. 센서와 A/D 변환(샘플링·양자화·부호화)이 인식 단계에서 하는 역할을 설명할 수 있다.
  3. 지능 에이전트를 이루는 세 부분(센서·지능·액추에이터)과 3가지 특징(자율성·협력성·목표 지향성)을 설명할 수 있다.
  4. 판단을 실제로 수행하는 방법(탐색, 지식 표현과 추론, 기계학습)의 차이를 구별할 수 있다.

인공지능은 어떤 순서로 일을 처리할까?

인공지능은 세상과 상호작용하기 위해 항상 이 세 단계를 거칩니다.
이 강의는 각 단계를 하나씩 풀어나갑니다.

지난 시간의 '4가지 특성'과 이번 시간의 '3단계'는 어떤 관계일까?

지난 시간에 인공지능의 특성을 인식·학습·추론·예측·문제 해결의 네 가지로 배웠습니다. 그런데 이번 시간에는 단계가 인식·판단·행동의 세 가지라고 합니다. 둘 중 하나가 틀린 것이 아닙니다. 두 가지는 서로 다른 것을 묻고 있습니다.

4가지 특성 — 무엇을 할 수 있는가

인공지능이 갖춘 능력의 목록입니다. 순서가 있는 것이 아니라, 어떤 제품이 어떤 능력을 가졌는지 따져 보기 위한 항목입니다.

3단계 — 어떤 순서로 일하는가

인공지능이 실제로 움직일 때 거치는 일의 흐름입니다. 앞 단계가 끝나야 뒤 단계로 넘어가는 순서가 있습니다.

정리하면 — 「인식」은 두 틀에서 같은 것을 가리킵니다. 「학습」·「추론·예측」·「문제 해결」은 모두 판단 단계 안에서 쓰이는 능력입니다. 그리고 「행동」은 특성 목록에는 없던 단계입니다. 능력을 따질 때는 굳이 셀 필요가 없었지만, 실제로 일을 시키려면 생각한 것을 세상에 내놓는 단계가 반드시 있어야 하기 때문입니다.

인식(Perception): 센서와 A/D 변환

컴퓨터는 어떻게 우리가 사는 세상의 빛과 소리를 알아들을까요?

컴퓨터의 감각 기관, '센서'

사람이 눈, 귀, 피부로 세상을 느끼듯, 인공지능은 '센서(Sensor)'를 통해 세상을 느낍니다. (인공지능에 센서와 움직이는 장치까지 갖춰 붙인 시스템 전체를 지능 에이전트라고 부르는데, 이 말은 뒤의 '판단' 단원에서 자세히 다룹니다.)
우리 주변의 빛, 소리, 온도처럼 끊임없이 변하는 자연의 정보를 '아날로그 신호'라고 부릅니다. 센서는 이 아날로그 신호를 기계가 다룰 수 있는 '전기적 신호'로 바꿔주는 역할을 합니다.

A/D 변환기는 어떻게 통역할까? (3단계)

A/D(Analog to Digital) 변환기는 끊어지지 않고 이어지는 아날로그 신호를 0과 1로 바꾸기 위해 세 가지 과정을 거칩니다.

1

샘플링 (Sampling)

"잘게 쪼개기"

이어지는 신호를 일정한 시간 간격으로 끊어서 조각냅니다.
예) 긴 가래떡을 일정한 크기로 썰기

2

양자화 (Quantization)

"숫자 매기기"

쪼갠 조각들의 크기를 측정해서 가까운 정수(숫자)로 값을 매깁니다.
예) 썰어둔 떡의 무게를 저울로 달아 적기

3

부호화 (Encoding)

"0과 1로 쓰기"

숫자로 매긴 값을 컴퓨터만 읽을 수 있는 0과 1의 이진수로 최종 번역합니다.
예) 무게를 컴퓨터 문서로 타자 치기

더 알아보기: 양자화 오차와 비트 수의 관계
Deep Dive

왜 양자화가 중요한가요?

아날로그 신호는 무한한 정밀도를 갖지만, 컴퓨터는 이를 저장하기 위해 유한한 눈금을 사용해야 합니다. 이때 실제 값과 눈금의 차이인 양자화 오차가 발생합니다.

비트(Bit) 수 ↑

눈금이 촘촘해짐, 오차 감소, 원본에 가까움 (고음질/고화질)

비트(Bit) 수 ↓

눈금이 듬성듬성함, 오차 증가, 데이터 용량 작음

양자화 비트 수에 따른 차이 시각화

2-bit (4단계 눈금) 오차 큼
4-bit (16단계 눈금) 오차 작음

센서를 100% 믿어도 될까?

자주 하는 오해

"카메라 센서는 사람의 눈처럼 사물을 완벽하게 알아본다?"

정답은 '아니요' 입니다! 사람은 빛이 강하든 그림자가 지든 사과를 사과로 알아봅니다. 하지만 센서는 '빛의 변화'에 매우 취약합니다. 빛이 조금만 반사되거나 역광이 비치면 아예 다른 물체로 착각하거나 인식하지 못하는 '인식 오류'가 발생할 수 있습니다.

빛의 마술과 자율주행차

앞에 트럭이 있어도, 강한 햇빛이 하얗게 반사되면 카메라 센서는 눈이 부셔서 트럭을 빈 공간으로 인식할 수 있습니다. 그래서 자율주행 자동차는 카메라 하나만 믿지 않고 레이더, 라이다 등 여러 센서를 동시에 사용합니다.

핵심: 센서에만 100% 의존할 수는 없다!

코드로 보는 인식의 흐름

Under the hood

컴퓨터 프로그램 속에서는 인식 과정이 어떻게 진행될까?

지금까지 배운 환경 정보 → 센서 → A/D 변환 → 인식 과정은 실제 프로그램에서도 비슷한 순서로 처리됩니다.

오른쪽 코드를 보며 아날로그 소리 데이터가 0과 1의 디지털 데이터로 변환되는 과정을 단계별로 확인해 보세요.

sensor_process.c 
// 에이전트가 소리를 듣고 인식하는 과정

void agentPerception() {
    // [1단계: 환경 정보] 자연의 소리(아날로그) 발생
    AnalogSignal soundWave = environment.getSound();

    // [2단계: 센서] 마이크가 소리를 전기 신호로 바꿈
    ElectricSignal rawSignal = micSensor.detect(soundWave);

    // [3단계: A/D 변환기] 컴퓨터의 통역사 등장!
    DigitalData dData = adConverter.transform(rawSignal);

    // [4단계: 인식] 에이전트의 두뇌가 디지털 데이터를 분석함
    if (aiBrain.recognizeVoice(dData) == "도와줘") {
        actuator.moveTowardUser();
    }
}

판단(Reasoning): 지능 에이전트

인식한 정보로 무엇을 할지는 누가 정할까?

인식한 정보를 바탕으로 무엇을 할지 결정하는 것이 판단입니다.
이 판단을 해내는 부분을 갖춘 시스템을 지능 에이전트라고 부릅니다.

지능 에이전트란 무엇인가

지능 에이전트(Intelligent Agent)란 환경을 스스로 살펴보고, 무엇을 할지 스스로 정하고, 그것을 실제로 실행하는 시스템 전체를 말합니다. 세 가지 일 가운데 하나라도 빠지면 지능 에이전트가 아닙니다. 살펴보기만 하고 아무것도 정하지 않으면 그냥 감지기이고, 정해 주는 대로 움직이기만 하면 그냥 기계입니다.

그래서 지능 에이전트는 세 부분으로 이루어집니다. 환경을 받아들이는 센서, 무엇을 할지 정하는 지능(소프트웨어), 그리고 실제로 움직이는 액추에이터입니다. 이 셋이 앞에서 본 인식 → 판단 → 행동의 세 단계를 하나씩 맡습니다.

사람에 빗대어 보면 — 지능 에이전트가 「사람 한 명 전체」입니다. 센서는 눈·귀 같은 감각 기관, 지능은 두뇌, 액추에이터는 팔과 다리에 해당합니다. 여기서 인공지능은 두뇌에 해당하는 부분, 곧 에이전트 안에서 판단을 맡는 소프트웨어입니다.

자주 헷갈리는 점

인공지능과 지능 에이전트는 나란히 놓고 견줄 짝이 아닙니다. 「두뇌 대 몸」처럼 둘로 갈라 외우면 틀립니다. 인공지능은 지능 에이전트 안에 들어 있는 한 부분이고, 지능 에이전트는 그 인공지능에 센서와 액추에이터까지 갖춰 붙인 것입니다. 아무리 똑똑한 인공지능이라도 세상을 받아들일 센서와 세상을 바꿀 액추에이터가 없으면 혼자서는 아무 일도 하지 못하기 때문에, 실제 제품은 늘 에이전트 형태로 만들어집니다.

헷갈리지 마세요! (오개념 방지)

"지능 에이전트가 알아서 다 해주면 사람은 아무것도 안 해도 되나요?"
그렇지 않습니다. 지능 에이전트는 인간을 대신하는 존재가 아니라 인간의 목표 달성을 돕는 협력 도구입니다. 즉 사람과 함께 문제를 해결하는 파트너 역할을 합니다.

로봇 청소기로 보는 에이전트의 3가지 특징

① 자율성

사람이 매번 리모컨으로 조종하지 않아도 됩니다.

로봇 청소기: "바닥의 먼지를 스스로 인식하고 알아서 청소하러 이동합니다."

② 협력성

다른 에이전트나 기계, 사람과 정보를 주고받으며 함께 목표를 이룹니다.

로봇 청소기: "만들어 둔 집 안 지도를 스마트폰 앱에 보내 주고, 사람이 앱에서 '오늘은 거실만'이라고 정해 주면 그에 맞춰 경로를 다시 짭니다."

③ 목표 지향성

주어진 '목표'를 달성하기 위해 최선의 방법을 찾습니다.

로봇 청소기: "'방 전체를 깨끗하게 만든다'는 목표 달성 여부가 에이전트를 평가하는 기준이 됩니다."

정리하자면! 지능 에이전트는 목적(목표 지향성)을 가지고, 스스로 판단하며(자율성), 필요할 땐 남과 소통(협력성)하는 스마트한 시스템입니다.

세 가지가 늘 똑같은 무게로 나타나지는 않습니다. 자율성과 목표 지향성은 지능 에이전트라면 어느 것이든 갖추고 있어야 하지만, 협력성은 주고받을 상대가 있을 때 드러납니다. 혼자서 일하는 에이전트도 있고, 여러 대가 함께 움직여야 하는 일일수록 협력성이 두드러집니다. 어떤 에이전트를 만났을 때 세 가지가 각각 어디에서 보이는지를 찾아보는 편이, 세 낱말을 외우는 것보다 도움이 됩니다.

(예: 로봇 팔, 스피커, 바퀴, 화면 표시)

헷갈리지 마세요! (오개념 방지)

"자동문도 사람이 오면 열리는데, 지능 에이전트인가요?"
자동문은 단순한 '센서'와 모터(액추에이터)만 있습니다. 하지만 상황을 보고 스스로 판단(누구인지, 열어줘야 할지 말지)하는 '지능(소프트웨어)' 요소가 없기 때문에 단순한 기계일 뿐, 지능 에이전트는 아닙니다. 앞에서 세 부분 중 하나라도 빠지면 지능 에이전트가 아니라고 한 것이 바로 이런 경우입니다.

지난 시간에 「자동으로 움직인다고 다 인공지능은 아니다」라고 배운 것과 같은 이야기입니다. 자동문에 얼굴을 알아보고 들여보낼지 말지를 스스로 정하는 소프트웨어를 붙이면 그때부터는 지능 에이전트가 됩니다. 가르는 것은 문이 열리느냐가 아니라, 열지 말지를 누가 정하느냐입니다.

설계 예시

스마트홈 경비원 에이전트 설계

센서, 지능, 액추에이터가 실제로 어떻게 함께 작동하는지 예시로 살펴봅니다.

집을 지키는 스마트홈 보안 에이전트를 만든다고 상상해 봅시다. 이 에이전트는 주변 상황을 인식하고, 판단한 뒤, 적절한 행동을 수행합니다.

1

목표 설정

집 내부가 안전한지 확인한다.

2

인식 (센서)

카메라로 집 내부 상황을 관찰한다.

3

추론 (지능)

가족인지 침입자인지 판단한다.

4

행동 (액추에이터)

경보를 울리거나 문을 열어준다.

smart_home.c 
// 스마트홈 보안 에이전트의 작동 흐름

void runSecurityAgent() {
    while (true) {
        // 1. 인식 (Sensor)
        Image currentView = cameraSensor.captureImage();

        // 2. 추론 (Intelligence)
        Person detectedPerson = aiEngine.analyzeFace(currentView);

        if (detectedPerson == UNKNOWN_PERSON) {
            // 3. 행동 (Actuator)
            speakerActuator.soundAlarm();
            networkModule.callPolice();
        } else if (detectedPerson == FAMILY_MEMBER) {
            doorActuator.unlock();
        }
    }
}

위 사례 중 하나를 골라 인식·판단·행동이 각각 무엇인지 말할 수 있나요? 그 사례의 설명을 다시 확인해 보세요.

그래서 '판단'은 실제로 어떻게 하는가?

인식 → 판단 → 행동의 순서를 배웠습니다. 그렇다면 '판단'은 어떤 방식으로 이루어질까요?
이것이 인공지능 기초 전체의 핵심 질문입니다.

'판단'이란 무엇인가?

판단이란 여러 선택지 중에서 하나를 고르는 일입니다. 로봇 청소기는 "어느 방을 먼저 청소할까?"를 골라야 하고, 체스 AI는 "다음 수를 어디에 둘까?"를 골라야 합니다. 이 선택을 하는 방법이 크게 세 갈래로 나뉩니다. 이 가운데 두 갈래를 1-2에서 배우고, 나머지 하나는 2단원 전체에 걸쳐 배웁니다.

지난 시간과 이어 보면 — 인공지능을 일반 소프트웨어와 견줄 때 「사람이 규칙을 적어 주느냐, 데이터에서 규칙을 찾아내느냐」로 갈라 보았습니다. 그런데 아래 세 갈래를 보면 데이터로 학습하는 것은 그중 하나뿐입니다. 나머지 둘은 학습하지 않고도 스스로 고릅니다. 그러니 「학습해야만 인공지능」이라고 외워 두면 안 됩니다. 공통점은 학습이 아니라 상황을 보고 스스로 고른다는 것입니다.

방법 1

탐색 (Search)

가능한 모든 경우를 상태 공간 트리로 펼쳐 놓고, 목표로 가는 최적의 길을 찾는 방법입니다.

로봇 청소기 예시:
"어느 방으로 갈지" — 가능한 경로를 모두 펼쳐 최단 경로를 탐색
1-2-1. 탐색과 문제 해결 →
상태 공간 트리, BFS/DFS
1-2-2. 지능적 탐색 →
휴리스틱, A* 알고리즘
1-2-3. 탐색을 활용한 문제 해결 →
8-퍼즐, N-Queen 등

방법 2

지식 표현과 추론

아는 사실을 규칙·의미망·프레임으로 미리 적어 두고, 그 지식에서 새로운 사실을 이끌어 내는 방법입니다.

로봇 청소기 예시:
"카펫 위에서는 물걸레를 올린다" — 사람이 적어둔 규칙으로 상황 판단
1-2-4. 지식의 표현과 논리 추론 →
규칙, 의미망, 논리 추론

그리고 세 번째 방법 (2단원 예고)

탐색이나 규칙은 사람이 직접 경우의 수나 규칙을 알려줘야 합니다. 기계학습은 그 규칙을 데이터에서 스스로 찾는 세 번째 방법입니다.

로봇 청소기 예시:
"먼지 사진을 수천 장 보여주면 AI가 스스로 '먼지 패턴'을 익힌다"
2-1-1. 기계학습과 문제 해결 과정 →
데이터로 규칙을 스스로 찾기

판단 방법 세 갈래 한눈에 비교

판단 방법 핵심 아이디어 로봇 청소기 예시 배우는 곳
탐색 경우를 모두 펼쳐 최적 경로 탐색 어느 방을 먼저 청소할까? 1-2-1, 1-2-2, 1-2-3
지식 표현·추론 규칙을 미리 적어두고 새 사실 추론 카펫이면 물걸레 올리기 1-2-4
기계학습 데이터에서 패턴을 스스로 학습 먼지 사진 보고 종류 파악 2단원 전체

AI와 함께 똑똑 정리하기

Q. 인공지능은 어떤 원리로 일하는가?

A. 인공지능은 인식 → 판단 → 행동의 순서로 세상과 상호작용합니다. 센서가 아날로그 신호를 수집해 A/D 변환으로 디지털 데이터로 바꾸면(인식), 지능이 탐색·지식 표현·추론·기계학습 가운데 알맞은 방법으로 무엇을 할지 결정하고(판단), 액추에이터가 실제로 환경을 바꿉니다(행동). 이 세 부분을 모두 갖춘 시스템 전체를 지능 에이전트라고 부르고, 인공지능은 그 안에서 판단을 맡는 부분입니다. 단, 센서는 완벽하지 않으므로 여러 센서를 함께 사용해야 합니다.

핵심 용어

  • 센서 — 아날로그 → 전기 신호
  • A/D 변환기 — 전기 → 디지털
  • 지능 에이전트 — 센서+지능+액추에이터
  • 액추에이터 — 판단 → 행동

에이전트의 3가지 특징

  • ① 자율성 — 스스로 판단
  • ② 협력성 — 다른 에이전트와 통신
  • ③ 목표 지향성 — 목표 달성을 위해 행동

판단의 세 가지 방법

  • 탐색 — 경로 탐색 (1-2-1~3)
  • 지식 표현·추론 — 규칙 기반 (1-2-4)
  • 기계학습 — 데이터 학습 (2단원)
