데이터(Data)란 무엇일까?

우리 주변에는 수많은 데이터가 있습니다. 데이터가 무엇인지, 어떤 종류가 있는지 알아봅시다.

데이터(Data)의 정의

관찰이나 실험을 통해 수집되는 값 또는 특성을 의미합니다.
숫자, 문자, 이미지, 소리 등 다양한 형태로 존재하며, 인공지능과 기계학습의 핵심 재료가 됩니다.

생활 속 다양한 데이터의 종류

수치 데이터

온도, 키, 몸무게, 점수, 가격 등 숫자로 표현되는 데이터

이미지 데이터

사진, 그림, 영상 등 시각적으로 표현되는 데이터

텍스트 데이터

기사, 리뷰, SNS 게시글, 책 등 문자로 표현되는 데이터

음성 데이터

말소리, 음악, 환경음 등 소리로 표현되는 데이터

데이터 속성(Attribute)이란?

하나의 데이터는 다른 데이터와 구별되도록 여러 가지 속성을 가집니다.

데이터 속성의 정의

데이터가 갖는 성질로, 하나의 데이터는 다른 데이터와 구별이 가능하도록 여러 가지 속성을 가집니다.
예를 들어 '책'이라는 데이터는 제목, 저자, 출판사, 대출 여부 등 여러 속성으로 구성됩니다.

예시 ① 책 데이터의 속성

도서관의 책 데이터는 제목, 저자, 출판사, 대출 여부 등의 속성을 가집니다. 아래 표에서 각 행(row)이 하나의 책(데이터)이고, 열(column)이 속성입니다.

번호 제목 저자 출판사 출판 연도 대출 여부
1 파이썬으로 배우는 인공지능 김인공 정보출판 2022 대출 중
2 데이터 과학 입문 이데이터 미래학습사 2021 대출 가능
3 기계학습 첫걸음 박학습 AI북스 2023 대출 중
4 수학으로 보는 딥러닝 최수학 딥북스 2020 대출 가능

각 열의 이름(번호, 제목, 저자, 출판사, 출판 연도, 대출 여부)이 바로 속성(Attribute)입니다.

예시 ② 학교 도서관 이용자 데이터의 속성

학교 도서관 이용자 데이터는 이름, 성별, 구분, 학년, 학반 번호, 도서관 이용 횟수, 대출 권 수 등의 속성을 가집니다.

이름 성별 구분 학년 학반 이용 횟수 대출 권 수
김○○ 여 학생 1 2 12 8
이○○ 남 학생 2 3 5 3
박○○ 남 교사 — — 20 15
최○○ 여 학생 3 1 3 2

하나의 행(row)은 한 명의 이용자를 나타내며, 각 열(column)은 그 이용자가 가진 속성값입니다.

✏️ 스스로 활동 — 문제 해결에 필요한 속성 골라내기

수집한 데이터의 모든 속성이 문제 해결에 다 필요한 것은 아닙니다. 위의 학교 도서관 이용자 데이터(이름, 성별, 구분, 학년, 학반, 이용 횟수, 대출 권 수)를 활용해 "독서량이 많은 학생에게 어울리는 책을 추천하는 기계학습 모델"을 만든다고 할 때, 다음을 정리해 봅시다.

  1. 수집한 데이터의 속성은 무엇인가요?
  2. 이 문제 해결에 꼭 필요한 속성은 무엇인가요?
  3. 반대로 문제 해결과 관련이 적은 속성은 무엇인가요?

데이터 속성의 유형

데이터 속성은 표현되는 형태에 따라 범주형, 숫자형, 문자형, 날짜/시간형으로 구분할 수 있습니다.

범주형 데이터

몇 가지 정해진 범주(카테고리) 중 하나로 구분되는 데이터

예: 성별(남/여), 대출 여부(대출 중/대출 가능), 품종(setosa 등)

숫자형 데이터

크기나 양을 숫자로 나타낸 데이터

예: 나이, 키, 온도, 꽃잎 길이(cm), 이용 횟수

문자형 데이터

문자(글자)로 표현되는 데이터

예: 책 제목, 저자 이름, 이용자 이름

날짜/시간형 데이터

날짜나 시간의 형식으로 표현되는 데이터

예: 출판 연도, 대출 일시, 조사 일자

오렌지(Orange)와 같은 데이터 분석 도구는 파일을 불러올 때 각 속성(열)마다 이러한 유형을 자동으로 인식하여 보여 줍니다. 속성의 유형에 따라 적용할 수 있는 시각화 방법이나 전처리 방법이 달라지므로, 데이터 속성의 유형을 파악하는 것은 데이터 분석의 첫걸음입니다.

붓꽃(Iris) 데이터로 속성 이해하기

기계학습에서 가장 많이 사용되는 데이터셋 중 하나인 붓꽃 데이터 세트를 통해 속성을 살펴봅시다.

붓꽃 데이터 세트란?

  • 붓꽃(Iris)의 품종과 꽃잎·꽃받침의 크기를 센티미터(cm) 단위로 측정한 데이터
  • 총 150개의 데이터 (품종별 50개씩)
  • 기계학습 입문자들이 가장 많이 연습하는 표준 데이터셋

3가지 품종

Iris setosa (아이리스 세토사)
Iris versicolor (아이리스 버시컬러)
Iris virginica (아이리스 버지니카)

붓꽃 데이터의 6가지 속성

1
Id

각 데이터를 구별하는 고유 번호 (1 ~ 150)

2
SepalLengthCm

꽃받침(Sepal)의 길이 (단위: cm)

3
SepalWidthCm

꽃받침(Sepal)의 너비 (단위: cm)

4
PetalLengthCm

꽃잎(Petal)의 길이 (단위: cm)

5
PetalWidthCm

꽃잎(Petal)의 너비 (단위: cm)

6
Species

붓꽃의 품종 (setosa / versicolor / virginica)

붓꽃 데이터 미리보기 (상위 5개)

Id SepalLengthCm SepalWidthCm PetalLengthCm PetalWidthCm Species
1 5.1 3.5 1.4 0.2 Iris-setosa
2 4.9 3.0 1.4 0.2 Iris-setosa
51 7.0 3.2 4.7 1.4 Iris-versicolor
101 6.3 3.3 6.0 2.5 Iris-virginica
150 5.9 3.0 5.1 1.8 Iris-virginica

각 행은 하나의 붓꽃 데이터이며, 총 150개의 행으로 구성됩니다.

독립 변수와 종속 변수

기계학습에서 데이터 속성은 역할에 따라 독립 변수와 종속 변수로 구분됩니다.

독립 변수

Independent Variable

데이터 속성의 관계에 있어 다른 변수(속성)에 영향을 미치는 원인이 되는 변수입니다.
기계학습 모델에 입력(Input)으로 들어가는 특성값입니다.

붓꽃 데이터에서의 독립 변수

SepalLengthCm SepalWidthCm PetalLengthCm PetalWidthCm

종속 변수

Dependent Variable

데이터 속성의 관계에 있어 다른 변수들의 영향을 받는 결과나 효과를 나타내는 변수입니다.
기계학습 모델이 예측(Output)해야 하는 목표값입니다.

붓꽃 데이터에서의 종속 변수

Species (품종)

기계학습에서의 역할

독립 변수 (입력)

꽃받침·꽃잎 길이/너비

기계학습 모델

종속 변수 (출력)

품종 예측 (Species)

기계학습 모델은 독립 변수(꽃의 크기 정보)를 입력받아
종속 변수(품종)를 예측하는 규칙을 스스로 학습합니다.

여러 가지 독립 변수·종속 변수의 예

해결할 문제 독립 변수 종속 변수
활동량에 따른 칼로리 소비량 계산 활동량 칼로리 소비
소고기 정보를 바탕으로 등급 판정 지방 함량, 지방색, 성숙도, 육색 소고기 등급(1+, 1++ 등)
환자의 데이터를 바탕으로 악성 종양 진단 X-ray 사진, 종양의 크기·두께 악성 종양 여부(양성/음성)
집의 정보를 바탕으로 적정 집값 계산 역세권 여부, 인근 학교 수, 방의 개수, 면적 집값

이처럼 문제에 따라 독립 변수와 종속 변수로 사용되는 속성은 달라집니다.

핵심 정리

데이터와 데이터 속성

  • 데이터: 관찰·실험을 통해 수집된 값 또는 특성
  • 데이터 속성: 하나의 데이터를 다른 데이터와 구별하게 해주는 성질
  • 하나의 데이터는 여러 속성값을 가짐
  • 속성 유형: 범주형·숫자형·문자형·날짜/시간형

붓꽃(Iris) 데이터셋

  • 150개의 붓꽃 데이터, 3가지 품종
  • 속성: Id, 꽃받침 길이/너비, 꽃잎 길이/너비, 품종
  • 기계학습 입문용 표준 데이터셋

독립 변수 vs 종속 변수

  • 독립 변수: 영향을 미치는 변수 → 모델의 입력값
  • 종속 변수: 영향을 받는 변수 → 모델의 예측 대상
  • 붓꽃: 꽃 크기(독립) → 품종 예측(종속)
