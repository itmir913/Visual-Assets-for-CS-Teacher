정형 데이터와 비정형 데이터

데이터는 구조에 따라 정형과 비정형으로 나뉩니다.
각 데이터의 특징을 이해하고,
기계학습에서 어떻게 활용되는지 알아봅시다.

학습 목표

  1. 정형 데이터와 비정형 데이터의 특징을 설명할 수 있다.
  2. 정형 데이터와 비정형 데이터의 차이를 비교할 수 있다.
정형·비정형 데이터
정형 데이터 비정형 데이터 비교 반정형 데이터 탐구활동 핵심 정리 퀴즈

정형 데이터란 무엇일까?

정형 데이터는 명확한 형태나 구조를 가진 데이터입니다.

정형 데이터(Structured Data)의 정의

규칙에 따라 정리된 명확한 형태나 구조로 이루어진 데이터를 말합니다.
주로 행과 열로 표현할 수 있는 테이블 형태로 저장이 가능하고, 모든 행이 같은 구조를 가집니다.
이름, 주소, 계좌번호, 가격 등 정량적으로 나타낼 수 있는 데이터가 대표적입니다.

정형 데이터의 구조

열(속성) 속성 1 속성 2 속성 3 …
행 (속성값) 값 값 값 …
값 값 값 …
값 값 값 …
… … … …

정형 데이터는 미리 정해 놓은 형식과 구조에 따라 저장되어 사용자가 쉽게 이해하고 관리할 수 있습니다.

예시: 학생 신상 정보 데이터

각 행은 한 사람에 관한 정보를 담고 있고, 모든 사람은 같은 속성(학번, 이름, 성별, 생년월일)을 가집니다.

학번 이름 성별 생년월일
10304 박OO 남 2005/05/06
10513 김OO 여 2005/07/29
10629 이OO 여 2006/12/06
… … … …

정형 데이터의 장점 — 검색·수정·삽입

① 검색

이름, 학번 등 특정 조건으로 원하는 데이터를 빠르게 찾을 수 있습니다.

② 수정

특정 행이나 열의 값을 정확히 찾아 수정할 수 있습니다.

③ 삽입

새로운 행(데이터)이나 열(속성)을 기존 구조에 맞게 추가할 수 있습니다.

정형 데이터의 대표 예시

스프레드시트

Excel, Google Sheets 등 행과 열로 구성된 표 형식의 데이터

CSV 파일

콤마(,)로 구분된 값으로 구조가 결정되는 텍스트 파일 형식

관계형 데이터베이스

MySQL, PostgreSQL 등 테이블 형태로 정제 및 구조화된 데이터

우리 반 시간표는 정형 데이터일까요? 행과 열로 정리되는지, 각 칸의 의미가 정해져 있는지를 위 정의에서 다시 확인해 보세요.

비정형 데이터란 무엇일까?

비정형 데이터는 명확한 형태나 구조를 가지지 않은 데이터입니다.

비정형 데이터(Unstructured Data)의 정의

정형 데이터와 달리 형태나 구조가 명확하지 않은 데이터를 말합니다.
이메일 본문, 문자 메시지, 문서(보고서), 소셜 미디어 텍스트, 사진, 음성, 영상 등이 해당됩니다.
구조화되어 있지 않고 일정한 규칙을 발견하기 어렵습니다.

비정형 데이터의 종류

소셜 미디어

SNS 게시글, 댓글, 해시태그 등 텍스트 데이터

위치 정보

GPS 좌표, 지도 경로, 이동 궤적 데이터

메시지

이메일 본문, 문자 메시지, 채팅 내용

영상

유튜브 동영상, 영상 통화, 스트리밍 데이터

음악 / 음성

음원 파일, 음성 녹음, AI 스피커 음성 데이터

이미지

사진 파일, 그림, 의료 영상(X-ray) 등

비정형 데이터는 왜 늘어날까?

정보 통신 기술의 발전으로 전 세계에서 매일 상상할 수 없을 만큼 많은 양의 데이터가 만들어지고 있습니다. 현대 사회에서 사람들 간의 의사소통이 대부분 스마트폰, 소셜 미디어, 채팅, 영상 통화 등으로 이루어지기 때문입니다.

대화

→ 음성 데이터

채팅

→ 텍스트 데이터

영상 통화

→ 영상 데이터

비정형 데이터의 가치

비정형 데이터를 잘 다룰수록 경쟁력이 올라가기 때문에 정부·기업·개발자·연구자들이 비정형 데이터 처리 기술을 지속적으로 개선하고 있습니다. 매일 쏟아지는 비정형 데이터를 처리하는 기술이 발달할수록, 이로 인해 얻을 수 있는 가치는 상당할 것이며 인공지능의 발전과 함께 인간의 삶을 크게 바꾸어 놓을 것입니다.

정형 데이터 vs 비정형 데이터

정형과 비정형 데이터는 기계학습에서 어떻게 다르게 다뤄질까?

데이터 유형에 따라 기계학습을 위한 처리 방법이 달라집니다.

정형 데이터

20%
  • 행과 열로 표현 가능하고 값의 의미를 파악하기 쉬움
  • 숫자, 날짜, 문자 등의 데이터 형식
  • 전체 데이터의 약 20% 차지
  • 상대적으로 작은 저장 공간 필요
  • 관리가 비교적 쉬움

비정형 데이터

80%
  • 행과 열로 표현되지 않고 형태가 불규칙
  • 문서(보고서), 이미지, 음성, 비디오, 이메일 본문 등
  • 전체 데이터의 약 80% 차지
  • 상대적으로 큰 저장 공간 필요
  • 관리가 비교적 어려움

특징 비교표

비교 항목 정형 데이터 비정형 데이터
구조 행과 열로 표현 가능 형태가 불규칙, 규칙 없음
데이터 형식 숫자, 날짜, 문자 문서, 이미지, 음성, 영상
전체 비중 약 20% 약 80%
저장 공간 상대적으로 작음 상대적으로 큼
관리 난이도 쉬움 어려움
기계학습 활용 비교적 쉽게 사용 가능 별도 처리·변환 필요

기계학습 모델 구현 과정에서의 위치

STEP1 문제 정의 STEP2 데이터 수집 STEP3 데이터 전처리 STEP4 알고리즘 선정 STEP5 모델 생성 STEP6 성능 평가 및 수정

수집한 데이터가 정형 데이터인지 비정형 데이터인지에 따라 다음 단계인 STEP3 데이터 전처리에서 적용할 처리 방법이 달라집니다. 정형 데이터는 비교적 쉽게 전처리하여 기계학습에 사용할 수 있지만, 비정형 데이터는 숫자 배열로 변환하는 등 별도의 처리 과정이 필요합니다.

Garbage In, Garbage Out

"쓰레기를 넣으면 쓰레기가 나온다." — 데이터를 기반으로 학습하는 기계학습에서 품질 좋은 데이터는 성능과 밀접한 관계가 있습니다. 만들 음식마다 재료를 손질하는 방법이 다르듯, 데이터가 정형인지 비정형인지에 따라 기계학습을 위한 처리 방법도 달라집니다.

반정형 데이터(Semi-Structured Data)란?

테이블의 행과 열로 구조화되어 있지는 않으나, 데이터 구조 정보를 데이터와 함께 파일 형식으로 제공하는 데이터입니다. 데이터의 형식과 구조가 변경될 수 있습니다. 대표적인 예로 XML, HTML, JSON 형태의 데이터가 있습니다.

반정형 데이터의 종류

XML

태그(tag)를 사용해 데이터의 구조와 의미를 함께 표현하는 형식

HTML

웹 페이지 구조를 표현하는 마크업 언어로 태그 기반 구조를 가짐

JSON

키(key)와 값(value) 쌍으로 이루어진 데이터 형식. 자바스크립트 객체 표기법

JSON 데이터 예시

{
  "name": "김인공",
  "age": 17,
  "gender": "female",
  "birthday": "8/5"
}

JSON은 키와 값의 쌍으로 구성됩니다. 구조 정보(키 이름)를 데이터와 함께 제공하므로 반정형 데이터에 해당합니다.

핵심 정리

정형 데이터

규칙에 따라 정리된 명확한 형태나 구조로 이루어진 데이터. 행과 열로 표현 가능하며 전체 데이터의 약 20%를 차지. 관리가 쉽고 기계학습에 비교적 쉽게 사용 가능.

비정형 데이터

구조가 명확하지 않고 일정한 규칙을 발견하기 어려운 데이터. 이미지, 음성, 영상, 텍스트 등이 해당하며 전체의 약 80% 차지. 처리 기술의 발달로 활용 가치가 높아지는 중.

기계학습과의 관계

데이터 유형에 따라 기계학습을 위한 처리 방법이 달라집니다. 품질 좋은 데이터가 좋은 기계학습 결과를 만듭니다. "Garbage In, Garbage Out"

Q. 정형 데이터와 비정형 데이터의 특징에는 어떤 차이가 있을까?

A. 정형 데이터는 명확한 형태나 구조를 가지고 있기 때문에 데이터 분석이나 기계학습에 비교적 쉽게 사용할 수 있습니다. 이에 비해, 비정형 데이터는 명확한 형태나 구조를 가지고 있지 않기 때문에 기계학습을 위해 정형 데이터와 다른 처리를 해야 합니다.
