데이터 시각화

데이터를 그래프와 차트로 시각화하면
숨어 있는 의미를 쉽게 발견하고
기계학습에 필요한 핵심 속성을 찾을 수 있습니다.

학습 목표

  1. 데이터를 다양한 형태로 시각화할 수 있다.
  2. 데이터 시각화를 통해 데이터가 가지는 의미를 해석할 수 있다.
데이터 탐색과 시각화
시각화란? 막대·선그래프 산점도 붓꽃 시각화 특성 통계표 오렌지 실습 퀴즈

데이터를 어떻게 시각화할까?

데이터를 시각화하여 나타내는 방법은 막대, 선, 점 등 다양합니다.

데이터 시각화(Data Visualization)란?

일상생활에서 발생하는 수많은 데이터는 수집한 형태만으로 전체를 파악하기 어려운 경우가 많습니다. 이런 데이터를 막대, 선, 점 등 다양한 형태로 시각화하면 그 의미를 쉽게 파악할 수 있고 숨어 있는 정보도 쉽게 찾을 수 있습니다.

핵심 요소

데이터 시각화

데이터가 가지는 의미를 그래프 등으로 표현하여 해석하는 방법

시각화 방법

막대, 선, 점(산점도), 워드 클라우드 등 목적에 맞는 다양한 형태 활용

시각화의 활용

기계학습에 필요한 핵심 속성을 파악하는 데 유용하게 활용

데이터의 양이 많을수록 시각화를 통해 의미 있는 정보를 더 잘 파악할 수 있습니다. 날씨 데이터는 기상 자료 개방 포털(data.kma.go.kr)에서 다운로드할 수 있습니다.

산점도 (Scatter Plot)

두 속성 사이의 관계는 그래프에서 어떻게 드러날까?

데이터 속성 간의 관계(상관관계)를 시각화하는 대표적인 방법입니다.

산점도란?

x축과 y축 두 값이 만나는 위치에 점을 표시하여 두 축 간의 관계를 나타내는 방법입니다. 강도와 이상치(outlier) 등을 확인할 수 있으며, 기계학습에서 독립 변수와 종속 변수의 관계를 파악하는 데 적절합니다.

이상치(outlier)란?

관측된 데이터의 범위에서 많이 벗어난 아주 작은 값이나 아주 큰 값을 말합니다. 산점도에서 대부분의 점과 멀리 떨어진 점이 이상치입니다.

🔬 실습 사례 — 산점도로 이상치 찾기 (감귤 당도 데이터)

오렌지(Orange) 프로그램의 Scatter Plot 위젯으로 x축을 '조사 일자', y축을 '당도'로 지정해 감귤 당도 데이터를 시각화하면, 대부분의 점과 멀리 떨어진 점을 발견할 수 있습니다. 예를 들어 일반적인 감귤의 당도 변화 폭을 크게 벗어난 값이 측정되었다면, 이 값은 이상치일 가능성이 높습니다. 산점도와 박스 플롯(Box Plot)을 함께 활용하면 이러한 이상치를 눈으로 쉽게 확인할 수 있습니다.

예시: 과목별 성적과 등급의 산점도

국어 성적과 영어 성적이 각각 전체 등급과 어떤 상관관계를 갖는지 산점도로 비교합니다.

(a) 국어 성적 × 등급

상관관계 높음 — 국어 성적이 높을수록 등급이 우수한 편. 이상치가 적어 선형 패턴이 뚜렷합니다.

(b) 영어 성적 × 등급

상관관계 낮음 — 전체 등급은 높은데 영어 성적이 낮은 이상치가 존재. 국어보다 상관 정도가 낮습니다.

핵심 해석: 국어 성적이 등급과 더 높은 상관관계를 보이므로, 등급을 예측하는 데 국어 성적이 더 많은 영향을 미치는 속성(독립 변수)임을 알 수 있습니다. 산점도는 기계학습에서 핵심 속성을 찾는 데 매우 유용합니다.

그 외의 시각화 — 워드 클라우드

워드 클라우드(Word Cloud)를 이용하면 SNS 댓글이나 긴 텍스트 데이터 속에 포함된 주요 의미를 한눈에 파악할 수 있습니다. 자주 등장하는 단어일수록 크게 표시됩니다.

예) 수능 필적 확인 문구 워드 클라우드 → 수험생에 대한 응원 메시지 파악

참고

데이터 시각화로 속성의 역할을 알 수 있을까?

데이터 시각화를 통해 기계학습에 많은 영향을 미치는 속성을 파악할 수 있습니다.

아래 붓꽃 시각화·특성 통계표 절은 참고 자료입니다. 2015 개정 교육과정에서 다루던 내용으로, 2022 개정 「인공지능 기초」 교과서에는 실려 있지 않습니다. 평가 범위가 아니며, 수업 상황에 따라 심화·보충 자료로 활용하세요.

더 알아보기: 붓꽃 데이터 시각화로 핵심 속성 찾기

붓꽃 데이터에서 꽃받침과 꽃잎의 속성으로 산점도를 나타내면 어떤 속성이 붓꽃의 품종을 더 잘 구분할 수 있는지를 눈으로 확인할 수 있습니다. 오렌지 프로그램을 이용하여 붓꽃의 네 가지 속성을 조합한 6가지 산점도를 살펴봅시다.

품종 범례: Iris-setosa Iris-versicolor Iris-virginica
(a) 꽃받침 길이 × 꽃받침 너비
구분 어려움

꽃받침 속성만으로는 세 가지 붓꽃 품종이 분명하게 구분되지 않습니다.

(b) 꽃잎 길이 × 꽃잎 너비
구분 잘 됨 ★

꽃잎 속성으로 시각화하면 붓꽃 품종이 뚜렷하게 구분됩니다.

(c) 꽃받침 너비 × 꽃잎 너비

꽃잎 너비를 한 축으로 사용하면 품종 구분이 어느 정도 가능합니다. 꽃받침도 품종 구분에 영향을 미치는 속성임을 확인할 수 있습니다.

(d) 꽃잎 길이 × 꽃받침 길이

꽃잎 길이를 포함한 조합에서도 품종 구분이 가능합니다. 꽃잎 길이가 분류에 중요한 역할을 합니다.

(e) 꽃잎 길이 × 꽃받침 너비

꽃잎 길이와 꽃받침 너비의 조합으로도 붓꽃 품종을 구분할 수 있어, 꽃받침도 분류에 기여함을 알 수 있습니다.

(f) 꽃받침 길이 × 꽃잎 너비

꽃잎 너비를 포함하면 품종 구분이 나타납니다. 꽃잎과 꽃받침 속성의 조합으로 시각화하면 품종 구분이 가능합니다.

산점도 분석 결론

더 중요한 속성

꽃잎 길이(PetalLengthCm)와 꽃잎 너비(PetalWidthCm)가 붓꽃 품종 분류에 더 중요한 속성입니다.

꽃받침도 유효

꽃잎뿐만 아니라 꽃받침도 품종을 구분하는 데 영향을 미치는 속성입니다. 조합에 따라 품종 구분이 가능합니다.

데이터를 시각화하면 기계학습에 영향을 미치는 핵심 속성을 추출할 수 있습니다.

참고

특성 통계표

속성값의 분포만 보고도 품종을 구분할 수 있을까?

속성값의 분포를 히스토그램으로 나타내어 품종 구분 능력을 확인합니다.

더 알아보기: 특성 통계표와 히스토그램 읽는 법

특성 통계표(Feature Statistics)란?

값의 분포를 시각적으로 확인할 수 있도록 속성값의 점수 분포를 막대 모양의 히스토그램으로 나타냅니다. 오렌지 프로그램의 '분포(Distribution)' 기능에서 확인할 수 있습니다.

히스토그램(Histogram)이란?

데이터의 빈도를 직사각형 모양의 막대그래프로 나타낸 것으로, 데이터의 빈도가 높을수록 막대의 높이가 높아집니다. 주로 데이터의 분포를 표현할 때 사용됩니다. 일반 막대그래프와 달리 막대 사이에 공백이 없습니다.

특성 통계표 해석

꽃잎 길이로 품종 구분하기 쉬운 이유

  • Iris-setosa: 꽃잎 길이 가장 짧음 (1.0~2.0cm)
  • Iris-versicolor: 중간 (3.0~5.0cm)
  • Iris-virginica: 가장 긺 (4.5~6.9cm)

주의: 약간 겹치는 구간 존재

3.95~4.54 cm 구간에는 Iris-versicolor와 Iris-virginica가 약간 섞여 있어 이 구간에서는 꽃잎 길이만으로 완벽하게 구분하기 어렵습니다.

결측치(Missing Value)란?

데이터에서 누락된 값을 말합니다. 특성 통계표에서 결측치 0(0%)은 해당 속성에 누락된 데이터가 없다는 의미입니다. 결측치가 있으면 기계학습 전 처리가 필요합니다.

오렌지 프로그램으로 실습하기

코딩 없이 데이터를 분석하려면 어떤 도구를 쓸 수 있을까?

오렌지(Orange)는 기계학습 및 데이터 시각화에 유용한 도구로, 코딩 없이 데이터를 분석할 수 있습니다.

오렌지 프로그램이란?

초보자뿐 아니라 전문 데이터 과학자에게도 훌륭한 데이터 마이닝 도구입니다. 위젯(Widget)이라는 구성 요소를 워크플로(Workflow)에 연결하는 방식으로 복잡한 데이터 분석을 간단하게 구성할 수 있습니다. 사용자는 코딩 대신 데이터 분석에 집중할 수 있습니다.

붓꽃 데이터 시각화 실습 4단계

1

오렌지 프로그램 설치

오렌지(orangedatamining.com) 웹 사이트에서 프로그램을 다운로드하여 설치합니다.

2

File 위젯으로 데이터 불러오기

Data 목록에서 File 위젯을 캔버스에 드래그하여, 캐글에서 다운로드한 붓꽃 데이터 파일(Iris.csv)을 불러옵니다.

3

속성 역할 설정

File 위젯을 더블 클릭하여 각 속성의 역할을 설정합니다.

feature: 꽃받침·꽃잎 길이/너비 target: Species(품종) meta: Id(일련번호)
4

Data Table로 데이터 확인 후 Scatter Plot 연결

Data Table 위젯으로 속성값을 확인한 뒤, Scatter Plot 위젯을 연결하여 x축·y축 속성을 선택하고 품종별로 다른 색으로 시각화합니다.

메타 meta 예측에 직접 영향을 주지는 않지만 데이터를 구성하는 데 필요한 값 Id (일련번호)
무시 skip 데이터를 예측하는 데 상관 없는 값을 처리할 때 사용. 데이터 테이블에서 보이지 않음 —

일련번호는 meta로 설정하면 데이터 테이블에서도 확인할 수 있습니다. skip으로 설정하면 테이블에서 사라집니다.

AI와 함께 정리하기

Q.

데이터 속성은 무엇이고, 데이터 시각화는 기계학습에 어떻게 활용될까?

A.

데이터 속성은 다른 데이터와 구별 가능한 성질이며, 데이터의 속성을 시각화함으로써 기계학습에 필요한 핵심 속성을 쉽게 찾을 수 있습니다. 즉, 종속 변수에 영향을 주는 독립 변수를 찾는 데 유용하게 활용됩니다.

막대·선그래프

비교(막대)와 추이(선)를 목적에 맞게 선택

산점도

속성 간 관계·상관관계 파악, 핵심 독립 변수 발견

특성 통계표

히스토그램으로 속성값 분포와 품종 구분력 확인

핵심 정리

시각화 방법

  • 막대그래프: 상대적 크기 비교
  • 선그래프: 시간에 따른 변화 추이
  • 산점도: 속성 간 관계·상관관계
  • 워드 클라우드: 텍스트 핵심 의미

붓꽃 데이터 시각화

  • 꽃잎(PetalLength/Width) → 품종 구분에 더 유리
  • 꽃받침도 품종 구분에 영향
  • 특성 통계표로 분포 추가 분석

시각화와 기계학습

  • 시각화 → 핵심 속성(독립 변수) 발견
  • 상관관계 높은 속성 → 기계학습에 더 유리
  • 오렌지 프로그램으로 시각화 실습 가능
