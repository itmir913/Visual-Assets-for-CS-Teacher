데이터 전처리 점검표

해결하려는 문제와 데이터의 특성에 따라 필요한 전처리 과정이 다릅니다. 아래 세 가지 질문에 따라 점검하고, 문제가 있는 데이터는 삭제하거나 대체 값을 입력하여 처리합니다.

데이터에서 발생하는 문제

결측치 (Missing Value)

데이터에서 누락된 값을 말합니다.
예) 시험 결석으로 성적 데이터가 없는 경우, 비가 오지 않아 강수량 값이 기록되지 않은 경우

처리 방법

  • 결측치가 있는 데이터 삭제
  • 숫자형은 평균값·중앙값, 범주형은 최빈값으로 대체
  • 특정 값(예: 0)으로 고정하여 대체
  • 다른 속성과의 상관관계·분포를 이용해 값을 생성해 대체
  • 임의의 값으로 대체 (결측치가 많을 때, 신중히 선택)

결측치가 지나치게 많으면 데이터의 신뢰도가 떨어질 수 있으므로, 필요한 경우 데이터를 다시 수집하거나 삭제 대신 다른 대체 방법을 고려합니다.

이상치 (Outlier)

정상적인 데이터의 분포 범위 밖에 있어 실제로는 발생하기 어려운 값을 말합니다.
예) 키 데이터에서 300cm처럼 극단적인 값

탐지·처리 방법

  • 산점도·박스 플롯으로 시각화하거나 Outliers 위젯으로 탐지(민감도 조절 가능)
  • 해당 데이터 삭제
  • 평균값·중앙값으로 대체
  • 원인을 파악해 실제 발생 가능한 값인지 신중하게 판단

이상치 판단은 맥락에 따라 달라집니다

이상치 아님 — 기상 데이터

강수량·기온·일조일사 데이터에서 정상 범위를 크게 벗어난 값이 탐지되어도, 실제 기상 이변으로 발생할 수 있는 값이라면 이상치로 처리하지 않습니다.

이상치 처리 — 감귤 당도 데이터

당도가 0으로 기록된 값은 실수로 잘못 입력되었을 가능성이 크므로, 산점도와 박스 플롯으로 확인한 뒤 이상치로 판단해 처리합니다.

스스로 활동 — 결측치 확인 및 처리 방법 정리하기

제주-성산의 기상 데이터와 감귤 당도 데이터를 오렌지3의 Feature Statistics 위젯으로 확인하여 결측치 유무와 처리 방법을 정리해 봅시다.

전처리(Preprocessing)란?

데이터를 기계학습에 적합한 형태로 만드는 작업을 말합니다.
노이즈 제거, 중복값 삭제, 결측치 보정 등의 정제 작업이 포함되며,
전처리를 한 데이터는 기계학습 성능 향상에 큰 영향을 미칩니다.

데이터 유형에 따른 전처리 방법 비교

구분 정형 데이터 비정형 데이터
예시 시험 성적, 고객 정보 이미지, 음성, 텍스트
결측치 처리 결석생 데이터 삭제 또는 인정 점수 부여 해당 파일 제거
수치화 필요성 이미 수치 또는 카테고리로 구성 숫자 배열(임베딩)로 변환 필요
대표 전처리 정규화, 표준화, 결측치 보정 임베딩(Embedding), 크기 조정

더 알아보기 — 데이터 정규화와 표준화

더 알아보기: 정규화와 표준화는 어떻게 계산할까

여러 특성을 가진 데이터를 함께 사용할 때, 특성마다 값의 크기나 범위가 크게 다르면 특정 특성이 학습에 지나치게 큰 영향을 줄 수 있습니다. 이 문제를 해결하기 위해 정규화나 표준화를 수행합니다.

정규화 (Normalization)

데이터값을 0에서 1 사이로 변환하여 모든 값이 같은 범위에 있도록 만드는 방법입니다. 가장 널리 쓰이는 방식은 최소-최대 정규화입니다.

예) 수행평가 점수(0~100점) → 0~1 사이의 값으로 변환

표준화 (Standardization)

데이터의 평균을 0, 표준 편차를 1로 맞추어 값들이 정규 분포를 따르도록 변환하는 방법입니다. 값이 평균에서 얼마나 떨어져 있는지를 나타냅니다.

표준화된 값 = (원래 값 − 평균) ÷ 표준 편차

오렌지3에서는 [Transform] → Preprocess 위젯의 Normalize Features 메뉴로 정규화와 표준화를 수행할 수 있습니다.

더 알아보기 — 범주형 변수의 인코딩

더 알아보기: 더미 인코딩과 순서 인코딩

성별, 학력 수준처럼 숫자로 나타낼 수 없는 범주형 변수는 기계학습 모델에 바로 사용할 수 없으므로 수치형 변수로 변환해야 합니다. 대표적인 방법으로 더미 인코딩과 순서 인코딩이 있습니다.

더미 인코딩 (Dummy Encoding)

각 범주마다 새로운 열(변수)을 만들고, 해당 범주에 속하면 1, 속하지 않으면 0으로 표시합니다.

예) 성별이 '남성'인 경우 → 남성 열 = 1, 여성 열 = 0

순서 인코딩 (Ordinal Encoding)

순서나 계층을 가진 범주형 변수의 값을 순서에 따라 정수로 변환합니다.

예) 옷 사이즈 S → 1, M → 2, L → 3

오렌지3에서는 [Data] → Edit Domain 위젯에서 검색할 키(key)와 교체할 값(Value)을 입력해 범주형 변수를 인코딩할 수 있습니다.

이미지 데이터를 어떻게 처리할까?

오렌지(Orange3) 프로그램으로 이미지 데이터를 전처리해 봅시다.

오렌지(Orange3) 프로그램 실습

총 5단계로 이미지 데이터를 수집, 입력, 확인, 전처리하는 과정을 실습합니다.

1

이미지 데이터 세트 다운로드

이미지 데이터 세트를 제공하는 캐글(Kaggle) 사이트에서 분리수거(재활용) 이미지 데이터를 다운로드합니다.
검색창에 Bottles and Cans Images를 입력하여 데이터 세트를 찾습니다.

Bottles and Cans Images Dataset

페트병 용량별(500ml~2,000ml) 이미지와 캔 이미지로 구성된 총 1,075개의 이미지(단위 'cl'은 1cl당 10ml)

폴더 구성

  • train data/ — 학습용 이미지(pet, can 하위 폴더)
  • test data/ — 테스트용 이미지(pet, can 하위 폴더)

전처리 기준

  • bottle_50cl과 can 이미지만 선택하고 나머지는 제거
  • 화질이 낮거나 식별이 어려운 이미지 삭제
  • 파일명을 pet1, pet2 … / can1, can2 …로 정리

🥤

🥫

선택한 이미지 중 페트병(bottle_50cl) 데이터가 240개, 캔 데이터가 56개로 개수 차이가 큽니다. 그대로 학습하면 페트병 쪽으로 편향된 모델이 만들어질 수 있으므로, 두 범주의 데이터 수를 비슷하게 맞춘 뒤 7:3 비율로 train data 폴더와 test data 폴더에 나누어 저장합니다.

이미지 데이터 입력 및 확인

① Import Images 위젯으로 폴더 업로드

[Image Analytics] 목록에서 Import Images 위젯을 선택하고 train data 폴더를 업로드합니다.
위젯의 Info 창에 84 Images / 2 Categories라고 표시되면 성공입니다.

확인: 84 images / 2 categories(pet, can)

② Image Viewer 위젯으로 이미지 확인

Image Viewer 위젯을 선택한 후 드래그하여 Import Images 위젯과 연결합니다.
위젯을 열면 84개의 페트병·캔 이미지가 잘 입력되어 있는지 확인할 수 있습니다.

③ Data Table 위젯으로 속성 확인

[Data] 목록에서 Data Table 위젯을 선택하고 Import Images 위젯과 연결합니다.
84개 이미지 데이터가 테이블 형태로 표현됩니다.

속성(컬럼) 내용
category 범주 (pet / can)
image name 이미지 파일 이름 (pet1, pet2 … / can1, can2 …)
size / width / height 이미지 파일 크기와 가로·세로 픽셀 수(파일마다 다름)

이 값들은 이미지 데이터의 속성(특징)이 아니라 각 이미지에 대한 사전 정보(메타데이터)입니다.

메타데이터(Metadata)란?

데이터에 대한 데이터를 말합니다. '어떤 목적을 가지고 만들어진 데이터'라고도 합니다.
예를 들어, 스마트폰으로 사진을 찍으면 촬영 시간, 해상도, 크기 등의 정보가 사진과 함께 저장되는데,
이러한 정보가 바로 메타데이터입니다.

Data Table에서 확인한 category, image name, size, width, height는 모두 이미지의 메타데이터입니다.

이미지의 픽셀 정보, 색상, 패턴 등이 숫자로 표현됩니다.

Embedder 설정 — VGG-16 선택

Image Embedding 위젯에서 데이터의 특성에 적합한 Embedder를 선택합니다. 여기서는 이미지넷(ImageNet)에서 훈련된 합성곱 신경망(CNN)을 적용한 16계층 이미지 인식 모델 'VGG-16'을 선택하여 임베딩을 수행합니다.

Embedder 설명
SqueezeNet 이미지넷에서 훈련된 작고 빠른 이미지 인식 모델
Inception v3 이미지넷 데이터 세트에서 78.1% 이상의 정확도를 보이는 이미지 인식 모델
VGG-16/19 이미지넷에서 훈련된 합성곱 신경망을 적용한 16/19계층 이미지 인식 모델
Painters 예술 작품의 그림에서 화가를 예측하도록 훈련된 모델
DeepLoc 효모나 세포 이미지를 분석하도록 훈련된 모델
openface 사람의 얼굴을 분석하도록 훈련된 모델

Q. 기계학습에서 데이터 처리는 왜 필요할까?

A. 데이터를 기계학습에 적합한 형태로 만들기 위해 전처리 작업이 필요합니다. 정형 데이터와 비정형 데이터에 따라 다른 전처리 방법이 사용되며, 전처리를 한 데이터는 데이터 분석의 성과뿐만 아니라 기계학습 성능 향상에도 큰 영향을 미칩니다.

핵심 용어

  • 결측치 — 누락된 값
  • 이상치 — 범위를 벗어난 값
  • 전처리 — 기계학습에 적합하게 가공

이미지 처리 흐름

  • ① 캐글에서 데이터 다운로드
  • ② Import Images로 입력
  • ③ Image Embedding으로 변환

임베딩 결과

  • 이미지 → 숫자 배열(벡터)로 변환
  • Embedder로 특징 추출
  • VGG-16 등 CNN 기반 모델 활용
