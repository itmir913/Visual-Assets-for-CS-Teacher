기계학습에서 데이터를 정해진 레이블로 나누는 분류 모델을 알아봅시다.

분류 모델의 정의

분류 모델 (Classification Model)

기계학습 중 지도 학습의 한 가지 방법으로, 레이블이 있는 훈련 데이터를 학습한 후
새로 입력한 데이터가 학습했던 데이터 중에서 어느 레이블에 속하는지를 찾는 모델입니다.
분류 모델의 결괏값은 학습했던 데이터의 레이블 중 하나가 됩니다.

분류 모델의 종류

k-최근접 이웃 (k-NN)

새로운 데이터가 들어왔을 때, k개의 가까운 이웃을 보고 어떤 카테고리로 분류할지 결정합니다.

k=5이면 가장 가까운 5개 이웃 중 다수의 레이블로 분류

로지스틱 회귀

여러 독립 변수를 결합하여 사건의 발생 가능성(확률)을 예측하는 데 사용합니다.

독립 변수: 연속형 / 종속 변수: 범주형일 때 적합

의사결정트리

스무고개 게임처럼 질문을 한 번에 하나씩 던지며 예/아니요로 가지를 나누어 데이터를 분류합니다.

데이터를 가장 잘 구분하는 질문을 맨 위(루트 노드)에 배치

인공 신경망

입력 층과 출력 층 사이에 여러 개의 은닉 층을 두고 학습하며, 실젯값과 예측값의 오차를 최소화합니다.

입력 층 → 은닉 층(들) → 출력 층

분류 모델 가상 예시 — 감기 분류 모델

환절기에 사람마다 나타나는 증상 데이터(기침, 콧물, 오한, 체온)를 수집하여 감기 환자인지 정상인지 분류하는 모델을 만들 수 있습니다.

훈련 데이터

분류 모델

감기 70% / 정상 30% 예측

분류 결과

감기 환자 / 정상인

k-NN 알고리즘의 분류 절차

①

분류하고 싶은 데이터와 기존 데이터 사이의 거리 계산

②

가까운 순서대로 나열

③

가장 가까운 k개 중 레이블별 빈도 세기

④

최다 빈도 레이블 값 반환

거리 계산에는 피타고라스 정리가 사용됩니다. 예: 두 점 (1,2)와 (5,5) 사이의 거리 = √((5-1)² + (5-2)²) = √25 = 5

의사결정트리의 구조와 분류 절차

더 알아보기: 의사결정트리는 어떤 순서로 질문할까

의사결정트리는 입력값을 이용해 스무고개 게임처럼 한 번에 하나씩 질문을 던지며 정답을 찾아가는 방식으로 데이터를 분류합니다. 질문의 순서(분할 기준)는 트리의 성능에 큰 영향을 미치므로, 데이터를 가장 잘 구분하는 속성을 첫 번째 질문(루트 노드)으로 정해야 합니다. 만약 덜 중요한 속성을 먼저 질문하면 트리가 데이터를 효과적으로 구분하지 못하게 됩니다.

트리가 완성되면 새로 입력된 데이터를 맨 위 질문부터 '예/아니요'에 따라 아래로 내려가며 분류합니다. 예를 들어 '날개가 있나요?'에 예, '날 수 있나요?'에 예라고 답하면 매라는 잎 노드(leaf node)에 도달합니다.

장점 — 해석 가능성

각 분기점이 명확한 질문으로 이루어져 있어 매우 직관적이고 시각적으로 이해하기 쉽습니다. 왜 특정 결론에 도달했는지 쉽게 설명할 수 있습니다.

한계 — 과적합

가지를 너무 많이 만들면 훈련 데이터에만 지나치게 잘 맞춰져 새로운 데이터에서는 잘 작동하지 않는 과적합(overfitting)이 발생할 수 있습니다. 가지치기(pruning)나 트리 깊이 제한으로 완화합니다.

오렌지(Orange3) 프로그램 실습 — 붓꽃(Iris) 데이터 분류

아래 단계별 설정값과 정확도(96.7%) 등의 수치는 오렌지 실습 과정을 이해하기 위한 예시이며, 실제 데이터와 실습 환경에 따라 결과는 달라질 수 있습니다.

붓꽃 데이터 세트 (Iris Dataset)

붓꽃 데이터는 꽃잎과 꽃받침 부위를 측정한 값과 품종을 속성으로 가지는 정형 데이터입니다. 전체 150개 데이터 중 약 70%를 훈련 데이터로 학습하고 30%를 테스트합니다.

속성 유형 역할 예시 값
Id 수치형 meta 1, 2, 3 …
sepal length (꽃받침 길이) 연속형 feature 5.1, 4.9 …
sepal width (꽃받침 너비) 연속형 feature 3.5, 3.0 …
petal length (꽃잎 길이) 연속형 feature 1.4, 1.3 …
petal width (꽃잎 너비) 연속형 feature 0.2, 0.4 …
species (품종) 범주형 target setosa / versicolor / virginica

feature(독립 변수)는 분류에 영향을 미치는 속성, target(종속 변수)은 예측하려는 레이블을 의미합니다.

꽃잎 길이와 꽃잎 너비를 조합했을 때 세 품종의 분포가 가장 명확하게 구분됩니다.

❹ 분류 모델은 어디에 적용될까?

스팸 메일 분류

이메일에서 스팸 메일과 정상 메일을 이항 분류로 자동 분류합니다.

주변의 물체를 인식하여 자동차, 사람, 신호등 등을 자동으로 분류합니다.

감정 인식

영화 리뷰

AI와 함께 똑똑 정리하기

Q. 분류 모델이란 무엇이며, 어떻게 동작할까?

A. 분류 모델은 지도 학습의 한 방법으로, 레이블이 있는 훈련 데이터로 학습한 후 새로운 데이터를 입력받아 해당 레이블을 예측합니다. k-NN, 로지스틱 회귀, 의사결정트리, 인공 신경망 등 다양한 알고리즘이 사용되며, 정형 데이터와 비정형 데이터 모두 분류할 수 있습니다.

핵심 용어

  • 분류 모델 — 레이블 예측 지도 학습
  • k-NN — k개 이웃으로 분류
  • 로지스틱 회귀 — 확률적 분류
  • 의사결정트리 — 질문으로 가지를 나누어 분류

오렌지 실습 흐름

  • ① 훈련 데이터 준비
  • ② 데이터 시각화·속성 설정
  • ③ 모델 학습 → 테스트 → 분류

비정형 데이터 분류

  • 이미지 → Image Embedding
  • 숫자 배열 → 로지스틱 회귀
  • Predictions로 결과 확인
