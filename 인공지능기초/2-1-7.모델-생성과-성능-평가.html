Section 1

인공지능으로 어떤 문제를 해결할까?

핵심 개념

인공지능은 인식이나 추론, 학습 같은 방법으로 문제를 해결하기에 적합하다. 따라서 모든 문제에 인공지능을 적용하는 것이 좋은 것은 아니며, 문제의 특성에 따라 적합한 해결 방법을 선택해야 한다.

전통적인 문제 해결

  • 수식이나 규칙으로 표현 가능
  • 데이터가 달라져도 해결 방법이 변하지 않음
  • 알고리즘이 명확히 존재

예시

불꽃지수 계산 놀이공원 입장료 랜덤 발표 순서

인공지능을 적용한 문제 해결

  • 데이터가 많고 규칙이 계속 달라짐
  • 인식·추론·학습이 필요한 문제
  • 수많은 데이터에서 패턴을 자동으로 찾음

예시

스팸 메일 분류 자율주행 자동차 음성 인식

Section 2

기계학습으로 어떻게 문제를 해결할 수 있을까?

기계학습 모델 구현 과정은 문제 정의에서 모델 활용까지의 5단계로 구성된다. 이 단계는 반드시 순서대로 한 번만 진행하는 것이 아니라, 필요에 따라 이전 단계로 돌아가 수정할 수 있다.

1

문제 정의

해결하고자 하는 문제가 인공지능으로 해결 가능한지 확인하고, 문제를 명확히 정의한다. 필요한 데이터가 무엇인지, 그것을 확보할 수 있는지 검토해야 한다.

분류 문제인지, 회귀 문제인지 결정 입력·출력 데이터 형태 파악
2

데이터 수집

정의된 문제에 적합한 대표성 있는 데이터를 수집한다. 데이터의 규모·형태·수집 방법을 고려하며, 수집한 데이터는 훈련 데이터와 테스트 데이터로 분리한다.

훈련 데이터 — 모델 학습에 사용
테스트 데이터 — 성능 평가에 사용

훈련 데이터와 테스트 데이터를 왜 나눌까?

모델이 훈련 데이터에만 과도하게 적응하면, 그 데이터에서는 잘 맞지만 새로운 데이터에서는 예측을 잘못하는 과적합(overfitting)이 발생할 수 있다. 훈련에 사용하지 않은 테스트 데이터로 성능을 확인해야 모델이 일반화(generalization) 능력을 갖췄는지 올바르게 평가할 수 있다. 일반적으로 전체 데이터를 훈련 데이터 7 : 테스트 데이터 3 (또는 8:2) 비율로 나눈다.

3

데이터 탐색

수집한 데이터의 핵심 속성을 파악한다. 수치 데이터는 이상치 여부를 확인하고, 이미지·텍스트 데이터는 전처리 방법을 결정한다.

정형 데이터 — 수치 이상치 확인, 결측치 처리
비정형 데이터(텍스트) — 코퍼스 구성, 전처리, 단어 모음 생성
4

모델링 및 성능 평가

훈련 데이터를 입력하여 기계학습 모델을 학습시키고, 테스트 데이터로 성능을 평가하여 적합한 모델을 선택한다.

과대적합 (Overfitting)

훈련 데이터에만 지나치게 최적화되어 새로운 데이터에 성능이 낮아지는 상태

→ 훈련 데이터 수 늘리기, 모델 복잡도 줄이기

과소적합 (Underfitting)

모델이 너무 단순하여 훈련 데이터에서도 좋은 성능을 보이지 못하는 상태

→ 더 복잡한 모델 선택, 충분히 학습시키기

5

모델 활용

모델링 및 성능 평가를 마치고 선택한 모델에 새로운 데이터를 입력하여 예측·분류 결과를 확인한다. 실제 인공지능 제품에 적용해 보는 단계이다.

훈련 데이터 (Training Data)

모델의 학습에 사용하는 데이터. 기계학습 모델은 훈련 데이터에서 패턴을 찾아 학습한다.

테스트 데이터 (Test Data)

학습을 마친 모델의 성능을 평가하기 위해 사용하는 데이터. 훈련에 사용하지 않은 새로운 데이터이다.

교차 검증 (Cross Validation)이란?

훈련 데이터의 일부를 여러 번 나누어 검증 데이터로 사용하는 방법이다. k-폴드 교차 검증(k-fold Cross Validation)의 경우, k=5이면 전체 훈련 데이터를 5등분하여 한 번씩 검증 데이터로 사용하고 나머지로 학습하는 과정을 5번 반복한다. 고정된 테스트 데이터로 인해 성능이 오히려 떨어지는 것을 개선하기 위해 사용한다.

(Precision)		 TP / (TP + FP) 50 / (50+2) ≈ 0.962 스팸으로 판정한 것 중 실제 스팸 비율
재현율
(Recall)		 TP / (TP + FN) 50 / (50+8) ≈ 0.862 실제 스팸 중 스팸으로 올바르게 판정한 비율
F1-점수
(F1 Score)		 2 × (정밀도×재현율) / (정밀도+재현율) 정밀도와 재현율의 조화 평균 두 지표가 모두 높을 때 F1도 높아짐

정밀도가 중요한 경우

정상 메시지를 스팸으로 잘못 판단하면 중요 메시지를 놓칠 수 있는 경우. 스팸 분류 문제에서 정밀도를 중요 지표로 삼는다.

재현율이 중요한 경우

실제 양성(예: 금융 사기 탐지)을 음성으로 잘못 판단하면 큰 손해. 금융 사기 탐지 같은 문제에서 재현율을 중요 지표로 삼는다.

회귀 모델의 성능 평가 지표

더 알아보기: 회귀 모델의 오차 지표(MSE·RMSE·MAE·R²)

선형 회귀처럼 연속적인 값을 예측하는 회귀 모델은 예측값과 실제값의 차이인 오차(error)를 기준으로 성능을 평가한다. 이산화탄소 배경 대기 농도 예측 실습에서도 아래 지표로 모델의 성능을 확인했다.

지표 의미 좋은 모델의 조건
평균제곱오차
(MSE)		 예측값과 실제값 차이를 제곱하여 평균한 값 값이 0에 가까울수록 좋음
평균제곱근오차
(RMSE)		 MSE의 제곱근. 오차가 커지는 것을 방지해 원래 단위로 해석하기 쉽게 한 값 값이 작을수록 좋음
평균절대오차
(MAE)		 예측값과 실제값 차이의 절댓값을 평균한 값 값이 작을수록 좋음
결정 계수
(R²)		 예측값이 종속 변수의 분산을 얼마나 잘 설명하는지 나타내는 지표 값이 1에 가까울수록 좋음
MSE·RMSE는 오차를 제곱하기 때문에 큰 오차(극단값)에 민감하고, MAE는 오차 크기를 그대로 반영해 전반적인 정확도를 보여 준다. 한 가지 지표만 보기보다 여러 지표를 함께 살펴보는 것이 좋다.

AI와 함께 똑똑 정리하기

Q. 기계학습 모델 구현 과정은 어떻게 구성될까?

A. 문제 정의 → 데이터 수집 → 데이터 탐색 → 모델링 및 성능 평가 → 모델 활용의 5단계로 구성된다. 각 단계는 반드시 순서대로 한 번에 끝내는 것이 아니라, 성능이 충분하지 않으면 이전 단계로 돌아가 수정할 수 있다. 훈련 데이터와 테스트 데이터를 나누는 것은 과적합을 막고 일반화 성능을 확인하기 위해서이다.

핵심 용어

  • 훈련 데이터 — 모델 학습에 사용
  • 테스트 데이터 — 성능 평가에 사용
  • 과적합 — 훈련 데이터에만 최적화
  • 일반화 — 새 데이터에서도 잘 작동

분류 성능 지표

  • 정확도(CA) — 전체 정답 비율
  • 정밀도 — 양성 판정 중 실제 양성
  • 재현율 — 실제 양성 중 발견율
  • F1-점수 — 정밀도·재현율 조화 평균

회귀 성능 지표

  • MSE·RMSE·MAE — 작을수록 좋음
  • 결정 계수(R²) — 1에 가까울수록 좋음

오렌지 실습 흐름

  • 스팸 분류: Bag of Words → Neural Network → Test and Score → Predictions
  • CO₂ 예측: Linear Regression → Test and Score(k-fold) → 오차·결정 계수 확인
