❶ 컴퓨터 비전 (Computer Vision)이란?

컴퓨터가 사진에서 의미 있는 정보를 뽑아내는 기술

사람이 눈으로 사물을 보고 "이건 사과네!", "저건 고양이네!"라고 알아채는 것처럼, 컴퓨터가 사진이나 영상(이미지)에서 의미 있는 정보를 뽑아내고 인식하는 기술을 연구하는 분야를 컴퓨터 비전이라고 합니다.

이 중에서 사진 속 장소, 물체, 사람 등을 알아맞히는 것을 '이미지 인식(Image Recognition)'이라고 부르며, 컴퓨터 비전의 가장 대표적인 기술입니다.

얼굴 인식 잠금 해제 스마트폰이 주인의 얼굴을 알아봅니다.
자율주행 자동차 카메라로 차선, 신호등, 보행자를 봅니다.

❷ 딥러닝은 이미지를 어떻게 학습할까?

사람이 특징을 찾아 주던 방식에서, 인공신경망이 스스로 특징을 학습하는 방식으로

지난 시간에 배운 심층 신경망(DNN)을 이미지 데이터에 특화시킨 알고리즘이 합성곱 신경망(CNN, Convolution Neural Network)입니다. 딥러닝을 활용한 컴퓨터 비전은 이 인공신경망을 사용하여 이미지 데이터의 특징을 모델이 스스로 학습하고 해석합니다.

전통적인 컴퓨터 비전

사람이 직접 이미지 데이터의 특징(모서리, 색상 등)을 추출하는 규칙을 정하고, 그 규칙으로 모델을 학습시키는 방식입니다.

딥러닝 기반 컴퓨터 비전 (CNN)

인공신경망이 수많은 데이터를 반복 학습하며 특징을 스스로 찾아냅니다. 충분한 데이터로 학습하면 사물 인식뿐 아니라 상황적 맥락까지 이해할 수 있습니다.

생각해보기

케이크와 선물 앞에서 웃고 있는 소년의 사진을 컴퓨터 비전으로 분석한다고 합시다. 전통적인 방식은 '소년', '케이크' 같은 개별 사물만 인식하지만, 딥러닝 기반 CNN은 사물 사이의 관계와 배경까지 분석해 "생일을 축하하는 상황"이라는 더 높은 수준의 맥락을 이해할 수 있습니다. 두 방식이 같은 사진을 어떻게 다르게 해석할지 짝과 이야기해 봅시다.

컴퓨터 비전에 쓰이는 대표 이미지 데이터 세트

  • MNIST — 0~9까지 손글씨 사진 (학습용 60,000개 / 테스트용 10,000개)
  • CIFAR-10 — 10개 클래스의 사물 사진 (학습용 50,000개 / 테스트용 10,000개)
  • ImageNet — 물체 인식 대회(ILSVRC)에 쓰이는 대규모 이미지 데이터 세트

딥러닝을 활용한 컴퓨터 비전 문제 해결 사례

의료 영상 분석

X-ray, MRI 같은 의료 영상을 분석해 폐렴·암 같은 질병을 조기 진단합니다.

물체 검출

이미지 안에서 특정 물체의 위치를 찾아냅니다. 자율주행차의 차선·사람 검출 등에 쓰입니다.

세분화(Segmentation)

이미지 속 물체나 영역의 경계를 픽셀 단위로 나눕니다. 의료 영상, 자연환경 모니터링 등에 활용됩니다.

광학 문자 인식(OCR)

사진이나 영상 속 글자를 감지하고 번역합니다. 사람의 감독 없이도 임의의 텍스트를 읽어냅니다.

생성 모델

텍스트나 스케치를 입력하면 이미지를 만들어냅니다. 스타일 변환, 그림 생성 등에 쓰입니다.

영상 분석

동영상 속 움직임과 상호 작용을 분석해 행동을 예측·추적합니다. 지능형 CCTV, 스포츠 분석 등에 쓰입니다.

❸ 컴퓨터는 이미지를 숫자로 봅니다

컴퓨터는 사진 한 장을 무엇으로 바꾸어 이해할까?

이미지를 처리하기 위한 픽셀과 RGB

픽셀(Pixel)과 RGB

우리는 고양이 사진을 전체적인 형태로 보지만, 컴퓨터는 다르게 봅니다. 컴퓨터에게 이미지는 작은 점(픽셀)들이 모여 있는 거대한 바둑판(모자이크)과 같습니다.

각각의 픽셀은 빨강(R), 초록(G), 파랑(B) 빛이 얼마나 섞여 있는지 나타내는 숫자 데이터로 저장됩니다. 즉, 컴퓨터 비전은 수많은 숫자의 패턴을 계산해서 "아, 이 숫자 패턴은 고양이 모양이구나!"라고 알아맞히는 것입니다.

이미지 수집 ➔ 픽셀 데이터(숫자) 분석 ➔ 객체 탐지 및 인식

컴퓨터가 보는 세상
(숫자로 이루어진 픽셀)

RGB 값으로 색을 표현하는 방법

각 픽셀은 R(빨강), G(초록), B(파랑) 3개의 값으로 이루어지며, 각각 0~255 사이의 숫자로 표현됩니다. 이 세 숫자의 조합으로 1,600만 가지 이상의 색상을 만들 수 있습니다.

빨강 (R)

R: 255 / G: 0 / B: 0

초록 (G)

R: 0 / G: 255 / B: 0

파랑 (B)

R: 0 / G: 0 / B: 255

❹ 인공지능의 눈은 완벽할까?

인공지능도 사람과는 다른 치명적인 약점이 있습니다.

자주 하는 오해

"인공지능 카메라가 사람의 눈보다 훨씬 똑똑하고 완벽하다?"

아닙니다! 인공지능은 3차원 세상을 2차원 평면(사진)으로 바꾸어 계산하기 때문에 사람과는 다른 한계가 발생합니다.

인간 운전자의 인식 한계

  • 사각지대 (자동차 뒤에 있는 사람을 보지 못함)
  • 악천후 시 노면이 얼마나 미끄러운지 눈으로 정확히 측정하기 어려움
  • 피로, 졸음, 스마트폰 사용 등 부주의로 인한 인식 실패

자율주행 AI의 인식 한계

  • 생김새가 비슷한 물체를 구분하기 힘들어함
  • 2D 이미지로 3차원 공간의 원근감을 정확히 측정하기 어려움
  • '적대적 공격'에 취약함 (스티커 하나로 표지판을 착각함)

❺ 인공지능을 속이는 '적대적 공격'

사람 눈에는 똑같은 사진으로 인공지능을 속일 수 있을까?

AI가 오류를 일으키는 방식

참고 자료입니다. 2015 개정 교육과정에서 다루던 내용으로, 2022 개정 「인공지능 기초」 교과서에는 실려 있지 않습니다. 평가 범위가 아니며, 수업 상황에 따라 심화·보충 자료로 활용하세요.

더 알아보기: 적대적 공격은 어떻게 인공지능을 속일까

적대적 공격(Adversarial Attack)이란?

이미지에 사람 눈에는 잘 보이지 않는 미세한 조작(노이즈)을 가해서 인공지능이 완전히 엉뚱한 것으로 잘못 인식하게 만드는 해킹 방법입니다.

자율주행 자동차가 카메라로 '정지(STOP)' 표지판을 보았다고 가정해 봅시다. 공격자가 표지판에 특수한 무늬의 스티커 몇 개를 붙여놓으면, 사람 눈에는 여전히 '정지'로 보이지만 컴퓨터는 이를 '직진'이나 '속도 제한' 표지판으로 착각하고 멈추지 않아 큰 사고가 날 수 있습니다.

Q. 딥러닝은 컴퓨터 비전 문제를 어떻게 해결할까?

A. 이미지를 픽셀 단위의 R·G·B 숫자 값으로 바꾼 뒤, 합성곱 신경망(CNN)이 이 숫자 패턴 속 특징을 스스로 학습합니다. 이렇게 학습된 모델은 의료 영상 분석, 물체 검출, 세분화, OCR, 생성 모델, 영상 분석 등 다양한 문제를 해결하는 데 활용됩니다. 단, AI는 2D 이미지로 3D 깊이를 파악하기 어렵고 적대적 공격에 취약하다는 한계가 있습니다.

핵심 개념

  • 컴퓨터 비전 — 이미지 인식 기술
  • CNN — 이미지 특징을 스스로 학습하는 심층 신경망
  • 픽셀·RGB — 이미지를 숫자로 표현하는 방식

딥러닝 활용 사례

  • 의료 영상 분석 · 물체 검출 · 세분화
  • 광학 문자 인식(OCR) · 생성 모델
  • 영상 분석 (지능형 CCTV 등)

AI의 한계

  • 3D 원근감 측정 어려움
  • 유사 물체 구분 어려움
  • 적대적 공격에 취약
