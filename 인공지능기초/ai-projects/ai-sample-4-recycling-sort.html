문항 1. 문제 정의

실생활에서 AI로 해결하고자 하는 문제를 구체적으로 정의하시오.

분리수거를 하고 싶어도 어떤 쓰레기가 어느 통에 들어가는지 헷갈리는 경우가 많다. 특히 페트병 뚜껑, 음식이 묻은 플라스틱 용기, 복합 재질 포장지 등은 정확한 분류가 어려워 잘못 버려지는 일이 자주 발생한다. 쓰레기 사진을 찍으면 종이 / 플라스틱 / 유리 / 금속 / 일반 쓰레기 중 어디에 버려야 하는지 자동으로 알려주는 인공지능 모델을 만들어, 올바른 분리수거를 돕는 스마트 앱에 활용하고자 한다.

자기점검 체크리스트

  • ☑ 해결하고자 하는 문제가 실생활과 연관되어 구체적으로 제시되어 있다.
  • ☑ 문제가 발생하는 상황(불편함·필요성)이 명확하게 서술되어 있다.

문항 2. 모델 설명 (입력 → 출력)

어떤 데이터를 입력받아 어떤 결과를 출력하는지 서술하시오.

■ 입력: 쓰레기 사진 (스마트폰 카메라 또는 웹캠으로 촬영한 이미지) ■ 출력: 분류 레이블 + 신뢰도(%) — 종이 / 플라스틱 / 유리 / 금속 / 일반 쓰레기 카메라로 쓰레기를 비추면 모델이 재질을 분석하여 해당 물체를 어느 분리수거 통에 버려야 하는지를 레이블과 신뢰도로 즉시 출력한다. 예) 플라스틱 병: 플라스틱 93.2% / 유리 4.1% / 기타

자기점검 체크리스트

  • ☑ 입력 데이터가 명확히 제시되어 있다.
  • ☑ 모델이 출력하는 결과가 구체적으로 서술되어 있다.
  • ☑ 입력과 출력을 통해 모델의 역할이 명확하게 드러난다.

문항 3. 기계학습 유형 및 구현 도구 선택

① 기계학습 유형, ② 구현 도구를 선택하고 각각 이유를 서술하시오.

① 기계학습 유형: 지도학습 — 분류 이미지를 입력받아 5개의 정해진 분리수거 범주(클래스) 중 하나로 판별하는 것이므로 분류 모델이 적합하다. 각 이미지에 '종이/플라스틱/유리/금속/일반쓰레기' 레이블을 붙인 데이터로 학습하므로 지도학습이다. ② 구현 도구: 티처블머신 (Teachable Machine) 구글 이미지 검색으로 내려받은 사진과 직접 촬영한 사진을 티처블머신에 업로드하기만 하면 코딩 없이 모델을 만들 수 있다. 학습 완료 후 스마트폰 카메라와 연동하여 즉시 테스트 가능하다.

자기점검 체크리스트

  • ☑ 지도/비지도 학습 중 하나를 명확히 선택하였다.
  • ☑ 유형 선택 이유가 논리적으로 서술되어 있다.
  • ☑ 구현 도구 선택 이유가 기계학습 유형과 연결되어 설명되어 있다.

문항 4. 데이터 설명

데이터의 출처·유형·수량·특성을 작성하고, 스크린샷을 첨부하시오.

• 출처: 구글 이미지 검색(각 재질 검색) + 직접 촬영 혼합 • 유형: 이미지 데이터 (224×224px, JPG) • 수량: 클래스별 각 60장 / 총 300장 (5클래스) 클래스 1 — 종이(60장): 신문지, 박스, 종이컵, 전단지 클래스 2 — 플라스틱(60장): 페트병, 플라스틱 용기, 비닐봉투 클래스 3 — 유리(60장): 유리병, 깨진 유리조각 클래스 4 — 금속(60장): 캔, 알루미늄 포일, 철사 클래스 5 — 일반쓰레기(60장): 음식물 묻은 포장지, 이쑤시개, 담배꽁초 • 다양성 확보: 조명 조건, 배경색, 쓰레기 형태(접힌/펼쳐진) 다양화 ※ 스크린샷: 티처블머신 5개 클래스 이미지 업로드 화면 [실제 수행평가 시 첨부]

자기점검 체크리스트

  • ☑ 데이터의 출처가 명시되어 있다.
  • ☑ 데이터의 유형과 수량이 구체적으로 서술되어 있다.
  • ☑ 학습에 사용된 데이터 화면 스크린샷이 첨부되어 있다.

문항 5. 학습 결과

학습 완료 화면을 스크린샷으로 첨부하고, 결과의 의미를 설명하시오.

• 학습 설정: Epochs 50 / 배치 크기 16 / 학습률 0.001 (기본값) • 학습 완료 후 성능 (테스트셋 20% 기준) 전체 정확도: 89.3% 클래스별 정확도: 종이 94.2% / 플라스틱 88.7% / 유리 91.3% 금속 90.5% / 일반쓰레기 82.1% (가장 낮음 — 종류 다양) • 손실(Loss)이 낮아지며 안정적으로 학습 완료 • 실시간 미리보기에서 플라스틱 페트병을 카메라에 비추자 '플라스틱: 93%'로 즉시 반응 → 실시간 분류 확인 ※ 스크린샷: 학습 완료 화면(정확도·Loss 그래프) [실제 수행평가 시 첨부]

자기점검 체크리스트

  • ☑ 학습 완료 화면 또는 학습 결과 스크린샷이 첨부되어 있다.
  • ☑ 학습 결과 수치가 구체적으로 언급되어 있다.
  • ☑ 학습 결과의 의미가 서술되어 있다.

문항 6. 테스트 및 결과 분석

새로운 데이터로 테스트하고, 예상 결과와 실제 결과를 비교·분석하시오.

■ 테스트 1 — 투명 페트병 입력: 내용물이 비어있는 투명 페트병 사진 예상: 플라스틱으로 분류 실제 출력: 플라스틱 95.1% → 예상과 일치 ■ 테스트 2 — 음료가 든 캔 입력: 내용물이 반쯤 남은 알루미늄 음료 캔 예상: 금속으로 분류 실제 출력: 금속 71% / 플라스틱 21% → 신뢰도 낮음 ■ 분석 캔의 색상과 형태가 플라스틱 통과 비슷하게 학습된 것으로 보인다. 내용물이 들어 있는 상태의 이미지를 학습 데이터에 포함하지 않았던 점이 원인. 다양한 상태(비어있는/가득 찬/찌그러진)의 이미지를 추가 학습하면 개선 가능하다.

자기점검 체크리스트

  • ☑ 학습에 사용하지 않은 새로운 데이터로 테스트를 수행하였다.
  • ☑ 예상 결과와 실제 결과가 모두 서술되어 있다.
  • ☑ 차이가 있다면 그 원인이 분석되어 있다.

문항 7. 기대 효과 및 개선 사항

모델 적용 시 기대 효과와 현재 모델의 한계 및 개선 방향을 서술하시오.

기대 효과

관심 분야: 환경 · 스마트시티 스마트폰 앱에 탑재하면 시민이 쓰레기를 카메라로 찍기만 해도 올바른 분리수거 방법을 즉시 안내받을 수 있다. 공공장소 쓰레기통에 카메라를 설치하여 자동 분리수거 시스템으로 발전시키면 재활용률 향상과 환경 오염 감소에 기여한다.

개선 사항

현재 모델의 한계: 5개 클래스만 있어 복합 재질 포장지, 음식물 쓰레기 등 세부 분류가 어렵다. 일반쓰레기 정확도가 가장 낮다. 개선 방향: 클래스를 세분화(비닐 / 스티로폼 등)하고, 다양한 상태(내용물 있음·찌그러짐 등)의 이미지를 충분히 추가 수집하여 재학습한다.

자기점검 체크리스트

  • ☑ 관심 분야가 명시되고, 기대 효과가 구체적으로 서술되어 있다.
  • ☑ 현재 모델의 한계가 언급되어 있다.
  • ☑ 성능 향상을 위한 개선사항이 제시되어 있다.

문항 8. 소감

달라진 생각, 어려웠던 점, 새롭게 알게 된 것, 또는 느낀 점을 자유롭게 서술하시오.

평소 분리수거를 할 때 '이게 플라스틱인지 일반쓰레기인지' 헷갈렸는데, 직접 AI 모델을 만들어보니 그 판단을 AI가 학습할 수 있다는 게 신기했다. 300장의 사진을 모으고 분류하는 과정이 생각보다 손이 많이 갔는데, 데이터 수집과 전처리가 AI 성능에 얼마나 중요한지를 직접 느꼈다. 캔을 플라스틱으로 잘못 분류한 결과를 보며, AI도 학습하지 않은 상황에는 틀릴 수 있다는 것을 깨달았다. 환경 문제에 관심이 있어서, 언젠가 이 모델을 발전시켜 실제 스마트 분리수거 앱을 만들어보고 싶다.

자기점검 체크리스트

  • ☑ 기계학습 구현 과정에서 새롭게 알게 된 것이 포함되어 있다.
  • ☑ 자신의 경험을 바탕으로 진솔하게 작성되어 있다.
