아이디어 발견부터 설계까지

이 모델은 어떤 계기로 만들게 됐을까? 왜 기계학습이 필요한지, 왜 하필 이 방법인지 사고의 흐름을 따라가 보자.

1

어디서 아이디어를 얻었나? — 실생활의 불편함

경제 뉴스에서 "AI가 대출 심사를 보조한다"는 기사를 읽고 관심이 생겼다. 같은 신청자인데 담당자마다 다른 결정을 내릴 수 있고, 사람의 주관적 판단이 개입된다는 문제를 알게 됐다. 데이터 기반으로 일관된 기준을 적용하면 더 공정한 심사가 가능하지 않을까 생각했다.

2

왜 기계학습이 필요한가? — 전통적 코딩의 한계

"신용점수 700 이상 + 월소득 300만원 이상이면 승인"처럼 기준표를 만들면 안 될까? 실제 대출 결과는 신용점수, 소득, 부채비율 등이 복잡하게 얽혀 있어 단순 기준표로는 정확도가 낮다. 예를 들어 신용점수가 낮아도 소득이 충분히 높으면 승인되는 경우도 있다. 수천 건의 실제 심사 기록에서 이런 복합 패턴을 학습하는 기계학습이 필요하다.

3

왜 분류(로지스틱 회귀)인가? — 기계학습 방법 선택의 논리

대출 결과는 '승인' 또는 '거절', 딱 두 가지 중 하나다. '얼마를 빌려줄 수 있나' 같은 수치를 추정하는 예측도 아니고, 비슷한 신청자를 묶는 군집도 아니다. 과거 심사 기록(정답 레이블: 승인/거절)이 있으므로 지도학습이고, 두 범주를 판별하므로 분류가 적합하다. 특히 승인 확률을 퍼센트로 출력할 수 있는 로지스틱 회귀가 이 문제에 잘 맞는다.

문항 1. 문제 정의

실생활에서 AI로 해결하고자 하는 문제를 구체적으로 정의하시오.

은행에서 대출 신청자가 많을 때 담당자가 모든 신청서를 일일이 검토하면 시간이 오래 걸리고 판단 기준도 담당자마다 달라질 수 있다.

신용점수와 월 소득 등의 데이터를 입력하면 '대출 승인' 또는 '대출 거절'을 자동으로 판단하는 인공지능 모델을 만들어, 은행의 대출 심사 과정을 보조하고 일관성 있는 기준을 적용하는 데 활용하고자 한다.

자기점검 체크리스트

  • ☑ 해결하고자 하는 문제가 실생활과 연관되어 구체적으로 제시되어 있다.
  • ☑ 문제가 발생하는 상황(불편함·필요성)이 명확하게 서술되어 있다.

문항 2. 모델 설명 (입력 → 출력)

어떤 데이터를 입력받아 어떤 결과를 출력하는지 서술하시오.

  • ■ 입력: 대출 신청자의 신용점수(점), 월 소득(만원), 부채 비율(%)
  • ■ 출력: '승인' 또는 '거절' 레이블 + 승인 확률(%)

과거 대출 승인·거절 기록 데이터를 학습하여, 새로운 신청자의 정보가 입력되면 대출 승인 가능성을 확률로 계산하고 결과를 출력한다. 예) 신용 720점 / 월소득 350만원 / 부채비율 20% → 승인 확률 87%

자기점검 체크리스트

  • ☑ 입력 데이터가 명확히 제시되어 있다.
  • ☑ 모델이 출력하는 결과가 구체적으로 서술되어 있다.
  • ☑ 입력과 출력을 통해 모델의 역할이 명확하게 드러난다.

문항 3. 기계학습 유형 및 구현 도구 선택

① 기계학습 유형, ② 구현 도구를 선택하고 각각 이유를 서술하시오.

① 기계학습 유형: 지도학습 — 분류 (로지스틱 회귀)

대출 결과는 '승인' 또는 '거절', 두 가지 중 하나를 판별하는 분류이므로 분류 모델이 적합하다. 과거 데이터에 '승인/거절' 레이블이 포함되어 있어 지도학습이다. '승인' 또는 '거절'을 확률로 판별할 수 있는 로지스틱 회귀를 선택했다.

② 구현 도구: Orange

Orange의 Logistic Regression 노드를 이용하면 코딩 없이 모델을 구성하고 결과를 표와 그래프로 직관적으로 확인할 수 있다.

자기점검 체크리스트

  • ☑ 지도/비지도학습 중 하나를 명확히 선택하였다.
  • ☑ 유형 선택 이유가 논리적으로 서술되어 있다.
  • ☑ 구현 도구 선택 이유가 기계학습 유형과 연결되어 설명되어 있다.

문항 4. 데이터 설명

데이터의 출처·유형·수량·특성을 작성하고, 스크린샷을 첨부하시오.

  • • 출처: Kaggle 'Credit Risk Dataset' (공개 데이터셋, CC0 라이선스)
  • • 유형: 수치형 정형 데이터 (CSV, 4개 열 사용)
  • • 수량: 1,000행 (대출 승인 700건 / 거절 300건)

자기점검 체크리스트

  • ☑ 데이터의 출처가 명시되어 있다.
  • ☑ 데이터의 유형과 수량이 구체적으로 서술되어 있다.
  • ☑ 학습에 사용된 데이터 화면 스크린샷이 첨부되어 있다.

문항 5. 학습 결과

학습 완료 화면을 스크린샷으로 첨부하고, 결과의 의미를 설명하시오.

  • • Orange 교차 검증(Cross Validation) 결과: 전체 정확도 88.2%

테스트 200건 결과

  • • 실제 승인 고객 140명 중 132명을 올바르게 승인 예측 → 대부분 놓치지 않음
  • • 실제로는 거절이어야 하는 고객 60명 중 16명이 승인으로 잘못 예측됨 → 추가 검토 필요

※ 스크린샷: Orange 학습 결과 화면 [실제 수행평가 시 첨부]

자기점검 체크리스트

  • ☑ 학습 완료 화면 또는 학습 결과 스크린샷이 첨부되어 있다.
  • ☑ 모델의 학습 결과를 확인할 수 있는 수치나 지표가 언급되어 있다.
  • ☑ 학습 결과의 의미가 서술되어 있다.

문항 6. 테스트 및 결과 분석

새로운 데이터로 테스트하고, 예상 결과와 실제 결과를 비교·분석하시오.

■ 테스트 1 — 우량 신청자

  • 입력: 신용점수 780점 / 월소득 420만원 / 부채비율 12%
  • 예상: 승인
  • 실제 출력: 승인 확률 96.4% → 예상과 일치

■ 테스트 2 — 고위험 신청자

  • 입력: 신용점수 490점 / 월소득 170만원 / 부채비율 68%
  • 예상: 거절
  • 실제 출력: 거절 확률 91.8% → 예상과 일치

■ 테스트 3 — 경계 사례

  • 입력: 신용점수 620점 / 월소득 260만원 / 부채비율 38%
  • 예상: 판단하기 어려움
  • 실제 출력: 승인 확률 54.2% → 경계 수준, 추가 심사 권고

■ 분석

신용점수가 높고 부채비율이 낮을수록 승인 확률이 명확히 높아지는 패턴이 모델에 잘 반영됐다. 경계 사례(확률 50%대)는 사람이 추가로 검토하는 하이브리드 방식이 적절하다.

자기점검 체크리스트

  • ☑ 학습에 사용하지 않은 새로운 데이터로 테스트를 수행하였다.
  • ☑ 예상 결과와 실제 결과가 모두 서술되어 있다.
  • ☑ 차이가 있다면 그 원인이 분석되어 있다.

문항 7. 기대 효과 및 개선 사항

모델 적용 시 기대 효과와 현재 모델의 한계 및 개선 방향을 서술하시오.

기대 효과

관심 분야: 금융 · 핀테크

은행 대출 심사에서 1차 자동 심사로 활용하면 처리 속도를 높이고 심사 기준의 일관성을 유지할 수 있다.

인터넷 은행·핀테크 앱에서 신청자가 입력값을 넣으면 즉시 예비 결과를 확인하는 신속 심사 서비스로도 활용 가능하다.

개선 사항

현재 모델의 한계: 신용점수·소득·부채비율 3개 특성만 사용하여 직업 안정성, 연체 이력, 담보 여부 등 실제 심사 기준의 다양한 요소를 반영하지 못한다.

개선 방향: 더 많은 특성을 추가하거나, 의사결정나무·랜덤포레스트로 모델을 교체하여 비선형 패턴도 학습할 수 있게 한다.

자기점검 체크리스트

  • ☑ 관심 분야가 명시되고, 기대 효과가 구체적으로 서술되어 있다.
  • ☑ 현재 모델의 한계가 언급되어 있다.
  • ☑ 성능 향상을 위한 개선사항이 제시되어 있다.

문항 8. 소감

달라진 생각, 어려웠던 점, 새롭게 알게 된 것, 또는 느낀 점을 자유롭게 서술하시오.

은행 대출 심사를 AI가 한다는 게 처음엔 윤리적으로 괜찮은지 의문이었는데, 직접 만들어보니 '보조 도구'로 활용하고 최종 결정은 사람이 하는 방식임을 이해했다.

잘못 승인된 경우와 잘못 거절된 경우의 의미를 살펴보면서, AI 모델의 오류가 실제 사람에게 미치는 영향을 고려해야 한다는 걸 느꼈다.

특히 부채비율이 높아도 소득이 충분하면 승인 확률이 올라가는 패턴을 보며, AI가 단순 규칙이 아닌 복합적인 패턴을 학습한다는 것이 인상 깊었다.

금융 분야에 관심이 있어서, 나중에 더 많은 특성과 데이터로 공정하고 정확한 신용 평가 AI를 만들어보고 싶다.

자기점검 체크리스트

  • ☑ 기계학습 구현 과정에서 새롭게 알게 된 것이 포함되어 있다.
  • ☑ 자신의 경험을 바탕으로 진솔하게 작성되어 있다.
