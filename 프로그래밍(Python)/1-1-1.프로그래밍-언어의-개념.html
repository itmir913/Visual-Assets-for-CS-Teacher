Chapter 1. 프로그래밍 기초

1-1-1. 프로그래밍 언어의 개념

프로그래밍 언어는 사람과 컴퓨터 사이의 다리 역할을 합니다. 우리가 원하는 명령을 내리기 위해 사용하는 특별한 약속입니다.

학습 목표 (Objective)

"프로그래밍 언어란 무엇이고, 어떻게 번역될까?"

  • 프로그래밍 언어의 개념을 설명할 수 있다.
  • 컴파일러와 인터프리터의 작동 방식을 비교할 수 있다.

Section 1

프로그래밍 언어란?

프로그래밍 언어는 사용자와 컴퓨터 사이에서 의사소통을 가능하게 하는 매개체입니다. 사람이 이해할 수 있는 문법으로 작성된 명령을 컴퓨터가 실행할 수 있는 기계어로 변환합니다.

정해진 문법과 의미를 가짐

언어마다 고유한 규칙(문법)이 있으며, 이를 따라야 컴퓨터가 이해할 수 있습니다.

기계어로 변환되어 실행됨

작성된 코드는 번역 과정을 거쳐 컴퓨터가 직접 처리할 수 있는 0과 1의 신호로 바뀝니다.

Section 2

저급 언어와 고급 언어

프로그래밍 언어는 컴퓨터 하드웨어와 얼마나 가까운지에 따라 저급 언어와 고급 언어로 나뉩니다.

Low-Level

저급 언어

하드웨어를 직접 제어하는 언어로, 컴퓨터에 가깝지만 사람이 이해하기 어렵습니다.

기계어 (0과 1의 이진 코드)
어셈블리어 (기호로 기계어를 표현)
High-Level

고급 언어

사람의 언어에 가까운 문법을 사용하여 배우기 쉽고 범용성이 높습니다.

Python, C, Java, JavaScript 등
번역기를 통해 기계어로 변환하여 실행

Section 3

번역 프로그램의 종류

고급 언어로 작성된 코드를 기계어로 변환하는 방식에는 두 가지가 있습니다. 번역 시점과 방식에 따라 컴파일러와 인터프리터로 구분됩니다.

Compiler

컴파일러

소스 코드 전체를 한꺼번에 기계어로 번역하여 실행 파일을 만듭니다. 번역 후 실행 속도가 빠릅니다.

Speedy C, C++, Java (컴파일 단계)
Interpreter

인터프리터

소스 코드를 한 줄씩 읽어 즉시 실행합니다. 수정과 테스트가 빠르고 유연합니다.

Flexible Python, JavaScript, Ruby
구분 컴파일러 인터프리터
번역 시점 실행 전 전체 번역 실행 중 한 줄씩 번역
실행 속도 빠름 상대적으로 느림
오류 발견 번역 시 전체 오류 확인 실행 중 오류 발생 시 중단
클립보드에 복사되었습니다!
