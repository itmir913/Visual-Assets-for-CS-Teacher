복리의 마법: 이자에도 이자가 붙는다

매달 일정 금액을 저축할 때, 단순히 원금에만 이자가 붙는 단리와 달리 복리는 누적 잔액 전체에 이자가 붙습니다. for 반복문으로 월별 잔액을 갱신하면, 시간이 지날수록 이자 효과가 점점 커지는 복리의 특성을 코드로 직접 구현할 수 있습니다.

Section 1

Step 1. 프로그램 기획 (문제 정의)

월 저축금액과 월 이자율을 입력받아 1개월~24개월 후의 잔액을 복리로 계산하여 출력하는 프로그램을 기획합니다.

핵심 공식: 월별 복리 잔액 갱신

잔액 = (잔액 + 월저축금액) × (1 + 이자율 / 100)

이 식을 for 반복문으로 24번 반복하면 매월 잔액이 복리로 증가합니다.

이전 잔액: balance
이번 달 저축: savings
이자 배율: 1 + rate/100

단리 vs 복리 비교

구분 이자 계산 방식 24개월 후 잔액
월 100,000원, 월 이율 1%
단리 원금에만 이자 계산
매월 고정 이자 = 저축 누계 × 0.01		 약 2,424,000 원
복리 ✅ 누적 잔액 전체에 이자 계산
잔액 = (잔액 + 100,000) × 1.01		 약 2,724,320 원

약 300,320원 차이 — 기간이 길어질수록 복리의 효과는 더욱 커집니다.

목적

월 저축금액·월 이자율 입력 시, 1개월부터 24개월까지의 복리 잔액을 매월 출력

대상

for 반복문과 누적 변수(balance)를 활용한 반복 연산을 학습하는 누구나

주요 기능

float 입력 · range(1, 25) · 복리 공식 반복 · :.2f 소수점 출력

Section 2

Step 2. 프로그램 설계 (알고리즘)

입력·반복 처리·출력 흐름을 순서대로 설계합니다.

입력 설계

  • • 1행: 월 저축금액 (원, 소수점 가능)
  • • 2행: 월 이자율 (%, 소수점 가능)
  • 자료형: float — 소수점 이율(1.5%) 지원
예시 입력 1행: 100000
예시 입력 2행: 1.0

출력 설계

  • • 총 24줄 출력
  • • 형식: N개월 후 잔액: X.XX 원
  • • 소수점 2자리 고정 (:.2f)
1개월 후 잔액: 101000.00 원
2개월 후 잔액: 203010.00 원
...
24개월 후 잔액: XXXXXX.XX 원

알고리즘 순서 설계

  1. 월 저축금액 savings 입력 (float)
  2. 월 이자율 rate 입력 (float, % 단위)
  3. 누적 잔액 balance = 0.0 초기화
  4. for month in range(1, 25): → 1~24 반복
  5. → balance = (balance + savings) * (1 + rate / 100)
  6. → print(f"{month}개월 후 잔액: {balance:.2f} 원")

핵심 문법: range(1, 25) vs range(24)

range_example.py 
# range(24)    → 0, 1, 2, ..., 23  (출력 시 month+1 필요 → 헷갈림)
# range(1, 25) → 1, 2, 3, ..., 24  ← 월 번호와 바로 일치 ✅

for month in range(1, 25):
    print(month)   # 1, 2, 3, ..., 24 — 별도 조정 불필요

Section 3

Step 3. 프로그램 구현 (Python)

복리 공식을 for 반복문으로 구현한 완성 코드입니다. 각 줄의 역할을 확인하세요.

compound_interest.py 
# 1. 입력: 소수점도 받을 수 있도록 float() 사용
savings = float(input())   # 월 저축금액 (원)
rate    = float(input())   # 월 이자율 (%)

# 2. 누적 잔액 초기화 (루프 밖에서 한 번만)
balance = 0.0

# 3. 1개월 ~ 24개월 복리 계산
for month in range(1, 25):          # month: 1, 2, ..., 24
    balance = (balance + savings) * (1 + rate / 100)
    print(f"{month}개월 후 잔액: {balance:.2f} 원")

코드 행별 설명

  • float(input()) — int() 대신 써야 1.5% 같은 소수점 이자율도 입력 가능
  • balance = 0.0 — 루프 밖에서 초기화. 루프 안에 두면 매월 0원으로 리셋됨
  • range(1, 25) — month 변수가 1~24를 순서대로 가져 출력 번호와 일치
  • (balance + savings) * (1 + rate/100) — 이달 저축금 추가 후 이자 적용 (복리)
  • balance:.2f — 소수점 2자리 고정 출력 (예: 101000.00)

코드 실행 추적 (Trace)

입력: 100000 / 1.0

month 계산 과정 balance (잔액)
1 (0 + 100000) × 1.01 101,000.00 원
2 (101000 + 100000) × 1.01 203,010.00 원
3 (203010 + 100000) × 1.01 306,040.10 원
... ... ...
24 (...) × 1.01 2,724,319.95 원

※ 24개월 값은 부동소수점 누적 계산 결과이며, 실행 환경에 따라 마지막 자리가 미세하게 달라질 수 있습니다.
