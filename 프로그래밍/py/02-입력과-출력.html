프로그래밍

입력과 출력

사람과 말을 주고받지 못하는 프로그램은
매번 같은 답만 내놓습니다.

학습 목표

  1. 여러 값을 한 줄로 내보내고, 사이에 넣을 것과 끝에 붙일 것을 바꿀 수 있다.
  2. 키보드로 값을 받아 변수에 담을 수 있다.
  3. 받은 값이 왜 언제나 글자인지 설명하고, 계산에 쓰기 위해 바꿀 수 있다.
  4. 한 줄에 들어온 값 여러 개를 나누어 각각의 변수에 담을 수 있다.
입력과 출력
내보내기 사이와 끝 받아들이기 여러 값 받기 핵심 정리 퀴즈

화면에 내보내기

쉼표로 나열하면 알아서 이어 줍니다.

앞 차시에서 값을 담는 것까지 했습니다. 담아 둔 값을 사람이 보려면 화면으로 내보내야 합니다.

쉼표로 나열하면 세 가지가 저절로 됩니다

  • 값 사이에 빈칸 하나가 들어간다.
  • 글자와 수를 섞어 놓아도 된다.
  • 끝에서 줄이 바뀐다.

셋 다 바꿀 수 있는 기본값입니다. 바꾸는 방법은 바로 아래에서 봅니다.

쉼표와 더하기는 다릅니다

print("점수는", 90)은 됩니다. 그런데 print("점수는" + 90)은 오류가 납니다. 쉼표는 「나열해 달라」이고 더하기는 「이어 붙여 달라」인데, 글자와 수는 이어 붙일 수 없기 때문입니다.

쉼표 쪽이 편하지만 빈칸이 저절로 들어가는 것은 알아 두세요 — print(score, "점")은 「90 점」으로 나옵니다.

스스로 확인

print("합계:", 100, "원")은 빈칸이 몇 개 들어간 채로 나올까요?

사이에 넣을 것과 끝에 붙일 것

기본값을 바꾸면 표도 만들고 한 줄에 이어 붙일 수도 있습니다.

값 사이에 들어가는 것을 바꾸려면 sep을 줍니다. 「구분해 주는 것」이라는 뜻입니다.

끝에 붙는 것을 바꾸려면 end를 줍니다. 기본값이 줄바꿈이라, 아무것도 안 넣으면 줄이 안 바뀝니다.

둘을 나누어 기억합니다

sep은 한 번의 출력 «안»에서 값과 값 사이에 들어갑니다. end는 그 출력이 끝난 «뒤»에 붙습니다. 그래서 값이 하나뿐이면 sep은 아무 일도 하지 않습니다.

스스로 확인

여러 값을 줄마다 하나씩 찍고 싶다면 sep과 end 가운데 무엇을 어떻게 주면 될까요?

키보드로 받아들이기

받은 값은 수처럼 보여도 글자입니다.

input은 사용자가 엔터를 칠 때까지 기다렸다가, 친 것을 그대로 돌려줍니다. 괄호 안에 물어보는 말을 적어 두면 기다리기 전에 먼저 찍어 줍니다.

받은 것은 «언제나» 글자입니다

17을 쳤는데 type으로 물어보면 str이라고 답합니다. 화면에 보이는 모양이 같다고 같은 종류인 것이 아닙니다. 그래서 age + 1을 하면 글자와 수를 더할 수 없다며 멈춥니다.

처음 배울 때 거의 모두 한 번은 겪습니다. 앞 차시에서 배운 형 변환이 바로 여기서 필요해집니다.

받자마자 바꿔 두는 편이 낫습니다

int(input(…))처럼 받는 자리에서 곧바로 바꿔 두면, 그 뒤로는 그냥 수처럼 쓰면 됩니다. 나중에 쓸 때마다 바꾸면 한 군데를 빠뜨리기 쉽습니다.

다만 수가 아닌 것을 치면 그 자리에서 오류가 납니다. 「열일곱」이라고 치면 수로 바꿀 수 없기 때문입니다.

스스로 확인

나이를 받아 글자 그대로 두면 age * 2는 무엇이 될까요? 오류일까요, 아니면 다른 결과일까요?

한 줄에 들어온 여러 값

두 번 물어볼 수도 있고, 한 번에 받아 나눌 수도 있습니다.

값이 여럿이면 input을 여러 번 써도 됩니다. 그런데 사용자가 「80 91」처럼 한 줄에 치는 편이 편할 때가 많습니다. 그러면 받은 글자를 빈칸에서 잘라 나누어야 합니다.

자른 결과는 값 여러 개가 늘어선 것입니다

split은 빈칸을 기준으로 잘라 조각을 순서대로 늘어놓아 줍니다. ['80', '91']처럼 대괄호로 묶여 나오고, 앞에서부터 0번, 1번으로 세어 꺼냅니다.

잘라도 여전히 글자입니다. 따옴표가 그대로 붙어 있는 것이 그 표시입니다. 그래서 꺼낸 다음 int로 바꿔 주어야 합니다.

「잘라서 하나씩 꺼내 바꾸기」는 값이 늘어날수록 길어집니다. 자른 조각 전부에 같은 변환을 걸어 한 줄로 줄일 수 있습니다.

한 줄을 셋으로 나누어 읽습니다

  1. input(…) — 한 줄을 통째로 받는다. "80 91"
  2. .split() — 빈칸에서 자른다. ['80', '91']
  3. map(int, …) — 조각마다 int를 걸어 준다.

왼쪽의 kor, eng는 나온 값을 순서대로 나누어 담습니다. 왼쪽 이름의 개수와 값의 개수가 맞아야 하고, 어긋나면 오류가 납니다 — 사용자가 값을 하나만 치면 그렇게 됩니다.

스스로 확인

쉼표로 구분해 「80,91」처럼 치게 하려면 split에 무엇을 알려 주어야 할까요?

핵심 정리

쉼표로 나열

사이에 빈칸 하나가 들어가고 끝에서 줄이 바뀐다. 글자와 수를 섞어도 된다 — 더하기로는 안 된다.

sep과 end

sep은 값과 값 사이, end는 출력이 끝난 뒤. end=""를 주면 줄이 바뀌지 않는다.

받은 것은 글자

input이 돌려주는 것은 언제나 글자다. 계산에 쓰려면 int·float로 바꾼다. 받는 자리에서 바로 바꿔 두는 편이 안전하다.

한 줄에 여러 값

.split()으로 빈칸에서 자르고, map(int, …)으로 조각마다 변환을 건다. 왼쪽 이름 개수와 값 개수가 맞아야 한다.

퀴즈

1. age = input()으로 17을 받았다. age + 1은?

2. print("가", end="") 다음에 print("나")를 하면?

3. input().split()의 결과에 대한 설명으로 틀린 것은?
